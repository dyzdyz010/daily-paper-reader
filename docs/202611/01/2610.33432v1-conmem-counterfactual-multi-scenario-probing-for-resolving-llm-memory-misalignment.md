## 摘要
长期记忆对于执行多会话、长周期任务的自主大语言模型（LLM）智能体至关重要。然而，现有记忆常常不恰当地存储、保留或检索过度泛化、错误归因或隐私敏感的信息，我们将这一问题称为记忆失配。为研究这一问题，我们构建了MemAlign，一个包含1,079条精选记忆案例的基准，这些案例基于合成的、经过验证的多会话对话上下文，涵盖多样的失配分类。随后，我们提出ConMem，一种将保留决策重构为前瞻性反事实因果推断的算法。ConMem合成反事实交互场景，以从相关任务执行、无关不变性检查和风险敏感边界偏移三个方面前瞻性地审计下游干预效应。实验表明，ConMem优于其他方法，达到75.16%的准确率、64.15%的平衡准确率和65.31%的Macro-F1，有效缓解过度保留偏差，而不牺牲个性化效用。

## Abstract
Long-term memory is critical for autonomous Large Language Model (LLM) agents executing multi-session, long-horizon tasks. However, existing memories often inappropriately store, retain, or retrieve over-generalized, misattributed, or privacy-sensitive information, a problem we term memory misalignment. To study this problem, we construct \textbf{MemAlign}, a benchmark comprising 1,079 curated memory cases grounded in synthetic, validated multi-session conversational contexts covering diverse misalignment taxonomies. We then propose ConMem, an algorithm that reframes retention decisions as prospective counterfactual causal inference. \textbf{ConMem} synthesizes counterfactual interaction scenarios to prospectively audit downstream intervention effects across three aspects: relevant task execution, irrelevant invariance checks, and risk-sensitive boundary shifts. Experiments show that ConMem outperforms other methods, achieving 75.16\% accuracy, 64.15\% balanced accuracy, and a Macro-F1 of 65.31\%, effectively mitigating over-retention biases without sacrificing personalization utility.

## 1. 核心问题与背景

- **研究动机**：长期记忆对自主大语言模型（LLM）智能体在多会话、长周期任务中的表现至关重要，但现有记忆系统常出现不当存储、保留或检索行为。
- **核心问题——记忆失配（memory misalignment）**：候选记忆可能被过度概括、错误归因或包含隐私敏感信息；当这些不当记忆被后续调用时，会污染智能体的决策边界。
  - 例如：用户提到“同事不吃肉”，朴素记忆流水线可能错误存储“用户本人是素食者”，三周后用户要求推荐牛排馆时，智能体却过滤掉所有牛肉菜品。
- **传统方法的局限**：现有技术往往孤立地评估候选记忆，仅依赖提取置信度、语义相关性或表面事实启发式，无法预判记忆对未来交互的下游影响。
- **研究目标**：构建专门基准 MemAlign 以系统评测记忆准入与使用问题，并提出 ConMem 算法，从反事实因果推断的视角解决记忆失配。

## 2. 方法论：ConMem 的核心思想与算法流程

- **总体思想**：将“是否存储候选记忆”的决策转化为**前瞻性反事实因果推断**。通过模拟未来交互，比较在“有记忆”和“无记忆”两种条件下生成响应的差异，估计候选记忆对下游行为的因果效应。
- **核心指标：CMTE（Counterfactual Memory Treatment Effect，反事实记忆处理效应）**：
  - 给定历史上下文 \(C\) 和候选记忆 \(M\)，合成三类未来探测 \(Q=\{q_{rel}, q_{irr}, q_{risk}\}\)。
  - 对每个探测 \(q_i\)，生成控制响应 \(R_i^0=f(q_i)\) 和处理响应 \(R_i^1=f(q_i,M)\)。
  - 通过盲质量判断与记忆归因审计，得到每个探测的效应贡献 \(c_i\)。
  - 聚合公式：

\[
CMTE(M)=\frac{1}{K}\sum_{i=1}^{K}c_i,\quad K=3
\]

- **未来探测构建**：
  - **相关探测（relevant probe）**：创建 \(M\) 能提供非冗余、用户特定信息并实质影响响应的场景。
  - **无关探测（irrelevant probe）**：任务结果应与 \(M\) 无关，用于检查不必要的个性化。
  - **风险探测（risk probe）**：引入实体偏移、事实更新、显式覆盖或范围转换，暴露不当记忆携带。
  - 独立探针审计器验证语义角色，防止泄漏候选记忆、金标准标签或基准伪影。

- **受控反事实响应生成**：
  - 控制分支仅输入未来查询 \(q_i\)；处理分支额外输入候选记忆 \(M\)。
  - 两分支使用完全相同的模型配置与解码参数，仅记忆访问不同。
  - 历史上下文 \(C\) 在生成阶段被隐藏，仅用于下游评估，以隔离 \(M\) 的直接因果效应。

- **双重评估（关键设计）**：
  - **盲响应质量判断**：在不告知哪个是处理响应、也不提供 \(M\) 的前提下，比较 \(R^0\) 与 \(R^1\) 的正确性、相关性、适当性与帮助性。结果可为 A、B 或 Tie。
  - **记忆归因审计**：独立审计器判断 \(M\) 是否被实质调用并改变响应，将归因效应分类为 \(P_i\in\{\text{utility},\text{unnecessary},\text{neutral},\text{risk}\}\)。
  - 最终响应级效应 \(E_i\in\{\text{HELPFUL},\text{NEUTRAL},\text{HARMFUL}\}\) 由质量偏好与归因结果共同决定。

- **探测贡献与准入规则**：
  - 相关探测：有帮助效用 \(+1.0\)；归因风险 \(-1.0\)。
  - 无关探测：不必要个性化 \(-0.5\)；归因风险 \(-1.0\)。
  - 风险探测：有帮助效用 \(+0.5\)；不必要个性化 \(-0.5\)；归因风险 \(-1.5\)。
  - 其他情形贡献为 0。
  - 若 \(CMTE(M)>0\)，判定为 STORE；若 \(<0\)，判定为 DO-NOT-STORE。
  - 若 \(|CMTE(M)|\le\epsilon\)（\(\epsilon=10^{-12}\)），引入**参数无关的 tie-break 判断器**，基于 \(C\)、\(M\) 和原始反事实日志做出最终决定。

- **后置原因分类**：在准入决策确定后，为拒绝案例分配结构化错误类别，用于失败分析，但不修改预测结果。

## 3. 实验设计

- **主要基准：MemAlign**
  - 包含 1,079 条候选记忆，基于 Chen et al.（2026）的原始数据扩展。
  - 每条样本包含：候选记忆、准确性标注、存储决策（金标准）、用户反馈，以及合成的多会话历史对话。
  - 最终分布：779 个 STORE（72.2%），300 个 DO-NOT-STORE（27.8%）；覆盖 10 种原因类型（如直接相关、虚假记忆使用、过度推断、粒度不匹配等）。
  - 上下文由 Qwen3.8-Max 生成，并通过结构检查、LLM 语义审计和人工审查三重验证。

- **对比方法**：
  - **MemoryBank**：基于近因、相关性、重要性建模保留。
  - **A-MEM**：提取属性化记忆，采用归一化重要性和语义新颖性评分。
  - **A-MAC**：基于期望效用、事实置信度、语义新颖性、近因和内容类型先验的准入控制方法。
  - **SAGE**：多智能体推理框架（挑战者、规划者、求解者、批评者），用于记忆准入决策。

- **实验设置**：
  - 所有 ConMem 组件和基线 LLM 骨干使用 Qwen3.8-Max（主要实验），温度 \(0\)，种子 \(42\)。
  - 输出 token 限制：探针/验证/审计/tie-break 上限 2,048；控制与处理响应生成上限 8,192。
  - 采用中等推理力度用于探针、响应和质量生成；高推理力度用于验证、审计和 tie-break。
  - 每个候选记忆评估需 14 次标准模型调用，零分时额外一次 tie-break 调用。

- **评估指标**：准确率、平衡准确率、Macro-F1、存储召回率（Store Recall）、不存储召回率（DNS Recall）。
