## 摘要
大多数智能体记忆基准将长期记忆定义为检索：智能体能否从漫长且不断演变的历史中恢复相关记录？科学智能体面临更严格的问题：一个被正确记住的事实仍可能在使用上无效。同一个报告测试结果，在结果和停止规则事先固定的情况下可以支持确认；但当结果是从二十个检查结果中挑选出来时，它只能支持探索。我们称此为科学使用有效性：被记住的证据是否有资格在支配其解释的状态下影响决策。我们引入 SciValidityBench，一个可执行的基准工厂，包含 64 个 TaskSpecs，涵盖五个有效性模块和六个科学领域。TaskSpecs 将生成的实验历史与科学状态定义、程序化决策预言机、受控干预和自动评分相结合。SciStateForge 编译器-读取器框架将分布式历史转换为显式的决策支配状态。反事实对和定向损坏-修复控制随后测试模型是否利用这些依赖关系，并定位失败。在四个模型家族中，与通用事件图相比，编译的科学状态将有效决策提高了 9.2-18.8 个百分点。仅靠检索无法复现这种跨家族增益，而内容相同的平面视图和类型化视图表明，这种改进来自暴露支配状态，而不是特定的图序列化。因此，SciValidityBench 将记忆评估从找到正确事实转向了决定该事实是否应该控制决策。

## Abstract
Most agent-memory benchmarks frame long-term memory as retrieval: can an agent recover the relevant record from a long and evolving history? Scientific agents face a stricter problem: a correctly remembered fact may still be invalid to use. The same reported test result can support confirmation when the outcome and stopping rule were fixed in advance, yet only exploration when the outcome was selected from twenty inspected results. We call this scientific use validity: whether remembered evidence is eligible to influence a decision under the state governing its interpretation. We introduce SciValidityBench, an executable benchmark factory with 64 TaskSpecs spanning five validity modules and six scientific domains. TaskSpecs couple generated experimental histories with scientific-state definitions, programmatic decision oracles, controlled interventions, and automatic scoring. The SciStateForge compiler-reader framework turns distributed histories into explicit decision-governing state. Counterfactual pairs and targeted corruption-repair controls then test whether models use those dependencies and localize failures. Across four model families, compiled scientific state improves valid decision-making by 9.2-18.8 percentage points over a generic Event Graph. Retrieval alone does not reproduce this cross-family gain, while content-identical flat and typed views show that the improvement comes from exposing governing state rather than a particular graph serialization. SciValidityBench thus shifts memory evaluation from finding the right fact to deciding whether that fact should control the decision.

- **关键概念**：论文提出 **“科学使用有效性”（scientific use validity）**，即被记住的证据是否有资格在支配其解释的科学状态下影响决策。

- **整体含义**：科学记忆应同时回答“事实是否正确、来源是否可靠、**该事实在当前状态下是否被许可使用**”三个问题。论文将记忆评估从“找到正确事实”转向“判断事实是否应控制决策”。

## 2. 论文提出的方法论

### 2.1 SciValidityBench 基准工厂

- **基本单元是 TaskSpec（任务规范）**，而非固定的自然语言问题。每个 TaskSpec 是一个可执行程序，其功能契约形式化为：

  \[
  \tau = \langle D_\tau, W_\tau, C_\tau, A_\tau, O_\tau, I_\tau, S_\tau \rangle
  \]

  分别对应：领域适配器、世界生成器、科学状态编译器、合法动作空间、决策预言机、受控干预、评分器。

- **64 个 TaskSpecs** 跨五个有效性模块和六个科学领域；通过种子生成 640 个世界、1,920 个公共事件记录。

- **两个正交扩展轴**：
  - 增添新领域：只需提供新的实体、单位、工件和事件语言，复用已有有效性规则；
  - 增添新机制：声明新的支配变量、编译器关系、预言机和干预，复用领域与评分接口。

### 2.2 SciStateForge 编译器–读取器流水线

四个核心阶段：

1. **实例化科学世界**：由领域适配器生成多回合历史，使用统一事件词汇：`PLAN`, `RUN`, `OBSERVE`, `ACCESS`, `WRITE`, `RETRIEVE`, `DECIDE`。
2. **规范化历史**：每个事件获得稳定标识、时序、可见性、版本化载荷、成本与溯源，确保字节级可重放。
3. **编译支配关系**：模块 reducer 将公共事件映射为**科学状态图（SSG）**，节点包括计划、观察、构念、访问记录、缺失、成本、决策等；类型化边包括 `SELECTED FROM`、`STOPPED AFTER`、`SEALED UNTIL`、`COMPARABLE WITH`、`ABSENT BECAUSE`、`RELEVANT TO` 等。派生字段保留指向支持事件的可溯源链接，不新增观察。
4. **渲染、决策与评分**：模型只接收公共历史投影和合法动作；预言机代码判定选择是否有效，并输出诊断信息。

- **与通用事件图的区别**：事件图只保留“发生了什么”和时序/对象边；SciStateForge 进一步解析这些事件对当前决策的**科学后果**。
- **两种编译视图**：Flat SSG（平面记录）和 Typed SVL（类型化账本）暴露相同节点、属性和关系，以隔离图序列化形式的影响。

### 2.3 诊断干预

- **状态改变反事实对**：在保持任务表面、图结构、合法选择和非目标信息不变的情况下，仅改变一个决定性公共值；契约声明预测机关系必须翻转或保持不变。用于检测模型是否真的依赖目标状态，还是仅凭答案偏好。
- **定向损坏与修复**：通过省略节点、断开关系、重标记、合并、复制、注入等算子破坏状态；精确修复恢复原始图，编辑匹配的无关修复在无关位置做同样操作。只有精确修复带来的恢复才支持对目标状态的依赖。

## 3. 实验设计

### 3.1 数据集与场景

- **64 个 TaskSpecs**，覆盖五个有效性模块：
  - **Inferential Ledger（推断账本）**：搜索家族、停止规则、预声明分析范围、证据消耗；
  - **Blind Memory（盲记忆）**：计划锁定、披露时间、授权访问角色；
  - **Construct Drift（构念漂移）**：指标定义、总体、重复含义、版本关系；
  - **Absence Algebra（缺失代数）**：尝试状态、仪器结果、删失、检测机制；
  - **Sunk Cost（沉没成本）**：未来价值与历史投资的相关性。
- 六个科学领域：机器学习、A/B 测试、临床研究、生物信息学、系统、因果推断。
- 每个 TaskSpec 用 10 个未见种子实例化。

### 3.2 评估基准与对比方法

五种记忆视图：

- **Raw Events**：完整有序公共事件序列；
- **BM25 Events**：固定 BM25 检索最多 5 个相关事件块；
- **Event Graph**：所有公共事件和对象，仅用通用序列/提及边连接；
- **Flat SSG**：将编译后的节点、属性、关系序列化为平面记录；
- **Typed SVL**：将同样编译内容表示为类型化节点和关系的账本。

四个开源模型家族：Qwen3-14B、Gemma-3-12B-IT、Mistral-7B-Instruct-v0.3、Phi-3.5-mini-instruct。使用 vLLM 服务、temperature-zero 解码，仅返回合法动作之一，无效 JSON/非法动作/无法解析均计为无效决策。

额外控制条件包括：Matched Source（匹配源事实闭包、令牌长度与 Flat SSG 完全相等）、Opaque Flat/Opaque SVL（替换状态值、关系名和动作标签），以及多种记忆策略（BM25、摘要、选择性记忆、溯源记忆、ECM 等）。

## 6. 论文的主要结论与发现

- **编译科学状态稳定提升有效决策**：与通用事件图相比，Typed SVL 在 Qwen3、Gemma-3、Mistral-7B、Phi-3.5 上分别提升 **+18.8、+18.3、+11.3、+9.2** 个百分点，且所有 95% 置信区间均大于零。
- **增益不由检索或输入长度驱动**：BM25 检索未能复现跨家族增益；事件图虽然最长，但表现接近原始事件；较短的编译视图反而领先。
- **增益来自暴露支配状态，而非图序列化**：Flat SSG 和 Typed SVL 内容相同但序列化不同，二者表现接近；与 Matched Source 的令牌长度完全匹配后，编译状态仍带来优势。
- **反事实状态使用测试揭示能力分层**：Qwen3 和 Gemma 在 Flat/SVL 视图中的关系准确率接近 1.0 和 0.90，而 Mistral 和 Phi 约为 0.55 和 0.36，说明更强模型能把显式状态转化为反事实一致行为，更弱模型常保留稳定答案偏好。
- **定向修复表现出特异性**：精确修复相对编辑匹配无关修复的平均恢复增益为 26.9/32.8/15.0/-0.3 点（四模型均值 18.6），能够区分对支配关系的恢复与一般文本/结构效应。
- **模块异质性**：Blind Memory 和 Inferential Ledger 受益最明显；Absence Algebra 主要惠及 Mistral；Sunk Cost 对部分模型无提升甚至下降，因为正确行为需要抑制无关历史投入。
- **敏感性检验**：移除 22 个存在“状态值等于合法动作”的易拷贝任务后，仍保留 8.3–14.8 点增益；家族等权、留一任务等均保持正效应。

## 7. 优点

- **概念创新**：提出“科学使用有效性”，清晰地分离“事实正确”与“事实可用”，弥补现有记忆基准只测检索能力的空白。
- **可执行基准工厂设计**：TaskSpec 契约将生成、编译、动作、预言机、干预、评分模块化，支持按领域或有效性机制扩展，而非静态数据集。
- **因果诊断能力强**：通过反事实对、定向损坏、精确修复与编辑匹配无关修复，把“性能从哪里来”定位到具体科学状态依赖，而非单一准确率分数。
- **实验控制严格**：源级干预、令牌长度精确匹配、Opaque 条件、任务规范平衡估计量等设计，排除了检索、输入长度、图结构、序列化、答案偏好等多种替代解释。
- **可复现性与透明度**：提供 GitHub 仓库、确定性生成器、编译器、五种视图、干预算子和发布测试；附录详尽记录契约和定义。

## 8. 不足与局限

- **生态效度有限**：历史为程序生成，事件类型和领域表面虽多样，但与真实实验室记录、多模态数据、非结构化笔记仍有距离。
- **模型覆盖范围偏窄**：主要评估 7B–14B 开源模型；托管模型只在部分复现中作为“H1/H2”出现，未完整报告模型版本和接口细节。
- **部分模块收益不一致**：Sunk Cost 在 Qwen3 和 Gemma 上甚至为负，说明“暴露更多结构化历史”并非对所有有效性规则都有益；当前编译器更擅长添加关系和事实，对“应排除哪些信息”的表达较弱。
- **序列化敏感**：Flat 和 Typed 视图在不同模型间差异明显（如 Gemma、Phi 更偏好 SVL），说明最佳表示高度依赖读取器；这意味着需要针对具体模型调整表示，可能增加工程成本。
- **故障诊断仅针对已编译视图**：损坏-修复算子主要用于 Flat/SVL 等编译状态；对于 Raw Events、BM25、Event Graph 等视图的内部失败机制，诊断覆盖相对有限。
- **通用性仍需更多外部验证**：虽做了独立托管复现和 Qwen 复现，但更多模型家族、更大规模状态图、更复杂科学流程尚未覆盖。
