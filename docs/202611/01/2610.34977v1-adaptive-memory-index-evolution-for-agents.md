## 摘要
长程智能体不断积累经验，但保留记忆并不能保证在需要时可被访问。现有系统可以同时适应记忆内容与访问方式；我们将持久化访问更新分离为一个独立控制的适应层。我们将该目标形式化为记忆索引演化，并以自适应记忆索引演化（AMIE）进行实例化；AMIE 是一个轻量级插件层，根据部署期间的检索更新每个记忆的访问状态，而无需修改已存储内容或重新训练宿主记忆系统。AMIE 将语义教师的保留/抑制判断蒸馏为以检索为条件的策略，并将其选择性动作累积到有界状态中，从而重新加权宿主的后续检索。令人惊讶的是，在多种设置下，即使仅累积检索频率的零调用策略也能与语义策略相当或更优，这表明检索流量本身就是访问适应的强信号；而当频繁检索的记忆仍然有用时，学习到的选择性可提高鲁棒性。在五个基于检索的宿主和三个基准上，经过训练的 AMIE 在所有 15 项比较中提高了下游任务 F1 或准确率，提升幅度为 0.70–3.37 个百分点（相对最高可达 25%），并在所有 10 项比较中改善了检索性能。对照分析表明，持续抑制竞争项可以揭示先前未见过的证据，而抑制反复有用的记忆则会产生互补的失效模式。总之，这些结果确立了持久化记忆访问作为基于检索的智能体记忆系统中一个实用的适应层，与其所服务的内容相分离。

## Abstract
Long-horizon agents continually accumulate experience, yet retaining a memory does not guarantee access when it is needed. Existing systems can adapt both memory content and access; we isolate persistent access updates as a separately controlled adaptation layer. We formulate this target as Memory Index Evolution and instantiate it with Adaptive Memory Index Evolution (AMIE), a lightweight plug-in layer that evolves per-memory access state from deployment retrievals without modifying stored content or retraining the host memory system. AMIE distils a semantic teacher's keep/suppress judgments into a retrieval-conditioned policy and accumulates its selective actions into bounded state that reweights subsequent host retrievals. Surprisingly, even a zero-call policy that simply accumulates retrieval frequency can match or outperform semantic policies in several settings, revealing retrieval traffic itself as a strong signal for access adaptation, while learned selectivity improves robustness when frequently retrieved memories remain useful. Across five retrieval-based hosts and three benchmarks, trained AMIE improves downstream F1 or accuracy in all 15 comparisons, by 0.70--3.37 percentage points (up to 25% relative), and improves retrieval in all 10 comparisons. Controlled analyses show that persistent competitor suppression can expose previously unseen evidence, while suppressing repeatedly useful memories creates the complementary failure mode. Together, these results establish persistent memory access as a practical adaptation layer, distinct from the content it serves, in retrieval-based agent memory systems.

## 1. 论文的核心问题与整体含义

- **研究动机**：长程（long-horizon）智能体在长期运行中不断积累经验，但"保留记忆"并不等于"在需要时能够访问到记忆"。有用的经验可能未被删除或改写，但由于后续相似内容的累积，其在检索排名中不断下沉，导致**访问失败**。
- **核心问题**：现有记忆系统通常将**记忆内容演化**（学什么该保留）与**记忆访问演化**（保留的经验如何保持可及）耦合在一起。本文提出将**持久化访问状态更新**分离为一个独立控制的适应层，即"Memory Index Evolution（记忆索引演化）"。
- **整体含义**：两个拥有完全相同存储内容的智能体，由于面对的查询流不同，应当拥有不同的访问状态。在有限的检索上下文中，选择哪些记忆被呈现是具有后果性的；本文的适应目标是**跨查询携带的状态**，而非新的上下文预算或查询时排序器。

## 2. 论文提出的方法论

### 2.1 问题形式化（Section 2）

论文将基于检索的智能体记忆形式化为：

- 内容与索引分离：**M_t = (C_t, I_t)**，其中 C_t 是存储内容，I_t 是索引状态；检索过程为 **S_t = R(q_t; C_t, I_t)**。
- 两条互补的演化轴：
  - **内容演化**：C_{t+1} = G(C_t, O_t)（学什么该保留）；
  - **索引演化**：I_{t+1} = F(I_t, O_t)（保留的经验如何保持可及）。
- 索引演化的目标是最大化**终身查询流上的下游效用**，且必须以前瞻性（prospective）方式评估——即更新对**后续查询**的价值，而非产生该更新的那次交互。

### 2.2 AMIE 框架（Section 3）

AMIE 将更新规则因子化为 **F_θ(I_t, O_t) = T(I_t, π_θ(O_t))**：

 **(1) 检索条件索引策略（π_θ）**
- 策略观察当前查询 q_t 和宿主原生反馈列表 B_t（与答案上下文 S_t 不同），为每个被反馈的记忆预测**抑制概率** p_{θ,i}(O_t)。
- 动作空间：a_i,t ∈ {0, 1}，1 表示"抑制"（增加持久惩罚计数），0 表示"保留"（不清除已有惩罚）。
- **教师蒸馏**：用 GPT-5.6-Sol 作为教师，在离线数据 D 上生成 keep/suppress 标签，然后用**类平衡二元交叉熵**拟合学生策略（Qwen/Qwen3-8B + LoRA + 十槽线性头）。
- 三种策略变体共享状态转换和宿主包装器：
  - **Trained（训练）**：蒸馏学习的选择性动作；
  - **Frozen（冻结）**：直接用提示词让同一骨干输出 mask，无任务微调；
  - **Count（计数）**：零模型调用，对所有反馈记忆执行 a=1，以重复曝光作为干扰代理信号。

 **(2) 有界持久访问动态（T）**
- 底层计数器：n_{i,t+1} = n_{i,t} + a_{i,t}。
- 有界抑制状态：**u_{i,t} = n_{i,t} / (n_{i,t} + κ)**，κ 为半饱和所需的选择事件数；饱和限制惩罚强度。
- 状态通过记忆 ID 持久化，即使记忆离开反馈列表仍然保留。

 **(3) 流内索引演化（Wrapper）**
- AMIE 附着在宿主打分候选接口上，重排序公式：**s_t(q, i) = σ̂(q, i)(1 − λ_p u_{i,t})**，λ_p 限制得分削减比例。
- **后密封更新约束**：先密封答案上下文 S_t，再提交由原生反馈推导出的 mask；只有后续查询使用新状态 u_{t+1}，避免将动作效果记到当前答案上。
- λ_p = 0 时恢复宿主选择，支持匹配比较。

## 6. 论文的主要结论与发现

1. **索引演化提升下游效用**：训练 AMIE 在 15/15 下游比较中提升 0.70–3.37 个百分点（相对最高 +25%）；10/10 检索比较同时改善。
2. **检索流量本身是强信号**：零调用 Count 策略在 LoCoMo BM25 和 MemoryOS 上与冻结策略接近或更优，说明访问频率累积已能解释相当部分增益。
3. **选择性提高鲁棒性**：在 GroupMem MemoryOS 上，训练策略比 Count 高 3.61 点，验证了选择性在"反复有用的记忆"场景中的价值。
4. **持久化状态是增益所在**：置换惩罚或反转方向即消除优势；少量历史即可改善未来检索；类别匹配状态优于换用状态。
5. **干扰而非体积**：近域混叠内容比远域内容造成更大宿主退化；可及 headroom（金标在池中但不在前十）集中了最大增益。
6. **粒度是有条件的风险**：粗粒度记忆单元会降低证据纯度，使 Count 增益趋于零，但并非细粒度存储的普遍要求。

## 8. 不足与局限

- **泛化证据有限**：策略训练/选择在 LoCoMo 上进行，其他基准只验证了"迁移"，未形成独立泛化测试；作者在附录中明确承认这一点。

- **机制分析依赖于标签信息**：多数诊断（如 headroom、gold exposure、hindsight oracle）只能在后验标签下使用，不能直接转化为在线决策规则。
