## 摘要
视觉-语言导航（VLN）要求具身智能体在3D环境中遵循语言指令行进。对基于视觉语言模型（VLM）的流式智能体而言，在长程导航中保持持久情景记忆仍是一项挑战。我们提出MEMVLN，一个流式情景记忆框架，该框架维护一个有界的压缩感知特征库，并以时间步和由动作推导的相对位姿进行标注，同时通过交叉注意力生成紧凑的记忆令牌。我们将所提出的记忆与一个冻结的预训练几何编码器配对使用。为了学习记忆模块，我们设计了一个基于掩码的轨迹摘要任务，并采用多粒度子轨迹分解，鼓励仅从情景记忆中重建路径。在仅使用官方R2R/RxR轨迹进行导航训练的条件下，MEMVLN在标准VLN-CE基准的大多数报告指标上取得了最先进的性能。长程分析进一步刻画了情景记忆在何种情况下有用。在物理评测中，我们在一个物理场景中收集了30个受指令约束的回合，使用其中24个作为后训练演示，并保留6个进行测试。在保留的回合上，MEMVLN将成功率从VLM基线的17%提高到40%，后训练进一步将其提升至47%。

## Abstract
Vision-language navigation (VLN) requires an embodied agent to follow language instructions through 3D environments. Maintaining persistent episodic memory remains a challenge for VLM-based streaming agents in long-horizon navigation. We present MEMVLN, a streaming episodic memory framework that maintains a bounded bank of compressed perceptual features annotated with timesteps and action-derived relative poses, and produces compact memory tokens via cross-attention. We pair the proposed memory with a frozen pretrained geometry encoder. To learn the memory module, we design a masking-based trajectory summarization task with multi-granularity sub-trajectory decomposition, encouraging route reconstruction exclusively from episodic memory. Under navigation training restricted to the official R2R/RxR trajectories, MEMVLN achieves state-of-the-art performance on most reported metrics on standard VLN-CE benchmarks. Long-horizon analyses further characterize when episodic memory is useful. For physical evaluation, we collect 30 instruction-conditioned episodes in one physical scene, use 24 as demonstrations for post-training, and hold out six for testing. On the held-out episodes, MEMVLN improves success over the VLM baseline from 17% to 40%, and post-training further raises it to 47%.

## 1. 论文的核心问题与整体含义

**核心问题**：视觉-语言导航（VLN）中，基于视觉语言模型（VLM）的流式智能体在长程导航任务中难以维持持久的**情景记忆**。随着导航序列的推进，早期观测信息（如地标、门廊、转弯决策依据）会逐渐丢失或被截断，导致智能体在需要回溯、识别已见环境或执行复杂多步指令时性能下降。

**研究动机与背景**：
- 现有 VLM 流式导航方法通常只保留有限的近期观测窗口，缺少对整条导航轨迹的紧凑、可查询总结。
- 早期递归方法将历史压缩进隐藏状态，但表达能力有限；显式记忆方法（如拓扑图、全景观测特征库）往往依赖全景观测或外部地图，难以直接适配单目流式视频输入。
- 已有流式记忆工作（如 JanusVLN）仍存在容量限制，且在长程指令和复杂场景中的增益尚未充分刻画。

**整体含义**：论文提出一种**即插即用的有界情景记忆模块**，使 VLM 在几乎不增加随路径长度线性增长的计算负担下，持续携带整条轨迹的压缩视觉证据，从而在标准 VLN 基准和真实机器人测试中显著提升导航成功率。核心思想是“记忆不是越长越好，而是要以紧凑且有界的形式保留关键语义”。


## 2. 方法论

MemVLN 的核心由四部分构成：**有界记忆库**、**记忆感知器**、**冻结几何编码器**与**多粒度轨迹摘要监督**。

### 2.1 有界记忆库（Memory Bank）
- 输入观测 \(o_t\) 经 Qwen3-VL 的视觉编码器得到 patch 特征 \(f_t\)，连同**时间戳 \(t\)** 和**由动作推导的相对位姿 \(z_t\)** 存入记忆库。
- 位姿 \(z_t\) 包含相对起点的位置 \((x,y)\) 和朝向 \((\cos\theta, \sin\theta)\)；推理时仅由已执行动作的航迹推算得到，不使用真值位姿或外部里程计。
- 当记忆库达到容量上限 \(N_b=100\) 时，对**平均 patch 级余弦相似度最高**的两个连续帧进行合并，实现有界压缩。

### 2.2 记忆感知器（Memory Perceiver）
- 对库中特征先进行**空间下采样**（ToMe，每帧最多保留 \(N_f=100\) 个 token）。
- 为特征和可学习查询分别加入**正弦时间嵌入**与 **Fourier 空间特征**：
  \[
  \bar{f}^+_{1:t} = \bar{f}_{1:t} + \text{sinusoid}(1:t) + \text{Fourier}(z_{1:t})
  \]
  \[
  q^+ = q + \text{sinusoid}(t) + \text{Fourier}(z_t)
  \]
- 经两层交叉注意力，将可变长度的记忆库压缩为**固定大小** \(N_m=300\) 的记忆令牌 \(m_t\)：
  \[
  m_t = \text{cross-attn}(q^+, \bar{f}^+_{1:t})
  \]

### 2.3 VLM 输入结构
- 除记忆令牌外，模型同时输入**近期历史令牌** \(h_t^{hist}\)（最多 16 帧窗口）和**当前观测令牌** \(h_t\)。
- 最终多模态输入序列为：
  \[
  [P_{mem}, m_t, P_{hist}, h_t^{hist}, P_{curr}, h_t, T, a_t]
  \]
- 记忆令牌与几何特征共同进入冻结的 Qwen3-VL 的 LLM 部分，仅通过 LoRA 适配。

### 2.4 冻结几何编码器
- 使用预训练的 **StreamVGGT-1B** 提取同一观测上下文的相机令牌，经轻量可训练适配器与视觉特征融合，产生局部混合令牌 \(H_t\)。该设计补充 VLM 的空间理解能力。

### 2.5 多粒度轨迹摘要监督
- **掩码轨迹摘要任务**：将同一导航轨迹的指令 \(T\) 作为摘要标签；对局部视觉令牌 \(H_t\) 全部掩码，仅保留记忆令牌 \(m_t\) 作为视觉证据，迫使模型从情景记忆中重建导航语义：
  \[
  \mathcal{L} = -\log p(T \mid m_t, T^{(\text{TS})})
  \]
- **子轨迹分解**：利用 FGR2R 的子指令和路径点标注，将完整轨迹映射到连续环境中的子轨迹，提供多粒度、细粒度的摘要监督。

## 6. 主要结论与发现

- 在仅使用官方 R2R/RxR 轨迹训练的前提下，**MemVLN 在标准 VLN-CE 基准的大多数指标上达到 SOTA**：
  - R2R：SR 55.0%（+2.2pp over JanusVLN）、SPL 50.5%

- **RxR 的增益大于 R2R**，表明记忆在更长、更复杂的指令下更有价值。
- **长程分析**显示，记忆在“非常复杂”指令（SR 40.5%→49.1%）和“回溯”类指令（SR 43.2%→52.8%）中增益最大。
- **组件贡献**：记忆提供路线级语义，几何编码器补充空间感知，轨迹摘要监督信令让记忆真正学会保留与导航语义相关的证据。
- **物理验证**：真实场景下成功率从 17%→40%（完整 MemVLN），后训练后 47%；验证了框架的部署可行性。


## 7. 优点

- **即插即用的有界记忆设计**：记忆令牌数量固定（300），不随路径长度增长，兼顾计算效率与长期上下文。
- **双层证据融合**：短期窗口负责细粒度局部感知，记忆库负责长期路线级证据，形成互补。
- **指令无关的记忆检索**：记忆通过时间戳和动作推导位姿进行查询，由 LLM 进行指令条件化解释，设计解耦清晰。
- **新颖的多粒度轨迹摘要监督**：用掩码迫使记忆成为唯一视觉证据，比一般辅助任务更具针对性；子轨迹分解提供了多时间尺度信号。
- **无外部数据下的公平比较**：在严苛的“官方轨迹限制”条件下达到 SOTA，避免了数据规模带来的混淆。
- **兼顾 Sim2Real**：在物理机器人上进行了真实论证，并给出后训练和安全性指标（碰撞率）。


## 8. 不足与局限

- **推理时记忆合并与检索是指令无关的**：有界记忆库在长路线中可能丢弃任务关键观测，缺乏任务感知的保留策略。
- **物理实验规模有限**：仅覆盖单个场景、6 条保留指令、每指令 5 次重复；碰撞率仍高达 46.7%，跨场景泛化和安全性改进未被系统验证。
- **训练策略探索有限**：轨迹摘要虽是有效监督，但更广泛的记忆学习策略（如未来动作预测、任务感知剪枝）尚未探索。
- **计算开销不可忽略**：完整模型推理延迟较基线增加约 37%，在实时低延迟机器人场景中可能需要进一步优化。
- **检索与合并策略依赖相似度启发式**：合并规则基于 patch 级余弦相似度，可能对语义上不相似但视觉上相似的帧产生误合并。
