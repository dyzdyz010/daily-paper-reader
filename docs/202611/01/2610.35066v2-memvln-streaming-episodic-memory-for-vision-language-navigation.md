## 摘要
视觉语言导航（VLN）要求具身智能体在三维环境中遵循语言指令。对于基于 VLM 的流式智能体而言，在长程导航中保持持久的情景记忆仍是一项挑战。我们提出 MEMVLN，一种流式情景记忆框架，该框架维护一个有界的压缩感知特征库，并以时间步和由动作推导的相对位姿进行标注，同时通过交叉注意力生成紧凑的记忆令牌。我们将所提出的记忆与一个冻结的预训练几何编码器配合使用。为了学习记忆模块，我们设计了一种基于掩码的轨迹摘要任务，并进行多粒度子轨迹分解，促使仅从情景记忆中重建路径。在仅使用官方 R2R/RxR 轨迹进行导航训练的情况下，MEMVLN 在标准 VLN-CE 基准的大多数报告指标上取得了当前最优性能。长程分析进一步刻画了情景记忆在何种情况下有用。在物理评测中，我们在一个物理场景中采集了 30 个受指令约束的片段，使用其中 24 个作为后训练演示，并保留 6 个用于测试。在保留片段上，MEMVLN 将成功率从 VLM 基线的 17% 提高到 40%，后训练进一步将其提升至 47%。

## Abstract
Vision-language navigation (VLN) requires an embodied agent to follow language instructions through 3D environments. Maintaining persistent episodic memory remains a challenge for VLM-based streaming agents in long-horizon navigation. We present MEMVLN, a streaming episodic memory framework that maintains a bounded bank of compressed perceptual features annotated with timesteps and action-derived relative poses, and produces compact memory tokens via cross-attention. We pair the proposed memory with a frozen pretrained geometry encoder. To learn the memory module, we design a masking-based trajectory summarization task with multi-granularity sub-trajectory decomposition, encouraging route reconstruction exclusively from episodic memory. Under navigation training restricted to the official R2R/RxR trajectories, MEMVLN achieves state-of-the-art performance on most reported metrics on standard VLN-CE benchmarks. Long-horizon analyses further characterize when episodic memory is useful. For physical evaluation, we collect 30 instruction-conditioned episodes in one physical scene, use 24 as demonstrations for post-training, and hold out six for testing. On the held-out episodes, MEMVLN improves success over the VLM baseline from 17% to 40%, and post-training further raises it to 47%.

## 2. 论文提出的方法论

### 2.1 整体架构

- 基于 **Qwen3-VL-4B** 的原生视觉编码器（SigLIP-2）和 LLM，同时引入一个冻结的 **StreamVGGT-1B** 几何编码器，以及一个可训练的**记忆模块**。
- 导航时，模型接收当前 RGB 观测和近期观测窗口（最多 16 帧）作为短时上下文，并通过记忆模块读取整个 episode 的压缩历史。
- 动作输出为文本形式，包含动作类型（前进、左转、右转、停止）和动作尺度（如前进 25/50/75 cm，转向 15/30/45 度）。

### 2.2 记忆模块

- **记忆库（Memory Bank）**：
  - 每一步将当前观测的视觉特征 \(f_t\) 加入一个 episode 专属记忆库。
  - 同时存储该帧的**时间步**和**由动作推导的相对位姿** \(z_t\)（位置 \(x,y\) 和朝向 \(\cos\theta,\sin\theta\)）。
  - 相对位姿在推理时仅由已执行的动作历史推算，不使用真值位姿或外部里程计。
  - 当记忆库达到容量上限（默认 \(N_b=100\)）时，采用相似度合并策略，将相邻帧中平均 patch 余弦相似度最高的两帧合并，以保持有界表示。

- **记忆感知器（Memory Perceiver）**：
  - 先用 **ToMe** 对每帧 patch 特征进行空间下采样（默认每帧最多 \(N_f=100\) 个 token）。
  - 对记忆库特征和可学习 query 分别注入时间正弦嵌入与 Fourier 空间特征，使模型感知时间和空间位置。
  - 通过交叉注意力，将可学习 query 与记忆库特征交互，得到固定数量（默认 \(N_m=300\)）的记忆 token \(m_t\)。
  - 这些记忆 token 与近期观测 token、任务指令一起送入 LLM 进行自回归动作预测。

- **与几何编码器的融合**：
  - 使用冻结的 StreamVGGT 提供相机 token 表示，通过轻量可训练 adapter 与视觉特征融合，形成混合 token \(H_t = [h_t^{hist}, h_t]\)。
  - 记忆 token、历史观测 token、当前观测 token 和任务指令按固定顺序组成多模态输入。

### 2.3 训练任务与损失

- **导航任务**：使用交叉熵损失监督模型预测真实动作。
- **轨迹摘要任务**：
  - 将导航指令 \(T\) 作为摘要标签。
  - 在摘要训练中，将局部视觉 token \(H_t\) 全部掩码，仅保留记忆 token \(m_t\) 作为视觉证据，迫使模型仅从情景记忆中重建路线语义。
  - 进一步利用 FGR2R 子指令/航点标注，将完整轨迹分解为多个子轨迹，进行多粒度摘要监督。
- **训练数据**：仅使用官方 R2R 和 RxR 训练轨迹，不引入额外导航轨迹或外部多模态微调数据。

## 6. 论文的主要结论与发现

- MemVLN 通过有界、时间/位姿标注的情景记忆，能够显著提升流式 VLM 在 VLN 中的长程导航能力。
- 在仅使用官方 R2R/RxR 训练轨迹的设置下，MemVLN 在 R2R 和 RxR 的多数指标上达到当前最优。
- 记忆模块在指令复杂度更高、需要回溯、存在停止条件或需要经过地标的任务中增益更大，说明情景记忆对长程推理和重访已观察区域尤为重要。
- 几何编码器和轨迹摘要训练对记忆学习有互补作用：几何特征提升空间感知，掩码轨迹摘要迫使记忆保留路径语义。
- 在物理机器人上，MemVLN 较 VLM 基线成功率从 16.7% 提升至 40.0%，后训练进一步至 46.7%，验证了方法的实用潜力。
- 尽管成功率提升，碰撞率仍然较高（46.7%），说明安全、细粒度空间定位仍是待解决问题。

## 7. 优点

- **问题定位清晰**：针对流式 VLN 中缺乏持久记忆这一关键瓶颈，提出了系统性的解决方案。
- **记忆设计巧妙**：
  - 有界记忆库 + 相似度合并 + ToMe 下采样 + 固定数量记忆 token，既保留长期证据，又控制计算成本不随路径长度增长。
  - 时间步和动作推导位姿的注入，使记忆具有时空基础。
  - 指令无关的 readout 设计让记忆成为通用的情景记录，交由下游 LLM 做指令条件解释。
- **训练策略有效**：
  - 掩码轨迹摘要任务是一种有效的自监督辅助信号，强制记忆捕获路径级语义。
  - 多粒度子轨迹分解进一步细化记忆学习。
- **实验设计严谨**：
  - 限制训练数据为官方轨迹，与 JanusVLN 等公平对比，同时清晰标注其他方法的额外数据量。
  - 包含长程分析、指令类型细分、物理部署和延迟评估，验证维度较全面。
- **可插拔性**：记忆模块可作为插件集成到现有流式 VLM，无需修改底层 LLM 架构。

## 8. 不足与局限

- **物理实验覆盖有限**：
  - 仅在 1 个物理场景中评测 6 条保留指令，样本量小，统计意义有限。
  - 未测试跨场景泛化能力。
  - 碰撞率仍较高（46.7%），后训练并未降低碰撞率。
- **记忆检索与合并指令无关**：
  - 记忆库的相似度合并和 readout 不依赖指令，可能在长 episode 中丢弃对当前任务重要的观测。
  - 未来需要任务感知的合并/检索策略。
- **轨迹摘要监督探索不足**：
  - 虽然轨迹摘要有效，但更广泛的训练策略仍未被充分研究。
