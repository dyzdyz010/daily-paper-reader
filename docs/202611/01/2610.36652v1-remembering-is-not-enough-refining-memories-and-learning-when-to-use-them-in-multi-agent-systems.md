## 摘要
记忆帮助基于大语言模型的多智能体系统复用经验，但存储的建议可能存在缺陷或被用于错误情境。仅凭团队层面的成功或失败无法可靠地表明某条记忆需要修正或本不应被使用。我们提出 DiscernMem，一个无需训练的框架，可同时提升记忆质量和记忆使用。为提升质量，缺陷感知记忆精炼（DMR）将团队执行与仅使用单条记忆和不使用记忆的情况进行比较，诊断规则缺陷，并在当前及先前任务上测试修复方案，以避免丢失先前有用的行为。为引导恰当使用，边界学习元记忆（BLM）记录每条记忆的过往使用情况及效果，基于任务上下文和传入消息学习其拥有者角色应在何时应用或避免该记忆。这些组件共同帮助团队修正有缺陷的经验，同时保留那些被错误应用的有用规则。在四个基准上使用 Qwen3-4B-Instruct-2507 的实验表明，DiscernMem 在 AutoGen、CAMEL 和 MacNet 上取得最高平均分，比已报告的最强基线高出 0.51-4.32 分。它在所有三个系统的代码生成和符号规划上处于领先地位，包括在 CAMEL 上 PDDL 得分为 37.71，而对照为 28.48。

## Abstract
Memory helps LLM-based multi-agent systems reuse experience, but stored advice can be flawed or applied in the wrong situation. Team-level success or failure alone cannot reliably show whether a memory needs correction or should not have been used. We propose DiscernMem, a training-free framework that improves both memory quality and memory use. To improve quality, Defect-Aware Memory Refinement (DMR) compares team executions with a single memory and with no memory, diagnoses rule defects, and tests repairs on current and earlier tasks to guard against losing previously useful behavior. To guide appropriate use, Boundary-Learning Meta-Memory (BLM) records each memory's past uses and effects, learning when its owner role should apply or avoid it based on task context and incoming messages. Together, these components help teams correct flawed experience while retaining useful rules that were applied incorrectly. Experiments with Qwen3-4B-Instruct-2507 on four benchmarks show that DiscernMem achieves the highest average score on AutoGen, CAMEL, and MacNet, exceeding the strongest reported baselines by 0.51-4.32 points. It leads on code generation and symbolic planning across all three systems, including a PDDL score of 37.71 versus 28.48 on CAMEL.

- **研究意义**：可靠的自适应需要同时学习“哪些记忆有用”和“何时应该使用它们”。已有方法多聚焦于记忆组织、检索或效用评分，较少区分“内容缺陷”与“情境误用”这两种根本不同的失败模式。
- **目标**：提出一个免训练框架 DiscernMem，分别改进记忆质量（修正错误规则）和记忆使用（学习使用/避免条件）。

## 2. 论文提出的方法论

- **总体框架**：DiscernMem 是一个训练免费的框架，不修改模型参数或协作结构，包含两个核心模块：
  - **缺陷感知记忆精炼（DMR）**：评估并修复角色拥有的行为规则。
  - **边界学习元记忆（BLM）**：从重用历史中学习每条记忆的使用/避免条件。

- **记忆表示**：每条记忆 \(m^{v}_{i}\) 包含：
  - 拥有者角色 \(r_i\)；
  - 行为规则正文 \(b^{v}_i\)；
  - 元记忆 \(\mu^{v}_i = (C^{v}_{i,\text{use}}, C^{v}_{i,\text{avoid}}, E^{v}_i, P^{v}_i)\)，其中 \(C\) 为使用/避免条件，\(E\) 为效果记录，\(P\) 为历史修正记录。

- **DMR——缺陷感知记忆精炼**：
  - **配对重放评估**：对同一条任务，在相同配置和种子下，分别执行“仅向拥有者提供该记忆”和“不向任何角色提供记忆”的完整协作，计算孤立注入效应：
    \[\Delta^{v}_i(q) = s(q;m^{v}_i) - s(q;\emptyset)\]
    其中 \(s(q;\emptyset)\) 为无记忆得分。\(\Delta > \epsilon\) 为正效应，\(< -\epsilon\) 为负效应，否则中性。
  - **缺陷与误用诊断**：先根据当前使用/避免条件判断是否在范围内；若为负效应且在范围内，则进行内容诊断，由 LLM 比较配对轨迹，识别具体规则缺陷（缺失步骤、错误顺序、错误停止条件等）。诊断结果分为：
    - `SCOPE`：应在范围外使用，归因于适用性问题；
    - `CONTENT`：内容存在可支持的规则缺陷；
    - `NONE`：证据不充分，不改动正文。
  - **证据引导修复与跨任务验证**：对 `CONTENT` 类问题，修复 LLM 基于触发轨迹证据和源轨迹提出局部编辑。候选修复需在触发任务、保留集 \(H_1\)（早期正效应任务）和相关集 \(H_2\)（相似任务）上满足非回归约束：
    \[s(h;c) \ge \max\{s(h;m^{v}_i), s(h;\emptyset)\} - \epsilon\]
    且失败次数不增加：\(F(c) \le F(m^{v}_i)\)。
  - **更新策略**：通过的候选成为新版本，版本状态重置为 provisional；多次失败则保留原体并标记 inactive。

- **BLM——边界学习元记忆**：
  - **适用性边界学习**：对范围误用，LLM 识别可观测异常条件 \(\phi_u\)，添加到避免条件；对多个正效应任务，LLM 泛化其上下文，添加到使用条件（至少 \(n^+\) 个不同正任务）。
  - **生命周期管理**：根据效果记录和修复结果，将记忆标记为 provisional、active 或 inactive。积极证据促进提升；持续有害、长期无效或修复失败导致停用；被误判的范围伤害不计入持续伤害。
  - **角色特定检索**：按角色过滤、嵌入相似度排序、LLM 相关性选择后注入。检索结果受生命周期状态影响，但不直接使用效果分数加权。

- **任务周期流程**：任务先用已积累记忆执行并评分；评分后再更新记忆。任务后重放的分数不替换原始任务得分。

## 7. 优点

- **概念清晰**：明确区分“规则缺陷”与“情境误用”，回应了多智能体记忆中常被忽视的细粒度问题。
- **方法创新**：
  - 用配对重放估计单条记忆的孤立团队效应，减少联合结果对记忆质量判断的混淆；
  - 修复验证在触发任务和历史上检查非回归，避免“修正一个错误却破坏原有能力”；
  - 元记忆以可观测前置上下文为基础，学习角色特定的使用/避免条件。
- **训练免费**：不改变模型参数或协作结构，易与现有多智能体系统集成。
- **实验较为全面**：跨三类任务、三种架构，对比多个强基线，并提供了消融与敏感性分析。
- **可解释性**：提供了具体案例研究，展示相同负面信号下两种不同归因与处理方式。

## 8. 不足与局限

- **环境依赖**：所有证据来自配对重放，需要任务可重复执行、可自动评分；开放式生成、人类判定、不可逆动作场景无法直接使用。
- **计算开销**：重放会增加额外执行，且数量随记忆数量和修复尝试增长，成本较高。
- **单记忆隔离假设**：每条记忆被单独评估和修复；依赖多角色规则协同才能发挥作用的记忆可能被误判为无效或有害，且无法处理跨角色规则交互导致的失败。
- **边界不可收缩**：使用/避免条件只增不删，且避免条件优先于使用条件；一旦避免条件过宽，后续正效应也无法推翻它，质量受骨干 LLM 判断能力限制。
- **QA 效果有限**：二元结果导致大量中性配对效应，证据积累慢；行为规则也无法补充模型缺失的事实知识，因此 QA 收益不如程序性任务稳定。
- **实验稳健性**：每个设置仅单次运行，未报告方差；仅测试 Qwen3-4B 一个骨干模型，未验证模型规模或家族变化下的稳定性。

## 9. 总体评价与适用边界

- **总体判断**：DiscernMem 在“可复现、可自动评分的程序性任务”上提出了一个清晰且实用的记忆治理框架。它没有试图用一个统一分数或单一检索策略去处理所有记忆问题，而是将记忆失效区分为**内容缺陷**与**情境误用**，并分别配置修复与边界学习机制。这一思路比多数“只按效用排序或只做记忆精炼”的方法更贴近多智能体系统中经验复用的真实失败模式。

- **方法定位**：该方法的价值主要体现在**模块化、训练免费、可解释**。它不改变宿主系统的协作结构或模型参数，而是作为记忆管理层嵌入现有系统，因此具有较好的可移植性。其元记忆以可观测上下文为条件，使用/避免边界可被人类检查，便于审计和调试。

- **适用场景**：  
  - 适合任务可重复执行、有明确自动评分或单元测试的场景，如代码生成、符号规划、可验证问答。  
  - 适合行为规则可以被自然语言描述、且单条规则能通过注入/移除观察到团队效果变化的任务。  
  - 适合经验长期积累、同一类任务反复出现、需要从失败中持续细化规则边界的系统。

- **不适用或需改造的场景**：  
  - 开放式对话、创造性写作、人类主观评分、不可逆环境动作等难以进行低成本配对重放的场景。  
  - 记忆之间存在强耦合、跨角色协同不可拆分的系统，单记忆隔离评估可能产生误判。  
  - 需要快速响应、无法承担额外重放执行开销的在线系统。

- **未来工作方向**：  
  1. **降低重放成本**：研究基于轨迹缓存、部分重放或近似效应估计的方法，减少每条记忆更新时的执行负担。  
  2. **支持记忆协同评估**：允许多条记忆联合评估，避免单记忆隔离假设对协同型规则的伤害。  
  3. **边界可收缩与修正**：当前使用/避免条件只增不删，未来可引入边界修剪或反例驱动的条件收缩机制。  
  4. **增强统计稳健性**：补充多次运行、多随机种子、多骨干模型规模的实验，报告方差或置信区间。  
  5. **扩展到弱监督信号**：探索在部分自动评分缺失时，利用人类反馈、代理指标或主动采样来驱动记忆更新。

- **结语**：DiscernMem 为多智能体系统的持久记忆管理提供了一种更细粒度的故障诊断视角，并在多个主机和任务上验证了其有效性。它更适合作为可复现、可评分场景下的记忆治理基础组件，而非通用、零成本的即插即用方案；但其“内容修复”与“使用边界学习”分离的思路，对后续研究具有明确的启发意义。
