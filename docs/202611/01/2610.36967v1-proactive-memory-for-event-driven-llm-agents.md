## 摘要
主动大语言模型智能体从持续观察和积累的历史中预测服务机会。现有方法侧重近期上下文或相关记忆检索，对于验证反复出现的行为规律并评估其对当前事件的适用性支持有限。我们提出主动记忆（ProactMem），将历史组织为近期事件、时间轨迹和行为规律。轨迹事实会与源事件核对，规律通过历史重放进行评估，再与当前条件匹配。我们还构建了 ProactiveStream，一个覆盖三个应用范围的纵向基准，其中智能体按时间顺序处理孤立的事件流，并在片段感知的机会标签下进行。在 ProactiveStream 上，ProactMem 的总体有效性（F1）达到 52.6%，比五个外部基线中最强的方法相对提升 21.4%。代码见：https://anonymous.4open.science/r/ProactMem-5351/。

## Abstract
Proactive LLM agents anticipate service opportunities from ongoing observations and accumulated history. Existing approaches emphasize recent context or retrieval of related memories, providing limited support for validating recurring behavioral regularities and assessing their applicability to the current event. We propose Proactive Memory (ProactMem), which organizes history into recent events, temporal trajectories, and behavioral regularities. Trajectory facts are checked against source events, and regularities are assessed through historical replay before being matched to current conditions. We also construct ProactiveStream, a longitudinal benchmark covering three application scopes, where agents process isolated event streams chronologically under episode-aware opportunity labels. On ProactiveStream, ProactMem achieves an overall effectiveness (F1) of 52.6%, a 21.4% relative improvement over the strongest of five external baselines. Code is available at: https://anonymous.4open.science/r/ProactMem-5351/.

## 1. 论文的核心问题与整体含义

- **研究背景**：LLM 智能体正从被动任务执行向主动辅助扩展，需要在持续观察和积累历史中识别服务机会，例如在运动支持、智能家居、软件协作等场景中主动给出提醒、建议或维护操作。
- **核心问题**：现有方法主要依赖近期上下文或检索相关记忆片段，但对**反复出现的行为规律缺乏验证**，也难以判断这些规律是否**适用于当前事件**。论文提出的中心问题是：**智能体如何将积累的历史转化为可靠证据，以决定何时提供主动帮助**。
- **整体含义**：论文通过提出 **ProactMem（Proactive Memory）**，将历史组织为近期事件、时间轨迹和行为规律三个层次，并用轨迹事实与源事件核对、历史重放评估规律，最终在事件到来时结合当前条件进行干预决策。此外，论文构建了纵向事件流基准 **ProactiveStream**，以评估主动服务机会检测能力。

## 2. 论文提出的方法论

### 2.1 三层记忆结构

- **有界事件记忆（Bounded Event Memory）**：保留最近 72 小时内、最多 99 个先前的公共事件（容量 K=100，当前事件单独提供），用于捕获即时变化；同时保留当天所有已提交事件用于后续轨迹构建。
- **经事实验证的时间轨迹记忆（Fact-validated Temporal Trajectory Memory）**：
  - 每个本地日结束时，LLM 将当天事件总结为轨迹片段（包含时间区间、类型化事实和来源引用）。
  - 通过**源一致性验证**约束轨迹：要求轨迹中的可检查事实必须来自同一天同一实体的已完成事件，且实体、区间、引用和规范化的标量值均需匹配（公式：\(F(d) \subseteq \bigcup_{e \in E(d)} F(e)\)）。
  - 验证不通过的细节不会进入轨迹，从而避免错误事实传播到后续规律提取中。
- **经重放评估的行为规律记忆（Replay-assessed Behavioral Regularity Memory）**：
  - 每周整合七个已完成的每日记录，LLM 提出规律候选（触发条件、预期行为、时间窗口、可选工作日限制、来源日期）。
  - **历史重放**：在已验证的日事实中检查触发条件下行为是否发生；满足记为 fulfilled（支持天），未满足记为 violated（违反天），缺失观测记为 censored，不适用的日期排除。
  - 计算两个指标：
    \[
    conf_{\text{replay}} = \frac{n_f}{n_f + n_v}, \quad lift = \frac{conf_{\text{replay}}}{base(p)}
    \]
    其中 base(p) 是相同时间/工作日限制下预期行为在所有可观测日中的基线频率。
  - 只有满足 **支持天数 \(n_f \ge 3\)、置信度 \(\ge 0.5\)、提升度 \(\ge 1.0\)** 的规律才被激活并可用于检索。
  - 后续观测会更新规律置信度和生命周期（如 active、weakening、dormant 状态转换）。

### 2.2 检索与决策流程

- **检索**：当前事件到来时，事件记忆提供最近事件序列；轨迹记忆提供当前周期内已完成的时间轨迹；规律记忆仅选择**触发条件匹配、时间适用、且未被满足或未被删失**的规律（最多前 3 条）。
- **决策上下文**：将当前事件、近期事件、时间轨迹、选中的规律和可观测的服务机会状态组合为上下文 \(C_t\)；LLM 基于该上下文提出干预（intervene）或弃权（abstain），并给出基于证据的服务消息。
- **干预控制**：控制器将新的服务提案与已允许的干预进行比较，去除重复提案；仅在机会状态、服务身份、情境规律或本地日发生变化时允许重新评估。决策完成后才将事件提交到记忆，避免未来信息泄漏。

## 3. 实验设计

### 3.1 基准数据集：ProactiveStream

- **三个场景（scope）**：
  - **Sports**：HeartSteps 移动活动数据，9 个参与者流，1,456 个事件，367 个观测参与者日，365 个参考干预。
  - **Home**：CASAS 智能家居传感器数据，4 个家庭，14 个连续日/家，1,624 个事件，190 个参考干预。
  - **Code**：GitHub 公开仓库活动（GH Archive），4 个仓库，1,459 个事件，174 个参考干预。
- **总体规模**：17 个孤立事件流，4,539 个输入事件，729 个参考干预。
- **标签设计**：参考干预标签由三名标注员独立标注后交叉审查和仲裁；事件只有在满足：
  - \(A\)：当前事件本身提供足够证据，或
  - \(B\)：结合完整先前历史后机会成立，
  - 且属于**新片段（novel episode）**时，才被标记为 intervene。
  - 后续覆盖窗口标为 abstain；当支持增强、服务变化或片段重开时，机会可被重新激活。
- **评估指标**：相关性（precision）、覆盖率（recall）、有效性（F1）、侵入率（intrusion / false positive rate）、平衡准确率（balance），以及干预频率（frequency）。

## 6. 论文的主要结论与发现

- **总体性能**：ProactMem 在 ProactiveStream 上总 F1 达到 **52.6%**，比五个外部基线中最强的方法相对提升 **21.4%**。
- **场景表现**：
  - Sports：ProactMem 更选择性，相关性和侵入率优于 Mem0，但覆盖率略低于 Mem0。
  - Home：ProactMem 覆盖率最高，且侵入率低于高频基线 A-MEM 和 Graphiti。
  - Code：ProactMem 覆盖率最高，Mem0 侵入率更低但机会恢复大幅降低。
- **分层记忆的价值**：在仅事件记忆基础上加入轨迹记忆提高机会恢复（尤其 Code），完整层级进一步提高 F1 并降低侵入率。
- **验证机制的重要性**：去掉重放门控或轨迹验证都会降低相关性和有效性；重放门控的移除导致最大有效性下降。
- **模型敏感性**：更强的 LLM 能同时提高有效性和降低侵入率。

## 7. 优点

- **分层证据管理**：将近期上下文、来源验证的时间轨迹和重放评估的行为规律结合，适合长时事件流中的主动决策。
- **可验证性设计**：轨迹事实必须与源事件一致，规律必须通过历史重放的支持度、置信度和提升度筛选，减少了记忆幻觉和不稳定规律。
- **统一干预控制**：所有方法共享相同干预控制器，使比较更公平，且控制重复服务，降低误报。
- **多维基准**：ProactiveStream 覆盖三个差异较大的应用场景，且设计为因果回放、流级隔离、片段感知标签，贴近真实纵向服务场景。
