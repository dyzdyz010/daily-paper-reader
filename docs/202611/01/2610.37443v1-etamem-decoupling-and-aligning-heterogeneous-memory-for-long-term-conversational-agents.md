## 摘要
长期记忆使大型语言模型（LLMs）能够在长期对话中保持连贯且个性化的交互。然而，现有记忆系统面临两大关键挑战：（1）信息纠缠，即异构信息混杂在粗粒度记忆单元中；（2）组织失配，即主要基于语义相似度的记忆结构可能忽略其他关联。为解决这些挑战，我们提出 ETAMem，一个多视图记忆框架，解耦异构对话信息，并使记忆表示和组织与其独特特征对齐。具体而言，异构信息解析提取原子记忆单元并识别情感信息。随后，按视图的记忆构建将这些单元组织成三个互补的层次化视图：事件、情感和时间。ETAMem 通过自适应校准阈值增量维护记忆结构。在检索方面，基于熵的检索在各视图间分配查询特定的预算，并在每个视图内执行层次化搜索。在 LoCoMo 和 LongMemEval-S 上的实验表明，ETAMem 优于当前最优基线，分别实现了 12.46% 和 7.96% 的相对准确率提升，同时保持了有竞争力的 token 效率。进一步分析展示了不同记忆视图的互补优势。

## Abstract
Long-term memory enables Large Language Models (LLMs) to maintain coherent and personalized interactions across extended conversations. However, existing memory systems face two key challenges: (1) Information Entanglement, where heterogeneous information is mixed within coarse-grained memory units; and (2) Organizational Mismatch, where memory structures based primarily on semantic similarity may overlook other associations. To address these challenges, we propose ETAMem, a multi-view memory framework that decouples heterogeneous conversational information and aligns memory representations and organization with its distinct characteristics. Specifically, heterogeneous information parsing extracts atomic memory units and identifies affective information. View-specific memory structuring then organizes these units into three complementary hierarchical views: Event, Affect, and Time. ETAMem incrementally maintains memory structures with adaptively calibrated thresholds. For retrieval, entropy-based retrieval allocates query-specific budgets across views and performs hierarchical search within each view. Experiments on LoCoMo and LongMemEval-S demonstrate that ETAMem outperforms state-of-the-art baselines, achieving relative accuracy improvements of 12.46% and 7.96%, respectively, while maintaining competitive token efficiency. Further analyses demonstrate the complementary benefits of different memory views.

## 1. 核心问题与整体含义

- **研究背景**：长期记忆使大语言模型（LLMs）能够在长时间、多轮对话中保持连贯性和个性化。个性化对话智能体在 Web 服务中日益普及，因此对长期用户建模的需求不断增强。
- **现有问题**：
  1. **信息纠缠（Information Entanglement）**：现有记忆系统通常把对话中的事实、偏好、时间等异构信息混合在较粗粒度的记忆单元中，检索时难以分离相关证据，容易引入噪声。
  2. **组织失配（Organizational Mismatch）**：多数记忆结构以语义相似度为核心，忽略其他关联，例如情感偏好可能因只按主题组织而被分散到不同分支。
- **整体含义**：不同信息类型需要不同的表示方式和组织原则。论文受认知神经科学中“情景记忆与情绪处理存在功能专门化但又相互作用的系统”启发，提出 **ETAMem**，目标是对异构对话信息进行解耦，并使记忆表示与组织结构同信息特性对齐。

## 2. 方法论

- **总体框架**：ETAMem 是一个多视图记忆框架，将记忆组织为三个互补的层次化视图：**事件视图（Event View）**、**情感视图（Affect View）**、**时间视图（Time View）**。
- **异构信息解析**：
  - 使用 LLM 将每一轮对话分解为语义完整的**原子记忆单元（Atomic Memory Units, AMUs）**，每个 AMU 表达一个独立记忆项。
  - 使用现成情感分类器（Twitter-RoBERTa-Sentiment）为每个 AMU 分配情感极性标签：`negative`、`neutral`、`positive`。
- **视图特定记忆构建**：
  - **AMU 表示**：中性 AMU 使用文本编码器 `φ_text`；积极/消极 AMU 使用情感编码器 `φ_affect`（RoBERTa-GoEmotions）。
  - **Event View**：按文本语义相似度组织中性 AMU，捕获重复事件、实体和交互。
  - **Affect View**：按情感语义组织积极和消极 AMU，捕获持续性偏好和态度。
  - **Time View**：按时间层级 `Session → Day → Week → Month` 组织所有 AMU，不依赖语义聚类。
  - 每个树节点：叶节点存储 AMU，内部节点维护子树摘要；摘要可由 AMU 或子节点摘要生成。
- **动态记忆维护**：
  - **插入（Attachment）**：对 Event 和 Affect 视图，通过层次 beam search 找到最合适的叶节点；根据匹配分数 `ρ*` 与阈值的关系选择三种操作之一：`Attach`（附着到现有叶）、`NewLeaf`（在父节点下新建叶）、`NewRoot`（新建根）。
  - **Split**：当叶节点 AMU 数超过 `M_max` 或内聚度 `κ` 低于 `θ_coh` 时，用 cosine K-means 分裂。
  - **Merge**：在会话结束时，若两个节点质心相似度 `s_merge` 超过 `θ_merge`，则合并，且叶节点合并后大小不能超过 `M_max`。
  - **摘要更新**：采用惰性更新机制，为每个内部节点维护 pending-change 计数器 `u_n`，当 `u_n ≥ δ` 时才重新生成摘要，降低 LLM 开销。
- **自适应校准**：
  - **结构参数**：根据历史 AMU 统计动态调整最大叶容量 `M_max`、最大子节点数 `b_max`、最大树深度 `H`，以适应记忆增长。
  - **维护阈值**：基于观察到的余弦相似度分布，使用 Otsu 方法划分低/高相似度子集，并按分位数估计 `θ_new`、`θ_attach`、`θ_coh`、`θ_merge`；用指数移动平均（EMA）平滑更新。
- **基于熵的检索**：
  - **视图路由**：对每个视图计算 query 与叶摘要的相似度，转换成概率分布；计算归一化熵 `H̄_v`，用 `1 − H̄_v` 作为路由分数，概率分布越集中，路由权重 `w_v` 越大。
  - **预算分配**：总检索预算 `K` 按权重分配到各视图，`K_v = max(1, round(K·w_v))`。
  - **视图内 beam search**：从根开始逐层搜索，综合语义相似度（query 与节点摘要的 embedding 余弦相似度）和词法相关性（BM25），取 top-B 扩展，最终选择 top-K_v 叶节点。
  - **证据合并与 fallback**：跨视图合并去重 AMU，形成证据集；若 LLM 返回 “no information”，则回退到原始对话轮次 `D_q` 进行回答。
- **复杂度**：论文附录给出 LLM 调用、记忆维护和检索的复杂度分析；由于视图数为常数，检索复杂度近似为 `O(D[L + b_max(R + BH)])`。

## 3. 实验设计

  - **LongMemEval-S**：500 个对话和 500 个问题，覆盖知识更新（KU）、多会话推理（MS）、单会话交互（SSA/SSP/SSU）和时间推理（TR）。
  - **CloneMem**：补充评估情感相关记忆，包括 Experience、Emotion、Opinion 三类个人记忆问题。
- **基准方法**：MemoryBank、A-MEM、Mem0、MemoryOS、MemOS、MAGMA、TiMem、LightMem；其中 TiMem 是论文主要的强对比方法。
- **实现细节**：

## 6. 主要结论与发现

- **主结果**：
  - LoCoMo 上 ETAMem 总体准确率 **84.68%**，相对最强基线 TiMem（75.30%）提升 **12.46%**；多跳问题相对提升 15.31%，开放域问题相对提升 37.51%。
  - LongMemEval-S 上总体准确率 **83.00%**，相对最强基线 TiMem（76.88%）提升 **7.96%**；多会话和时间推理分别提升 8.12 和 6.77 个百分点。
  - 构建 token 成本显著低于 TiMem 和 A-MEM：LoCoMo 上比 TiMem 减少 67.92%，比 A-MEM 减少 88.51%；LongMemEval-S 上比 TiMem 减少 88.75%。
- **消融发现**：
  - 去除 AMU 提取、层次树结构或 fallback 都会降低性能，说明细粒度表示、结构化和回退机制均有贡献。
  - 统一语义/情感/时间组织均不如三视图混合，说明不同组织原则适合不同信息类型。
  - 共享文本或共享情感表示不如视图特定表示，表明仅分离信息类型还不够，表示也需要对齐。
  - 三视图联合优于任何单视图或双视图；Time-only 单视图相对最强，但仍有差距。
  - 熵路由优于 Max、Mean、LLM-based 路由，证明查询自适应预算分配有效。
- **进一步分析**：
  - CloneMem 上 ETAMem 在 accuracy、helpfulness、recall 上均超过基线。
  - 情感视图对 Emotion 问题权重更高，事件视图对 Experience 问题权重更高，支持视图互补性。
  - 错误分析显示 LongMemEval-S 错误更多是证据聚合/推理问题，而 LoCoMo 错误更多是检索覆盖不足。

## 7. 优点

- **提出清晰的问题框架**：将长期记忆中的“信息纠缠”和“组织失配”作为核心挑战，给出明确的解耦 + 对齐思路。
- **多视图层次设计**：Event/Affect/Time 三视图分别匹配不同信息特性，体现认知科学启发，结构新颖。
- **细粒度 AMU 表示**：原子记忆单元解耦了同一轮对话中的事实、偏好和时间信息，降低噪声。
- **动态维护与自适应校准**：分裂、合并、懒摘要更新、基于相似度分布的阈值校准，使系统能随记忆增长保持效率。

- **基于熵的检索路由**：通过查询自适应分配检索预算，避免固定分配造成的低效或遗漏，在路由策略消融中表现最佳，证明该机制能有效提升检索精度。
- **效率与性能的良好平衡**：相比 TiMem、A-MEM 等强基线，构建 token 成本显著降低，同时准确率提升，说明层次化摘要与惰性更新有效控制了 LLM 开销。
- **系统性实验与可视化分析**：包含多个基准、多种消融、人工评估和错误分析，提供了较完整的证据链，增强了结论的稳健性。

## 8. 缺点与局限性

- **依赖外部组件**：情感分类器和情感编码器均为现成模型，若文本情感表达隐含或语境复杂，可能引入分类噪声并传播到 Affect View。
- **超参数较多**：包括 `λ`、`B`、`δ`、`β`、`M_max`、`b_max`、`H` 及多个阈值，虽然部分自适应校准，但初始值和部分固定超参数仍需根据数据集调整。
- **跨视图融合较为简单**：证据合并采用去重合并，尚未建模视图间冲突或互补关系，可能导致证据冗余或矛盾。
- **资源报告不完整**：未说明 GPU 型号、运行时间、训练/推理算力，只报告 token 成本，使实际部署成本难以全面评估。
- **部分基线公平性风险**：部分对比方法结果来自已有工作，且 CloneMem 实验设置与主实验不一致，可能削弱可比性。
- **评估偏差**：LLM-as-a-judge 可能对某些问题存在判断偏差，尤其开放域生成问题。

## 9. 总结与启示

ETAMem 通过解耦异构长期记忆为事件、情感和时间三个层次化视图，并将表示与组织原则对齐，缓解了信息纠缠和组织失配问题。实验表明其在 LoCoMo 和 LongMemEval-S 上均取得明显提升，同时降低了记忆构建 token 成本。该工作为长期对话记忆系统提供了一种认知科学启发的多视图设计范式，但仍需在跨视图融合、外部组件鲁棒性和资源可复现性方面进一步改进。
