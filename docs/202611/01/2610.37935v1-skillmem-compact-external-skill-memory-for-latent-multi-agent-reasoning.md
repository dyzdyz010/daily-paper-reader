## 摘要
隐式多智能体系统通过将中间推理和智能体间通信保持在连续表示中，降低了推理成本。然而，可复用技能通常以文本形式提供，或存储为逐层 Key-Value 状态或技能专属模型参数，这会引入重复处理或较高的每技能存储开销。我们提出 SkillMem，将每个可复用技能表示为一个小的外部隐式记忆，并使其在隐式多智能体推理过程中可直接使用。角色条件化的交叉注意力读取器使同一记忆能够根据不同智能体的角色和当前隐藏状态来引导它们。我们通过行为蒸馏训练技能记忆和共享读取器，在保持主干模型冻结的情况下，匹配文本技能引起的 token 预测变化。在实验中，我们从配对的成功与失败多智能体轨迹中获取文本技能，不过现有技能也可以直接编译。在六个基准以及参数规模从 4B 到 14B 的 Qwen3 模型上，SkillMem 为较小主干模型带来了显著提升，同时在各种模型规模下保持了高效的隐式多智能体推理。我们在所有评估模型规模上使用相同的 8×256 记忆配置，每个技能仅需 9.6KB 的技能专属存储，其中包括其检索嵌入。对于包含 100 个技能的技能库，与替代技能表示相比，SkillMem 将总存储量减少了 38 倍以上，并实现了最高 4.23 倍的端到端推理加速。这些结果表明，紧凑的程序性记忆可以在不牺牲隐式多智能体推理效率的情况下被复用。

## Abstract
Latent multi-agent systems reduce inference cost by keeping intermediate reasoning and inter-agent communication in continuous representations.\ Reusable skills, however, are commonly supplied as text or stored as layer-wise Key-Value states or skill-specific model parameters, introducing repeated processing or substantial per-skill storage.\ We introduce \textbf{SkillMem}, which represents each reusable skill as a small external latent memory and makes it directly available during latent multi-agent reasoning.\ A role-conditioned cross-attention reader allows the same memory to guide different agents according to their roles and current hidden states.\ We train the skill memories and shared reader through behavioral distillation, matching the change in token predictions induced by a textual skill while keeping the backbone frozen.\ For our experiments, we obtain textual skills from paired successful and failed multi-agent trajectories, although existing skills can also be compiled directly.\ Across six benchmarks and Qwen3 models ranging from 4B to 14B parameters, SkillMem provides strong gains for smaller backbones while preserving efficient latent multi-agent inference across model scales.\ We use the same $8\times256$ memory configuration across all evaluated model scales, requiring 9.6\,KB of skill-specific storage per skill, including its retrieval embedding.\ For a library of 100 skills, SkillMem reduces total storage by more than $38\times$ compared with alternative skill representations and achieves up to a $4.23\times$ end-to-end inference speedup.\ These results show that compact procedural memories can be reused without sacrificing the efficiency of latent multi-agent reasoning.

## 2. 方法论

### 2.1 核心思想

- 将每个可复用技能表示为一组小型外部隐式记忆向量，而不是技能文本、KV 前缀或 LoRA 参数。
- 通过一个共享的、角色条件化的交叉注意力读取器，让同一份技能记忆能够根据不同智能体角色和当前隐状态产生不同的影响。
- 通过行为蒸馏训练记忆和读取器，目标不是重建技能文本，而是复现文本技能对模型 token 预测行为的影响，并保持主干模型冻结。

### 2.2 技能记忆与检索

- 技能库定义：`S = {s1, ..., sN}`，每个技能包含名称、使用场景描述和程序性指令。
- 技能索引：用冻结骨干编码技能文本，得到 `ei`；对任务查询 `q` 编码得到 `eq`；通过余弦相似度检索最相关技能。
- 记忆表示：每个技能存储为 `Zs ∈ R^{M × dmem}`，默认 `M=8`，`dmem=256`，因此每个技能仅需约 9.6 KB 存储，包含检索嵌入。
- 与 KV 缓存和 LoRA 的区别：
  - KV 技能存储随前缀长度和层数增长，约 13.0 MB/技能；
  - LoRA 技能约 30.7 MB/技能；
  - SkillMem 的记忆存储与技能文本长度无关，且共享读取器。

### 2.3 角色条件化记忆读取器

- 在冻结骨干的若干 Transformer 层插入交叉注意力读取器，默认插入层为 `{L/4, L/2, 3L/4, L-1}`。
- 角色表示：从每个角色系统指令中提取固定的角色向量 `eρ`，不参与训练。
- 读取器计算流程（用文字概括）：
  - 将当前隐藏状态与角色向量拼接，再经过 LayerNorm，得到查询输入 `Uρℓ`；
  - 从技能记忆 `Zs` 生成键和值；
  - 通过 softmax 注意力得到对记忆的读取结果；
  - 通过输出投影和角色条件化门控 `gρℓ` 控制多少记忆信息被加到隐藏状态中。
- 每个插入层有独立的读取器参数，但所有技能和所有角色共享同一套读取器；训练时仅更新技能记忆和读取器，骨干完全冻结。

### 2.4 行为蒸馏

- 对每个技能、每个角色、每个标定任务：
  1. 使用文本技能生成一个教师响应；
  2. 在同一条响应上分别计算三种条件下的 token 对数概率：带文本技能、无技能、带技能记忆；
  3. 计算文本技能带来的行为变化 `Δtext` 和记忆带来的行为变化 `Δmem`。
- 引入 token 级技能支持权重 `wρt = σ(β · sg(Δtext))`，用于区分技能真正起作用的 token 和通用 token。
- 训练目标由三项组成：
  - `L_token`：提高技能支持 token 在记忆条件下的对数似然；
  - `L_shift`：匹配记忆诱导行为变化与文本诱导行为变化（SmoothL1）；
  - `L_safe`：在技能支持较弱的 token 上保持接近无技能模型行为。
- 总目标：`L = λ_token L_token + λ_shift L_shift + λ_safe L_safe`。
- 行为蒸馏只训练技能记忆和共享读取器，不修改主干。

### 2.5 技能发现

- 从每个基准的 20 个标定样本中，用基础多智能体流程多次运行，收集成功与失败轨迹的配对。
- 用同一骨干比较每对轨迹，提取可复用程序，去除实例特定信息并去重，得到技能库。
- 技能发现得到的文本技能随后被编译为隐式记忆；但如果已有文本技能，也可以直接编译，无需经过轨迹发现。

- 论文用命题说明：行为蒸馏把文本技能导致的预测变化表示为似然比，并让记忆技能在隐式输入上近似这一变化。

## 6. 主要结论与发现

- **对较小骨干收益明显**：在 Qwen3-4B 上，SkillMem 在五个基准上达到最高准确率，并显著优于 LatentMAS 和所有替代技能表示；在 Qwen3-8B 上，也在 GSM8K、MedQA、MBPP+ 上取得最佳结果。
- **模型规模增大后收益下降**：到 Qwen3-14B，优势不再一致，部分原因是基线准确率已经很高，提升空间有限。
- **存储优势显著**：每个技能仅 9.6 KB；包含共享读取器后，100 个技能总存储约 35.5 MB，相比 KV Skill 减少约 38.3 倍，相比 LoRA Skill 减少约 86.6 倍；技能库增长到 1000 时优势更大。
- **推理效率高**：SkillMem 端到端延迟约 7.95 秒，接近 LatentMAS 的 8.18 秒，明显低于文本技能和 KV 技能；相对 TextMAS 实现 4.23 倍加速。
- **训练效率高**：共享读取器训练时间比逐技能 LoRA 少约 9.4 倍。
- **消融结论**：
  - 角色条件化对性能至关重要，移除后平均准确率大幅下降；
  - 每角色单独记忆并不优于共享记忆；
  - 记忆容量 M=8 最优，继续增大到 16 反而下降；
  - `L_token`、`L_shift`、`L_safe` 三项损失互补，移除任一项均降低平均准确率，其中 `L_shift` 影响最大。
- **零训练隐式技能提取不可靠**：直接从成功/失败轨迹中提取或生成隐向量作为技能，要么效果接近无技能，要么在部分基准上导致生成退化或崩溃。

## 7. 优点

- **高效紧凑的表示**：技能记忆与技能文本长度无关，9.6 KB/技能远小于 KV 缓存和 LoRA，适合大规模技能库。
- **共享与角色条件化结合**：同一记忆可以被规划者、批评者等不同角色按需使用，避免为每个角色存储单独技能。
- **冻结骨干训练**：只训练外部记忆和读取器，不修改主干模型，适合与不同模型组合使用。
- **行为蒸馏目标明确**：训练目标是复现技能对模型预测行为的影响，而不是重建技能文本，更契合隐式推理场景。
- **理论支持**：通过似然比和 Lipschitz 扰动分析，说明了文本监督到隐式行为迁移的可行性。
- **实验设计较扎实**：跨任务、跨模型规模、多表示对比、多种消融和零训练对照，证据链条较完整。
- **技能发现流程可复用**：从成功/失败轨迹中自动提取技能，且允许直接编译已有文本技能。

## 8. 不足与局限

- **大模型收益有限**：在 Qwen3-14B 上没有一致优势，说明方法可能主要适用于能力较弱、改进空间较大的骨干。
- **评估模型单一**：只使用 Qwen3 系列，未在 Llama、Mistral 等其他模型家族上验证泛化性。
- **技能使用模式简单**：每次只检索并使用一个技能，不支持多技能组合或冲突消解；未来工作也提到这一点。
- **检索策略较初级**：仅根据任务查询进行 top-1 余弦检索，未考虑智能体角色或当前推理状态；对于跨领域任务可能不够灵活。
- **行为蒸馏依赖文本教师**：训练时需要为每个技能和角色生成文本教师响应，中间角色本来不产出文本，训练和推理存在一定差异；文本教师质量也影响记忆学习效果。
- **技能发现可能存在偏差**：从同一骨干的成功/失败轨迹中提取技能，可能继承该骨干已有的错误模式或偏好；去除实例特定信息的过滤也可能不够彻底。
- **部分比较不够对等**：S2L 基线没有角色条件机制，因此与 SkillMem 的对比并不能完全分离“角色共享读取器”带来的收益。
- **零训练替代方案不可靠**：附录显示直接隐式提取技能效果不佳，进一步凸显对行为蒸馏和读取器训练的依赖。
- **资源信息缺失**：未报告 GPU 型号、显存和总实验算力，难以精确评估训练与推理资源需求。
