## 摘要
多智能体辩论系统要求智能体在多轮辩论中保留并重新审视论点，但有限的上下文窗口和非结构化记忆使得相关信息越来越难以恢复。现有的扁平记忆和成对图记忆也难以捕捉高阶关系，包括多智能体一致意见、冲突证据和不断演化的共识。我们提出 HEDGE，一个选择性记忆框架，将辩论轨迹表示为语义超图。超边连接不同智能体间的相关主张，而超边内的关系图保留细粒度论证结构。一个经过监督学习和强化学习训练的记忆选择模块（MSM）将每个候选记忆路由到 STORE、BACKUP 或 OMIT，在保留有用信息的同时限制冗余。在七个不同的基准上，HEDGE 一致优于强单智能体、多智能体和记忆基线，在使用 GPT-4o-mini 的最强多智能体系统基础上平均准确率提高 5.0 个百分点。在冲突密集型任务上提升达 8.2 个百分点，同时 HEDGE 将记忆使用量减少 48%，辩论轮数减少 34%。

## Abstract
Multi-agent debate systems require agents to retain and revisit arguments across multiple rounds, yet limited context windows and unstructured memories make relevant information increasingly difficult to recover. Existing flat and pairwise-graph memories also struggle to capture higher-order relations, including multi-agent agreement, conflicting evidence, and evolving consensus. We introduce HEDGE, a selective memory framework that represents debate trajectories as semantic hypergraphs. Hyperedges connect related claims across agents, while intra-hyperedge relational graphs preserve fine-grained argumentative structure. A learned memory selection module (MSM), trained through supervised learning and reinforcement learning, routes each memory candidate to STORE, BACKUP, or OMIT, retaining useful information while limiting redundancy. Across seven diverse benchmarks, HEDGE consistently outperforms strong single-agent, multi-agent, and memory baselines, improving accuracy by 5.0 points on average over the strongest multi-agent system with GPT-4o-mini. The gains reach 8.2 points on conflict-heavy tasks, while HEDGE reduces memory usage by 48% and the number of debate rounds by 34%.

## 2. 论文提出的方法论

### 2.1 核心思想
HEDGE 将多智能体辩论轨迹表示为一个**语义超图**：
- **节点**：原子辩论元素（主张、反主张、证据陈述、中间结论等）。
- **超边**：将语义相关的节点聚为一类，允许节点属于多个超边，以自然表达重叠主题和共享结论。
- **超边内关系图**：在每个超边内部维护一个有向、带类型的关系图，关系类型包括 `SUPPORTS`、`REFUTES`、`EVIDENCE-FOR`、`DEPENDS-ON`、`LEADS-TO`，保留细粒度论证结构。

### 2.2 记忆构建与维护
- 对每个节点计算 **ℓ2 归一化嵌入** `hv` 和 **稀疏语义签名** `σv`（包含实体、名词短语、数值、内容词元）。
- 超边维护未归一化嵌入和、质心、并集签名。
- 对新节点，通过 **Jaccard 签名相似度** 和 **余弦嵌入相似度** 双重阈值判断其可加入的超边；若无匹配则创建新超边。
- 关系图由 LLM（默认 GPT-4o-mini）对节点对预测关系类型。
- **在线维护**：
  - 每轮结束时重新评估 `BACKUP` 节点，可提升为 `STORE`。
  - 合并冗余超边（基于签名重叠和质心相似度）。
  - 对连续多轮低效用的超边进行剪枝，并尽量重新分配有用节点。
  - 仅更新受影响超边的嵌入和关系，避免全局重算。

### 2.3 两级记忆检索
- **超边级**：根据查询签名和质心余弦相似度选取 top-\(K\) 个超边。
- **节点级**：在每个选中超边内按嵌入相似度选取 top-\(m\) 个节点。
- 返回由检索节点及其内部关系构成的**诱导子图**，作为有界记忆读取结果。

### 2.4 记忆选择模块（MSM）
- 输入：候选节点 token 表示、当前超图质心、候选-超边对齐特征。
- 利用**候选与超边质心的交叉注意力**融合记忆上下文。
- 将候选表示、上下文表示和两个标量效用特征拼接，通过三层 MLP 输出 `STORE`、`BACKUP`、`OMIT` 的动作分布。
- 训练分两阶段：
  1. **Stage I 监督预训练**：使用从 HotpotQA 模拟辩论轨迹中通过后验分析得到的伪标签（如是否被后续引用、是否参与冲突解决、是否贡献最终答案），优化交叉熵和类别平衡正则。
  2. **Stage II 强化学习（PPO）**：在在线多智能体辩论环境中根据最终答案正确性、路由效用（后续使用率）和记忆效率（惩罚记忆增长）构造奖励，进行策略优化。

## 7. 优点
