## 摘要
长时程对话智能体需要有效的记忆系统来从交互历史中回忆事实、事件和关系。本文提出了一种混合记忆架构，包含情景记忆和结构化关系记忆，以及一个保持效率的整合机制。我们在两个基准 LoCoMo 和 LongMemEval-S 上进行了实证研究。实验表明，两种记忆类型始终互补，结合二者优于现有最先进的记忆框架，在 LoCoMo 上达到 90.2% 的准确率，在 LongMemEval-S 上达到 85.5% 的准确率。

## Abstract
Long-horizon dialogue agents require effective memory systems to recall facts, events, and relationships from interaction histories. In this work, we propose a hybrid-memory architecture comprising episodic memories and structured relational memories and a consolidation mechanism which preserves efficiency. We conduct an empirical study across two benchmarks: LoCoMo and LongMemEval-S. Our experiments demonstrate that the two memory types are consistently complementary, combining both outperform state-of-the-art memory frameworks and achieves 90.2% accuracy on LoCoMo and 85.5% on LongMemEval-S.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：大语言模型（LLMs）虽然推动了多轮交互智能体的发展，但在长时程对话中回忆、整合和推理历史信息仍存在根本性局限。
- **核心问题**：如何为长时程对话智能体设计有效的记忆系统，使其能从长期交互历史中高效回忆事实、事件和关系，同时避免大规模上下文窗口带来的成本与性能退化。
- **现有方案不足**：
  - **参数化记忆**：将知识写入模型参数，推理延迟低，但编码成本高、更新困难，且可能引入幻觉。
  - **非参数化记忆**：外部存储按需检索，灵活可扩展，但存在检索延迟；现有方法要么只保存片段事实，要么缺乏结构化关系，难以兼顾叙事上下文和关系推理。
- **本文含义**：提出一种**混合记忆架构**，结合情景记忆与结构化关系记忆，并引入离线整合机制，在保持效率的同时提升长期记忆的准确性与可扩展性。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 总体框架
系统采用三阶段流程：

1. **记忆整理（Memory Curation）**：会话结束后离线处理，同时生成情景记忆和结构化关系记忆。
2. **记忆整合（Memory Consolidation）**：定期对记忆进行聚类、合并与删除，减少冗余、冲突和过时信息。
3. **检索与问答（Memory Retrieval & QA）**：查询时分别从两个记忆库检索相关条目，生成上下文相关的回答。

### 2.2 情景记忆（Episodic Memory）
- 以**会话**为粒度，由 LLM 生成整体情景条目。
- 每条情景包含：
  - **标题**：3–7 词短标题；
  - **摘要**：一句话概括关键点；
  - **详情**：保留叙事上下文、事件、背景信息；
  - **时间戳**：会话发生时间。
- 侧重保留**叙事顺序**与上下文丰富性。

### 2.3 结构化关系记忆（Structured Relational Memory）
- 从对话中提取实体-关系三元组：  
  \[
  (e, r, o, t, c)
  \]
  其中：
  - \(e\)：主体实体；
  - \(r\)：关系标签（如 `WILL_PRESENT`）；
  - \(o\)：客体（实体、数值或属性）；
  - \(t\)：时间戳，表示该关系何时成立；
  - \(c\)：来源上下文，保留三元组被提取时的原始语句，用于保存细微语义和出处。
- 优势：使人物、地点、事实之间的隐式连接显式化，支持跨会话关系推理。

### 2.4 记忆整合（Consolidation）
- 使用 **UMAP** 降维 + **HDBSCAN** 聚类，将语义相似的记忆分组。
- 令记忆集合 \(M = \{m_1, m_2, \dots, m_N\}\)，每个记忆有语义嵌入 \(e_i \in \mathbb{R}^d\) 及元数据。
- 聚类结果：  
  \[
  C = \{C_1, C_2, \dots, C_K\}, \quad C_k \subseteq M
  \]
- 对每个簇 \(C_k\) 应用整合算子 \(\Phi(\cdot)\)，执行两类操作：
  - **MERGE**：合并冗余或互补记忆，保留重要信息，生成 \(\tilde{M}_k = \text{merge}(C_k)\)；
  - **DELETE**：删除过时、冲突或被取代的记忆，得到 \(M'_k = \tilde{M}_k \setminus \{m_i\}\)。
- 整合后的记忆库：
  \[
  M' = \bigcup_{k=1}^{K} M'_k
  \]
- 效果：减少存储开销、检索噪声，保持记忆新鲜度。

### 2.5 检索与问答
- 分别对**情景记忆库**和**关系记忆库**做独立 **top-k 语义相似度搜索**。
- 情景记忆以“详情”字段做向量索引；关系记忆将三元组拼接成自然语言字符串后索引。
- 检索预算：
  - 情景记忆取前 \(k\) 条；
  - 关系记忆取前 \(2k\) 条（因为关系条目更短，可以在相同 token 预算下取更多）。
- 默认 \(k=10\)，性能在此附近趋于饱和。

## 6. 论文的主要结论与发现

- **两种记忆类型具有互补性**：结合情景记忆和关系记忆比单独使用任何一种都更优，尤其在 **Multi-Hop**（多跳推理）和 **Temporal**（时间推理）任务上提升显著。
- **性能表现**：
  - 在 LoCoMo 上，使用 gpt-4o-mini 时达到 **83.5%** LLM Score，超过 FullContext 和所有记忆基线；
  - 使用 gpt-4.1-mini 时达到 **90.2%**，仅略低于 FullContext（91.3%），但 token 使用量减少约 **87%**；
  - 在 LongMemEval-S 上达到 **85.5%**，超过 FullContext 和 Nemori。
- **整合机制有效**：在保持几乎不损失性能的前提下，记忆存储量压缩 **16.34%**；在 LoCoMo 上整合后系统在 single-hop 和 multi-hop QA 上准确率还有提升。
- **检索效率**：\(k=10\) 时性能趋于饱和，且 \(k=2\) 时仍有 0.811 的分数，说明检索精度较高。
- **模型泛化性**：gpt-4.1-mini 与更强的 gpt-5.4 性能接近，而 Qwen3-8B 也能达到 76.2%，说明瓶颈在于记忆系统设计而非模型容量。

## 7. 优点：方法或实验设计上的亮点

- **互补性设计**：显式区分叙事型情景记忆与结构化关系记忆，针对不同推理类型提供不同信息，相互补充。
- **整合机制**：通过聚类+LLM 合并/删除，在不牺牲准确性的前提下降低存储和检索开销，兼顾效率与效果。
- **时间戳与来源上下文**：关系三元组带有时间戳和原文上下文，避免纯结构化抽取丢失上下文和时态信息。
- **实验较为全面**：两个难度差异较大的基准、多类推理任务、多指标（F1、BLEU、LLM Score）、消融、参数敏感性、模型泛化均有覆盖。
