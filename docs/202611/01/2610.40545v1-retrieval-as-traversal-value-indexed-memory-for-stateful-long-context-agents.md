## 摘要
长上下文模型会反复解决密切相关的检索问题。注意力或全局检索能够保留大规模存储，但每次前向传播都会重新搜索重要内容。循环压缩避免这种搜索，但只是通过更早决定要保留哪些信息。这两种机制都没有直接利用一个事实：相邻检索步骤中有用的记忆可能高度重叠。我们提出一种替代方案，其中检索是一种在地址空间中持续的局部遍历。我们将记忆的内容与其地址分离。效用由检索该内容所揭示的信息来定义，而几何结构只决定能以多低的代价到达该信息。由此产生一个成本正则化的索引目标：它在局部邻域内保持信息价值，同时对每个被纳入局部可访问范围的记忆收取代价。其边际价值形式同时带来吸引与排斥压力。因此，当额外价值超过检索成本时，互补记忆应当能够被共同检索；而冗余记忆不应仅仅因为各自有用就占用同一检索集合。作为原理验证，我们仅在 MiniGrid Memory 上测试了最简单的固定几何结构实例。在五个 token 的上下文条件下，一个持久局部遍历头在 0.59M 训练步后达到 0.95 的平均回报；相比之下，高斯绝对寻址需 0.94M 训练步，分类绝对寻址需超过 2M 训练步。本实验未测试学习得到的几何结构或重复检索。相反，它支撑了以下假设：有状态检索可能比无状态检索更容易学习。要检验完整提出的方法，还需要进一步实验。

## Abstract
Long-context models repeatedly solve closely related retrieval problems. Attention or global retrieval can retain large stores, but each forward pass again searches for what matters. Recurrent compression avoids this search only by deciding earlier what information to preserve. Neither mechanism directly exploits that useful memories at neighbouring retrieval steps may substantially overlap. We propose an alternative in which retrieval is a persistent local traversal through an address space. We separate a memory's content from its address. Utility is defined by the information revealed by retrieving the content, while geometry determines only how cheaply that information can be reached. This leads to a cost-regularised indexing objective that preserves information value inside local neighbourhoods while charging for every memory made locally accessible. Its marginal-value form gives both attractive and exclusion pressures. Thus, complementary memories should be co-retrievable when the additional value exceeds retrieval cost, whereas redundant memories should not occupy the same retrieval set solely because they are individually useful. As a proof of principle, we test only the simplest fixed-geometry instance on MiniGrid Memory. A persistent local traversal head reaches $0.95$ mean return after $0.59$M training steps with a five-token context, compared with $0.94$M for Gaussian absolute addressing and more than $2$M for categorical absolute addressing. The experiment does not test learned geometry or repeated retrieval. Instead, it motivates the hypothesis that stateful retrieval may be easier to learn than stateless. To test the full proposed method further experimentation is necessary.

## 2. 论文提出的方法论

### 2.1 记忆内容、上下文与地址分离

- 设外部记忆集合为 \(\Omega_t\)，每个记忆 \(j\) 包含随机变量 \(M_j\)，其内容在检索前不可观测，检索后可获得实现值 \(m_j\)。  
- 每个记忆的**地址** \(z_j = \Phi(C_w^j)\) 由写入时的上下文 \(C_w^j\) 映射得到，与内容本身分离。检索记忆时，插入的是记忆内容而非写入上下文。  
- 当前上下文 \(C_t\) 包含近期观察与已检索记忆，而检索头位置单独维护，不属于 \(C_t\)。  
- 信息价值定义为：
  \[
  V(S;c) = \mathbb{E}[U(c \oplus M_S) - U(c) \mid C_t = c],
  \]
  其中 \(U\) 是任务效用（如期望回报或负预测损失）。该定义**完全独立于地址**，只取决于内容。

### 2.2 成本正则化的局部索引目标

- 局部可访问集合定义为以查询位置 \(\Phi(c)\) 为球心、半径为 \(\epsilon\) 的球内所有记忆：
  \[
  B_\epsilon(x) = \{j : \|z_j - x\| \le \epsilon\}.
  \]
- 如果直接最小化信息损失 \(V(\Omega_t;c) - V(N_c(\Phi);c)\)，会得到平凡解：把所有上下文和记忆映射到同一点，所有记忆都在邻域内。因此引入**单位检索成本** \(\lambda > 0\)，目标函数为：
  \[
  L_\lambda(\Phi) = \mathbb{E}\big[V(\Omega_t;C_t) - V(N_{C_t}(\Phi);C_t) + \lambda |N_{C_t}(\Phi)|\big].
  \]
- 固定上下文下，这等价于最大化：
  \[
  J_\lambda(S;c) = V(S;c) - \lambda |S|,
  \]
  用**价值阈值**取代了固定 top-k 预算：只有当新增信息的价值超过检索成本时，该记忆才值得被局部可访问。

### 2.3 互补性与冗余性导致相反压力

- 定义记忆 \(j\) 在已有集合 \(S\) 上的**边际价值** \(\Delta_j(S;c) = V(S \cup \{j\};c) - V(S;c)\)。  
- 两个记忆 \(i,j\) 的**条件交互**为：
  \[
  s_{ij}(S;c) = \Delta_j(S \cup \{i\};c) - \Delta_j(S;c),
  \]
  正值表示互补（观察 \(i\) 增加 \(j\) 的边际价值），负值表示冗余。  
- **观察 1（成本调整的共同检索）**：联合检索 \(i,j\) 优于只检索 \(i\) 当且仅当
  \[
  \Delta_j(S \cup \{i\};c) > \lambda.
  \]
  互补性扩大满足该条件的上下文范围，形成**吸引力**；反之，若 \(j\) 一旦知道 \(i\) 就完全冗余，则 \(\Delta_j(S \cup \{i\};c)=0\)，共同检索会损失 \(\lambda\)，形成**排斥力**。  
- **价值等价替代**：若两个记忆对任意上下文和背景集都有相同价值且合并无额外价值，则它们拥有相同的个体价值和与其他记忆联盟的交互 profile。因此地址几何应反映**价值和交互结构**，而非原始内容相似性。

### 2.4 持久检索作为遍历

- 引入持久检索头位置 \(i_t\)，每一时刻的局部检索集合为：
  \[
  M_t = B_\epsilon(\Phi(c_t)) \cup B_\epsilon(i_t),
  \]
  工作窗口保留最近 \(H\) 步遍历过的记忆：
  \[
  W_t = \bigcup_{\tau=t-H+1}^{t} M_\tau.
  \]
- 检索头的移动规则保持模块化，可以由强化学习学习，也可以设计为移向上一步最高价值的记忆。  
- 定义成本最优检索集 \(S^\star_t = \arg\max_S [V(S;c_t) - \lambda |S|]\)，以及一步添加漂移 \(D_t = |S^\star_t \setminus S^\star_{t-1}|\)。当 \(D_t\) 相对 \(|S^\star_t|\) 很小时，持久机制可以复用上一步的检索状态，避免从头搜索。
