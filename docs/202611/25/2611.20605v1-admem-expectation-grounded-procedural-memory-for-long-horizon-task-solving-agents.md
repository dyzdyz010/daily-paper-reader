## 摘要
跨任务携带记忆的智能体，其表现取决于其所保留的条目。我们从一个容易复现且令该领域不安的观察出发：天真地累积跨任务经验可能使智能体比完全没有记忆时表现更差。在 AgentBoard 上，一种工作流归纳记忆在八个领域中的七个里解决的任务数少于无记忆的 ReAct 智能体；而在 Jericho 上，一个缺乏周边结构的逐步骤程序性存储损失了 ReAct 完成数的一半。我们认为缺失的要素是逐动作的信用分配和存储条目的显式生命周期，并提出 AdMem 以同时提供这两者。在每次动作之前，行动者承诺一个预期结果；同时运行的评判器将实际结果与该预期进行评分，并写入一条携带二元奖励和反思的程序性条目，因此信用落在赢得该奖励的动作上，且无需环境奖励。随后每条目携带一个标量效用，在 noisy-OR 奖励模型下在线更新；该效用与上下文相似度联合用于检索排序，并驱动淘汰与合并，从而使存储拥有遗忘与巩固策略，而非无界增长。在八个 AgentBoard 领域共 707 个任务上，AdMem 解决了 441 个，ReAct 为 388 个，工作流归纳基线为 312 个——这一汇总增益在双侧 Fisher 精确检验下显著，且集中在提供可迁移跨任务结构的领域。所有记忆均为人类可读文本，这正是上述失败可诊断的原因——并且如我们所讨论，这也使存储成为一个可审计但可攻击的表面。

## Abstract
An agent that carries memory across tasks is only as good as the entries it keeps. We begin from an observation that is easy to reproduce and uncomfortable for the field: naively accumulating cross-task experience can make an agent \emph{worse} than one with no memory at all. On AgentBoard, a workflow-induction memory solves fewer tasks than a memoryless ReAct agent in seven of eight domains, and a per-step procedural store with no surrounding structure loses half of ReAct's completions on Jericho. We argue that the missing ingredients are per-action credit assignment and an explicit life cycle for stored entries, and present AdMem, which supplies both. Before each action the actor commits to an expected outcome; a concurrently running critic scores the realized outcome against that expectation and writes a procedural entry carrying a binary reward and a reflection, so credit lands on the action that earned it and no environment reward is required. Each entry then carries a scalar utility, updated online under a noisy-OR reward model, that ranks retrieval jointly with context similarity and drives eviction and merging, giving the store a forgetting and consolidation policy instead of unbounded growth. Across 707 tasks in eight AgentBoard domains AdMem solves 441 against 388 for ReAct and 312 for the workflow-induction baseline --- a pooled gain significant under a two-sided Fisher exact test, concentrated in the domains that supply transferable cross-task structure. All memory stays human-readable text, which is what makes the failures above diagnosable --- and, as we discuss, also makes the store an auditable but attackable surface.

## 2. 方法论：AdMem 的核心思想与关键技术细节

AdMem 由三个并发模块组成：**行动者（actor）**、**评判器（critic）** 和**长期记忆存储（long-term memory store）**。

### 2.1 记忆类型
- 遵循经典认知划分，长期记忆 \(M\) 包含三类条目：
  - **语义记忆** \(M_S\)：环境事实、工具返回含义等一般知识。
  - **情景记忆** \(M_E\)：过去事件摘要，按作用域组织。
  - **程序性记忆** \(M_P\)：记录“在何种情境下采取何种动作、结果是否满足预期、更好的动作是什么”的决策指导。

### 2.2 期望引导的信用分配
- **动作前承诺预期**：行动者在执行每个动作前，必须在 `take_action` 工具中写明该动作的预期结果或目的。
- **评判器异步评分**：评判器缓存动作及其预期，等待相关观察到达后，将实际结果与预期对比。
  - 产生**二元奖励** \(r_k \in \{0,1\}\) 和一段反思文本。
  - 该奖励是**逐动作**的，不需要环境提供额外奖励信号。
- **作用域关闭即判定**：子目标栈提供了自然的判定边界——当子目标被弹出或任务结束时，对应记录即可被评判。
- 规划工具包括：`plan_for_the_task`、`add_subgoal`、`conclude_subgoal`、`take_action`、`think`，用于划定评判单元和压缩上下文。

### 2.3 短时记忆：子目标栈与压缩
- 短时记忆 \(s_t^{short}\) 按任务生命周期维护，任务结束时清空。
- 采用**运行栈**结构：当前子目标以全分辨率保留，上一级目标被 LLM 压缩为摘要。
- 子目标和任务边界同时是记忆安全边界：原始观察不会跨任务直接泄漏到后续任务，只通过长时记忆摘要传递。
- 窗口上限：短时窗口保持 30 条消息，超出时最老回合被压缩。

### 2.4 长期记忆生命周期：效用、检索、遗忘与合并
- 每条程序性条目 \(m\) 带有一个标量效用 \(v_m \in [0,1]\)，表示“遵循该条目使当前动作成功”的概率估计。
- **检索排序**：程序性条目按效用和上下文相似度的乘积排序：
  \[
  \text{score}(m \mid c_t) = v_m \cdot \psi(c_t)^\top \psi(c_m)
  \]
  其中 \(\psi\) 为归一化嵌入映射，相似度被裁剪到 \([0,1]\)。
  - 程序性条目还受**动作空间硬约束**：只有在当前合法工具集与条目记录时的工具集匹配时才可被检索。
- **效用更新**：采用 noisy-OR 奖励模型：
  \[
  r_t \sim \text{Bernoulli}\Big(1 - \prod_{i=0}^n (1 - q_i)\Big), \quad q_i = v_{m_i} \cdot \sigma_i
  \]
  - \(\sigma_i\) 是当前上下文与条目存储上下文的相似度。
  - 失败样本会同时压低所有被检索条目的效用；成功样本按各条目成为成功原因的概率分配信用。
  - 新条目以 \(v_m=1\) 初始化（乐观面对不确定性）。
- **遗忘**：低效用条目因排序靠后而停止被检索，随后因检索频率低于阈值 \(\epsilon_e=0.01\) 被淘汰。
- **合并**：当两个程序性条目在检索中频繁共现、无法区分时（共检索率高于 \(1-\epsilon_m\)），合并为一条。
- 语义条目通过 LLM 编辑进行合并；情景条目按作用域压缩。
- 所有生命周期操作（遗忘、合并）都由同一个标量效用驱动，避免了“写路径 + 旁路计数器”的分离。

## 3. 实验设计

### 3.1 数据集与基准
- **AgentBoard** 八个领域：AlfWorld、BabyAI、Jericho、PDDL、Tool-query Academic、Tool-query Weather、WebShop、ScienceWorld。
- 共 **707 个任务**，每个领域为固定任务集。
- 指标：
  - **任务完成度 C**：解决任务的占比。
  - **平均进度 P**：每个任务进度分 \(p_i \in [0,1]\) 的平均值。
- 运行设置：流式多任务，一个领域内任务按顺序出现，长期存储跨任务不重置；每个任务上限 30 环境步。

### 3.2 对比方法
- **ReAct**：无跨任务记忆的基线，任务内推理-行动交错，每个任务从零开始。
- **AWM**：工作流归纳记忆，从成功轨迹在线归纳可复用工作流，是最接近的已发表系统。
- **STP 消融**：仅保留短时规划和上下文管理，移除所有长期记忆回忆。
- **LTP 消融**：仅保留长期程序性存储（含评判器反思和基于奖励的效用），移除短时规划和上下文管理。

### 3.3 模型与实现细节
- 主干模型：**Claude Haiku 4.5**，行动者、评判器、摘要器均使用同一模型；解码为贪心（温度 0，top-p 1）。
- 检索嵌入：`text-embedding-3-small`，L2 归一化，内积即余弦相似度；程序性条目取 top \(n=3\)，包含阈值 0.1；情景条目取 top \(n=3\)；语义条目整体注入。
- 生命周期常量：\(\epsilon_e = \epsilon_m = 0.01\)；淘汰需至少 500 次检索轮次，合并需 100 次；子目标栈深度上限 3。

## 6. 主要结论与发现

- **AdMem 显著优于无记忆和现有记忆基线**：在 707 个任务上解决 441 个（62.4%），ReAct 为 388 个（54.9%），AWM 为 312 个（44.1%），汇聚差异显著（Fisher exact \(p=5\times10^{-3}\)）。
- **跨任务记忆并非免费**：AWM 比 ReAct 少解决 76 个任务（\(p=7\times10^{-5}\)），在 8 个域中 7 个域落后；LTP 消融在 Jericho 上持续低于 ReAct（4/20 vs 8/20），三 epoch 后仍未超越。
- **增益集中在有可迁移结构的领域**：PDDL 上 AdMem 解决 46/60 任务，ReAct 20/60，提升 +43.3 个百分点，经 Holm-Bonferroni 校正后仍显著（\(p=3\times10^{-6}\)）；AlfWorld 为名义显著（+14.2 点，\(p=0.03\)）但未通过多重检验校正。
- **在结构稀少的领域达到持平**：WebShop 和 ScienceWorld 上 AdMem 完成度与 ReAct 无显著差异（各差 2 个任务），但平均进度略高；这一结果支持“AdMem 防止了无管理记忆的崩塌，而非在这些域获得增益”。
- **组件互补性**：STP 单独提升平均进度但无跨任务收益；LTP 单独为负收益；两者组合后 AdMem 在 Jericho 上从 9→10→12 个任务单调提升，逆转了 LTP 的负面效果。
- **记忆作为攻击面**：人类可读文本使环境文本可通过评判器写入程序性条目，随后被检索进入后续任务的动作选择；`v_m=1` 的乐观初始化使新条目获得最高检索优先级，放大了注入风险；但生命周期（效用递减、淘汰、溯源、工具集作用域）提供了相应防御。

## 7. 优点

- **期望引导的信用分配**：在动作前固定预期，使评判器能在没有环境奖励的情况下给出逐动作二元奖励，解决了任务级奖励的信用分配难题。
- **统一的存储生命周期**：用单个标量效用 \(v_m\) 同时驱动检索排序、遗忘和合并，机制简洁且可解释。
- **人类可读文本记忆**：所有记忆均可读、可溯源，使失败模式可诊断，也便于审计和删除。
- **并发架构**：行动者不等待评判器，记忆写路径与推理路径分离，降低了对关键路径的阻塞。
- **统计严谨性**：针对固定任务集使用 Fisher 精确检验、最坏情况 McNemar 检验和设计效应敏感性分析，对配对和聚类效应进行了保守处理。
- **负向结果的意义**：明确指出“跨任务记忆可能有害”，并给出 AWM 和 LTP 消融的反面证据，增强了结论的可信度。

## 8. 不足与局限

- **单次运行、无种子扫描**：每个配置仅运行一次，无法评估随机性和流式顺序的影响；记忆臂的区间估计可能因任务间自相关而偏乐观。
- **单一主干模型**：仅在 Claude Haiku 4.5 上验证，未跨模型或开源模型进行一致性检验。
- **消融不彻底**：组件消融仅在一个领域（Jericho）上分离 STP 和 LTP，未对期望奖励、效用淘汰、上下文作用域等子机制进行独立消融。
- **统计功效受限**：三个 20 任务领域难以支撑结论；AlfWorld
