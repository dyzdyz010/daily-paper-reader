## 摘要
智能体记忆系统通过将经验提取为文本并在查询时检索，为大语言模型提供持久记忆，但模型本身并未演化：无论经历过多少次交互，每次查询的初始状态都相同。提取错误会累积，任何单一片段都无法陈述的跨会话隐含模式难以浮现，构建成本随每次对话不断增加。对过往交互进行微调确实会改变权重，但需要在服务时进行反向传播，并在长历史上性能下降。我们提出 CLAM（Carried Latent Adapter Memory，携带式潜在适配器记忆），它结合两者优势：由循环超网络执行参数化巩固，将一系列会话激活在单次前向传播中编译为低秩适配器，无需梯度步骤，也无需语言模型生成调用；同时一个互补的情景缓冲区在推理时提供逐字细节。门控潜在状态以固定大小跨会话携带知识，因此参数化记忆可以在不增长的情况下累积。在 LoCoMo 和 LongMemEval-S 上，针对三个开源模型（2-7B 参数），CLAM 比所有智能体基线高出 1-45 个点，比所有基于梯度的参数化方法高出 10-45 个点，同时构建记忆时无需任何生成式大语言模型调用、无需梯度步骤，并且比提取系统的实际耗时少 3-151 倍。两个通道互补：当情景缓冲区未命中标准证据时，巩固后的适配器可增加 12-15 个准确率点；即使使用 oracle 缓冲区，也仍能增加 4-5 个点。

## Abstract
Agentic memory systems give LLMs persistent memory by extracting experience into text and retrieving it at query time, but the model itself does not evolve: however many interactions it has had, it starts each query the same. Extraction errors compound, implicit cross-session patterns that no single fragment states cannot be surfaced, and the construction cost grows with every conversation. Fine-tuning on past interactions does change the weights, but requires backpropagation at serving time and degrades on long histories. We introduce CLAM (Carried Latent Adapter Memory), which combines the strengths of both: a recurrent hypernetwork performs parametric consolidation, compiling a stream of session activations into a low-rank adapter in a single forward pass with no gradient steps and no language-model generation calls, while a complementary episodic buffer supplies verbatim detail at inference. A gated latent state carries knowledge across sessions in fixed size, so the parametric memory accumulates without growing. On LoCoMo and LongMemEval-S across three open models (2-7B parameters), CLAM leads all agentic baselines by 1-45 points and all gradient-based parametric methods by 10-45 points, while requiring zero generative LLM calls, zero gradient steps, and 3-151x less wall-clock time than extraction systems to build its memory. The two channels are complementary: the consolidated adapter adds 12-15 accuracy points when the episodic buffer misses the gold evidence, and still adds 4-5 points even with an oracle buffer.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- 现有主流 LLM 智能体记忆系统（如 Mem0、A-Mem、Generative Agents、MemoryBank、SimpleMem）本质上只做“情景记忆”：把对话历史提取成文本、摘要、知识图谱，查询时再检索回上下文。模型参数不发生任何变化，每次查询的出发点都一样。
- 这种纯检索式方案存在根本缺陷：提取错误会累积；从未被显式写出的跨会话隐含模式（如用户偏好、长期结构、渐进变化）无法被单个片段检索出来；记忆构建成本随对话数量不断增长，且需要大量生成式 LLM 调用。
- 另一条路线是测试时微调（如 TMEM、TLM、Test-time LoRA），虽然能改变权重，但需要在线反向传播，且论文实验表明其在长历史上会退化（梯度噪声、过拟合早期会话）。
- 论文从生物学的互补学习系统理论出发，提出长期记忆应包含一个快速、无损的情景存储和一个缓慢、有损但可泛化的语义/参数存储。CLAM 的目标就是把“参数化巩固/语义存储”这一缺失部分补上：用单个前向传播把会话流编译成低秩适配器，无需梯度步骤，并让参数记忆在固定大小状态中持续累积。

## 2. 论文提出的方法论：CLAM

### 2.1 整体框架
- CLAM 由两个互补通道组成：
  - **巩固通道（参数化）**：循环超网络 \(H_\phi\) 将会话流 \(S_{1:N}\) 编译为低秩适配器 \(\Delta W = H_\phi(S_{1:N})\)，答案使用“冻结基础模型权重 + 适配器”生成。
  - **情景缓冲区（非参数化）**：查询时检索最相关的历史片段 \(C = \text{Buffer}(q, S_{1:N})\)，提供逐字细节。
- 最终生成公式：
  \[
  y = f_{\theta+\Delta W}(q, C)
  \]
  其中 \(\theta\) 是冻结的基础模型权重，\(\Delta W\) 是超网络输出的适配器，\(C\) 是检索到的上下文。

### 2.2 巩固通道的三个阶段
1. **Read（读取）**：
   - 将会话 \(S_t\) 输入冻结基础模型，收集每层隐藏状态 \(Z_t \in \mathbb{R}^{L \times |S_t| \times d}\)。
   - 使用 Perceiver 交叉注意力块把 \(Z_t\) 压缩到一个固定大小的工作状态 \(m\) 个隐槽中，每个槽独立池化会话信息。

2. **Carry（携带）**：
   - 维护跨会话的状态 \(Q_t \in \mathbb{R}^{m \times d}\)，通过门控循环更新：
     \[
     g_t = \sigma(W_g[x_t; Q_{t-1}] + b_g)
     \]
     \[
     Q_t = \text{LN}\left((1 - g_t) Q_{t-1} + g_t x_t\right)
     \]
   - 其中 \(x_t\) 是当前会话经过读入和槽间自注意力重新组织后的结果。
   - 门控使不同槽位可以保留长期稳定事实，也可以被新证据覆盖；LayerNorm 防止长流上的数值漂移。
   - 槽间仅在一个会话边界处通过自注意力交换信息。

3. **Decode（解码）**：
   - 用单个 Perceiver decoder 块把最终状态 \(Q_N\) 映射为适配器权重。
   - 每个 \((层, 秩索引)\) 对应一个输出查询，解码为秩-1 组件，最终适配器为：
     \[
     \Delta W_\ell = \alpha B_\ell A_\ell, \quad A_\ell \in \mathbb{R}^{r \times d_{ff}},\; B_\ell \in \mathbb{R}^{d \times r}
     \]
   - 应用于每个 transformer block 的前馈下投影 `down_proj`，秩固定为 \(r=8\)，不随会话数增长。

### 2.3 情景缓冲区
- 使用轻量句子编码器（all-MiniLM-L6-v2）对会话切片（按轮次边界切分，每片最多 1800 字符）进行嵌入。
- 查询时通过余弦相似度取 top-k（\(k=5\)）片段，预算约 7K token，并按时间顺序排序。
- 该缓冲区不改变模型权重，只提供局部证据。

### 2.4 推理与训练
- 推理时：加载缓存的适配器；检索 top-k 片段；合并 \(\theta' = \theta + \Delta W\)；生成答案。每用户一次超网络前向，之后所有查询复用适配器。
- 训练方式：上下文蒸馏。教师模型带完整历史回答问题，学生模型（基础模型仅加超网络生成的适配器、不带历史）最小化教师答案的交叉熵损失：
  \[
  \mathcal{L}(\phi) = \mathbb{E}_{(S,q,y) \sim \mathcal{D}}\left[-\log p_{\theta+H_\phi(S)}(y \mid q)\right]
  \]
  加上小的适配器幅度惩罚。仅更新超网络参数 \(\phi\)，基础模型冻结。
- 训练分两阶段：
  - Stage 1：从已有的单文档到适配器检查点（Doc-to-LoRA）初始化，新增循环机制初始化为无操作。
  - Stage 2：在多会话序列（3–30 个会话）上训练累积与门控，使用截断 BPTT 控制激活内存。

## 6. 论文的主要结论与发现

- **主结果**：
  - 在 LoCoMo 上，CLAM 比最强智能体系统 Mem0 分别领先 6.0（Gemma）、1.2（Qwen）、12.0（Mistral）个点；除 Mem0 在 Qwen 上领先但不显著外，CLAM 在所有三个基础模型上领先其他智能体基线 1–45 个点。
  - 在 LongMemEval-S 上，CLAM 在 Gemma 和 Mistral 上领先所有智能体基线，在 Qwen 上落后 Mem0 但差距不显著。
  - 相比所有基于梯度的参数化方法，CLAM 领先 10–45 个点。
  - CLAM 构建记忆时 0 次生成式 LLM 调用、0 梯度步骤、0 生成 token，墙钟时间比提取系统少 3–151 倍。
- **双通道互补性**：
  - 仅巩固通道得分较低（约 22–24%，LoCoMo），但加上情景缓冲区可大幅提升；反之，在情景缓冲基础上加巩固适配器可再提高 7–11 点。
  - 当缓冲区未检索到黄金证据（约 36% 问题），适配器单独贡献 12–15 点；即使缓冲区是 oracle，适配器仍贡献 4–5 点，说明权重携带的是跨会话整合信息而非重复索引。
- **长历史扩展性**：
  - 巩固通道在历史变长时保持平稳，而 FT-Ceiling 随证据深度下降（每 10 个会话损失约 2.2 点）。
  - 在 16–192 个 chunk 的受控扩展中，CLAM 保持稳定，适配器在每一长度上比纯缓冲区高 6–11 点，测试时训练仍低于 5%。
- **消融结论**：
  - 丢弃携带状态会损失 4.8–5.2 点；无门控覆盖也会降分；随机适配器得分接近 0。
  - 缓冲区单位越粗越好，因为细粒度切分会丢失消歧上下文。

## 7. 优点

- **创新性**：首次实现 LLM 长期记忆的“即时权重空间巩固”，用超网络单次前向代替在线梯度训练，兼具参数化持久性与推理级速度。
- **与生物互补学习系统理论对应清晰**：参数化缓慢语义存储 + 快速情景缓冲，且实验证明两者确实互补。
- **极低的构建成本**：记忆构建零生成调用、零梯度步骤，对大规模部署非常友好；适配器固定大小（约 7 MB 半精度），不随会话增长。
- **长历史稳定**：门控潜在状态和固定秩设计避免了测试时训练在长历史上退化的问题。
- **实验严谨**：三个基础模型、两个基准、多个基线，以及判官独立性、Cover-EM、解码方差等稳健性检验充分；使用了 bootstrap 置信区间。
- **数据管道可扩展**：提出自动化六阶段合成数据管道，可生成约 90 万条记忆依赖轨迹，填补了长期记忆训练数据不足的空白。

## 8. 不足与局限

- **应用范围有限**：仅在两个英文对话记忆基准、2–7B 开源模型上验证；更大规模模型、其他语言、非对话历史（文档、代码）尚未测试。
- **未给出训练总时长/总算力明细**：论文仅说明单卡 A100-80GB 和检查点步数，未报告合成数据生成与超网络训练的总 GPU 小时，外部难以直接复现成本。
- **超网络与基础模型绑定**：每个基础模型需单独训练超网络，未见跨模型迁移或零样本泛化实验。
- **合成数据偏差**：训练数据全部由 Llama-3.3-70B-Instruct 生成，判官也来自同一模型家族，尽管有独立判官验证，但语料风格和任务分布可能存在偏置。
- **适配器容量固定**：论文假设低秩固定状态足以承载长期记忆，但面对海量用户事实或极长历史（远大于当前）时，可能存在容量瓶颈；论文提到扩展秩和超网络规模可改善，但未做验证。
- **情景缓冲区实现较简单**：只用了轻量句子嵌入 + 余弦 top-k，虽消融显示具鲁棒性，但更强检索器可能进一步改变两通道贡献的比例。
- **评估基于静态问答召回**：未在真实动态交互、多轮推理或主动记忆更新场景下测试智能体行为。
