## 摘要
一条已存储记忆是否能帮助回答用户问题，往往取决于世界知识而非表面相似性。Jetriever 用全池效用评分取代相似性搜索：给定查询，它使用 Jev——一个由 LLM 衍生的 System One 决策模型——为每条已存储记忆打分，估计其对答案有用的概率，并直接按这些概率对记忆池排序。在 InMind 的 125 个间接查询任务上，Jetriever 在 84.8% 的情况下将黄金对话置于首位（相比之下，BM25 为 1.6%，采用用户轮次索引的 MiniLM 为 0.0%），端到端 Application 达到 76.0%，而已发表的检索与记忆系统最高仅为 16.0%。一项受控的 20 问对比将“识别隐式证据”与“正确排序”分开考察：Jev 和 Qwen3.5-9B 都能在前 50 名中找回 90% 的黄金对话（相比之下，基于 BERT 的决策模型 Laya 为 30%），但在第 1 名上，Jev 达到 85%，而 Qwen3.5-9B 降至 40%。在按维度比例抽取的 60 个 MemoryAgentBench 问题随机样本上，Jetriever 将四维平均得分从 44.3%（ReFind）提升到 55.4%，平均检索成本为每个 InMind 查询 0.00834 美元、每个 MAB 查询 0.03103 美元。这些结果共同表明，有效的效用检索关键在于结合广泛的世界知识、经过校准的排序概率以及可负担的全池评估。

## Abstract
Whether a stored memory helps answer a user's question often depends on world knowledge rather than surface similarity. Jetriever replaces similarity search with full-pool utility scoring: given a query, it uses Jev, an LLM-derived System One decision model, to score every stored memory for the probability that it is useful to the answer, ranking the memory pool directly by those probabilities. On InMind's 125 indirect-query tasks, Jetriever places the gold exchange first in 84.8% of cases (versus 1.6% for BM25 and 0.0% for MiniLM with user-turn indexing) and reaches 76.0% end-to-end Application, compared with at most 16.0% across published retrieval and memory systems. A controlled 20-question comparison disentangles recognizing implicit evidence from ranking it properly: Jev and Qwen3.5-9B both recover 90% of gold exchanges within the top 50 (versus 30% for the BERT-based decision model Laya), yet at rank 1 Jev reaches 85% while Qwen3.5-9B drops to 40%. On a dimension-proportional random sample of 60 MemoryAgentBench questions, Jetriever raises the four-dimension average from 44.3% (ReFind) to 55.4%, at a mean retrieval cost of USD 0.00834 per InMind query and USD 0.03103 per MAB query. Together, these results show that effective utility retrieval hinges on combining broad world knowledge, calibrated ranking probabilities, and affordable full-pool evaluation.

## 1. 论文的核心问题与整体含义

- **研究动机**：智能体记忆检索长期沿用文档搜索的“相似度”逻辑——根据查询与记忆的表面词汇或嵌入相似度来召回内容。当问题明确提及相关实体时，BM25、稠密检索等方法表现良好；但当记忆的价值来自**隐式关联与外部世界知识**时，相似度检索会失效。
- **核心盲点**：例如用户曾说过“我对坚果过敏”，之后询问“马卡龙食谱”。查询与记忆之间没有共同词汇，但马卡龙通常含杏仁粉，属于坚果，因此该记忆对回答至关重要。相似度检索无法建立这种联系，而答案生成阶段的 LLM 也看不到未召回的隐式证据。
- **整体含义**：Jetriever 提出将智能体记忆检索的目标从“相似性”转向“效用性”：不再问“哪条记忆听起来像查询”，而是问“哪条记忆能真正改善对当前查询的回答”。这需要模型具备**广泛世界知识**、**校准的排序概率**和**可负担的全池评估成本**。

## 2. 方法论

- **核心思想**：放弃相似度索引和查询扩展，直接对记忆中所有候选单元（全池）逐一评分其对查询的效用，然后按效用概率排序。
- **关键技术细节**：
  - 使用 **Jev**：一个由 LLM 衍生的 System One 决策模型，经 **RLCD（强化学习校准决策）** 训练，能够返回结构化概率而不进行自回归文本生成。
  - Jev 提供多种决策原语，Jetriever 使用其中的 **Noul**（二元概率判断），对每个查询-记忆对输出概率 \(s(q, m_i) \in [0,1]\)，表示该记忆对生成正确、个性化回答是否有用。
  - 对 InMind，判断标准为：“该记忆块是否包含回答用户查询所需的个人信息，包括间接相关信息？只判断该块本身的贡献，不要依赖块外信息。”
  - 排序公式：
    \[
    \pi_q = \arg\sort_i(-s(q, m_i), \text{id}(m_i)),\quad M_k(q)=\{m_{\pi_q(1)}, \dots, m_{\pi_q(k)}\}
    \]
    即按效用概率降序排列，概率相同则用候选 ID 破除平局；取前 \(k\) 条原始记忆直接送入下游答案模型。
  - 与传统两阶段重排不同：Jetriever **不先用 BM25 或嵌入做短列表过滤**，因为相似度过滤会提前丢弃隐式关联的关键记忆。
- **方法需求**：作者认为全池效用评分要求评分器同时具备三点：
  - **广泛世界知识**：来自 LLM 预训练基础；
  - **校准的排序概率**：区分决定性证据与宽松相关的背景对话；
  - **可负担的全池评分**：无需生成式解码，支持高并发批量判断。

## 6. 主要结论与发现

- **InMind 检索**：Jetriever 在 84.8% 的任务上将黄金对话排第 1，R@5 达 92.0%，R@10 达 94.4%；BM25 和 MiniLM 的 R@5 最高仅 4.8% 和 2.4%。

- **候选粒度**：以整段会话（47 候选）替代逐条对话（241 候选）会令 R@1 从 84.8% 降至 49.6%，说明细粒度候选有利于突出关键事实。
- **MAB-60**：Jetriever 四维宏平均 55.4%，高于 ReFind 的 44.3%，且在所有四个维度均领先；但多跳选择性遗忘（FC-MH）仍然困难。
- **世界知识与校准的区分**：在受控 20 问中，Jev 和 Qwen3.5-9B 都能在前 50 中找回 90% 的黄金对话，而 Laya 仅 30%；但在第 1 名，Jev 达 85%，Qwen3.5-9B 仅 40%。这表明：
  - **广泛世界知识决定能否在宽候选范围内识别隐式证据**；
  - **校准概率决定证据能否排到第 1**。
- **成本结论**：全池效用评分在数百至约千条候选规模下，成本仅为每个查询约一至三美分，具有实际可用性。

## 8. 不足与局限

- **线性扩展瓶颈**：全池评分是 \(O(N)\)，对于终身智能体积累数十万条记忆时，成本与延迟会显著增长。
- **预过滤不可行**：作者承认若引入 BM25/嵌入预过滤会重新引入相似度盲点，因此只能依靠开发更轻量、仍保留世界知识的决策模型，但这一方向尚未实现。
- **MAB 评估规模小**：仅 60 题样本（作者也说明预算有限），LRU 仅 3 题，统计稳定性不足；无法跑完整 3,671 题池。
- **基线对比条件不完全一致**：MAB 中部分已发布基线是完整基准分数，而 Jetriever 只在 60 题子集上评测，直接并列表格可能带来误导。
- **依赖外部专有模型 API**：Jev 由 TypeSafe 提供，训练细节、算力、成本结构未完全公开，限制可复现性。
- **未充分测试不同答案模型**：端到端实验仅使用 GPT-5-mini 和 GPT-4o-mini；不同下游 LLM 对检索排序的鲁棒性有待验证。

## 9. 总体评价与未来方向

- **贡献总结**：Jetriever 将记忆检索从相似性范式推进到效用性范式，提出全池效用评分和校准概率决策模型，解决了隐式关联记忆的关键盲点。在 InMind 和 MAB 上均取得显著提升，且检索成本可控。
- **适用场景与边界**：适用于候选记忆规模在数千条以内、需要高精度个性化回忆的智能体场景；不适用于需要实时检索百万级记忆库或对延迟极度敏感的场景，除非替换为更轻量的效用评分模型。
- **未来工作方向**：
  - 将全池效用评分扩展到更大规模记忆，例如结合分层结构、记忆聚类或可微索引，同时避免相似度预过滤的信息损失。
  - 开发开源、可训练、保留世界知识且支持高并发概率输出的轻量决策模型。
  - 在更大规模、更多维度的记忆基准上进行完整评测，增加统计显著性与鲁棒性验证。
  - 测试不同下游答案模型对排序误差的容忍度，以及检索结果与生成质量的联合优化。
  - 探索如何将效用评分与记忆写入、总结、遗忘机制结合，形成闭环记忆管理系统。
- **对领域的启示**：传统检索假设“查询与证据表面相关”，但个性化记忆的价值常来自“外部知识 + 用户历史”的隐式联结；智能体记忆系统需要重新思考索引结构，从相似性索引转向效用评估或混合方案。
