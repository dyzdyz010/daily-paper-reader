## 摘要
大型语言模型智能体在记忆中积累经验，而记忆在交互过程中如何演化与其存储的内容同样重要。近期方法在线更新记忆，但无论是转换记忆的算子还是选择算子的规则在设计上均保持固定。我们提出 EvoDisco，将智能体记忆演化形式化为演化式策略发现：智能体必须发现应用哪个算子、何时应用以及如何实例化，而不是在静态算子调度下重写记忆。一个可学习策略以当前记忆状态和近期任务历史为条件，选择并实例化四种语义算子之一——抽象（Abstract）、精炼（Refine）、桥接（Bridge）和重构（Reframe）——它们分别压缩相关记忆、分解过载条目、连接弱关联经验，并重组检索到的推理链。该策略通过双层适应度更新。内层信号利用以记忆复杂度正则化的检索质量提升来对每次变换评分。外层信号在过去决策窗口上评估策略效能，结合历史算子效用遗憾、效用预测误差和选择多样性。在 ALFWorld、WebShop 和 LifelongAgentBench（OS 与 DB）上的单遍在线加冻结迁移协议下，EvoDisco 相较于包括 MemP 和 MemRL 在内的强记忆基线取得改进。最大增益出现在 ALFWorld（在线 +8.8 / 冻结迁移 +12.9 分，相较于 MemP；相较于 MemRL 为 +16.4 / +17.9）。消融实验将这些增益归因于两个适应度层级和算子库。

## Abstract
Large language model agents accumulate experience in memory, and how that memory evolves during interaction is as important as what it stores. Recent methods update memory online, yet both the operators that transform memory and the rules that select them remain fixed by design. We propose EvoDisco, which formulates agent memory evolution as evolutionary strategy discovery: the agent must discover which operator to apply, when to apply it, and how to instantiate it, rather than rewriting memory under a static operator schedule. A learnable policy conditions on the current memory state and recent task history, then selects and instantiates one of four semantic operators---Abstract, Refine, Bridge, and Reframe---which respectively compress related memories, decompose overloaded entries, connect weakly linked experiences, and reorganize retrieved reasoning chains. The policy is updated with a bi-level fitness. An inner signal scores each transformation using a retrieval-quality improvement regularized by memory complexity. An outer signal scores strategic efficacy over a window of past decisions, combining historical operator-utility regret, utility-prediction error, and selection diversity. Under a one-pass online plus frozen-transfer protocol on ALFWorld, WebShop, and LifelongAgentBench (OS and DB), EvoDisco improves over strong memory baselines including MemP and MemRL. The largest gains are on ALFWorld ($+8.8$ online / $+12.9$ frozen-transfer points over MemP; $+16.4$ / $+17.9$ over MemRL). Ablations attribute these gains to both fitness levels and the operator library.

# EvoDisco: Strategy Discovery for Evolving Agent Memory 论文总结

## 1. 核心问题与整体含义

- **研究动机**：大语言模型（LLM）智能体在长周期、多轮交互任务中需要积累、保留并复用经验，但仅靠上下文窗口会导致相关信息被稀释或遗忘。记忆系统因此成为 LLM 智能体的核心模块。
- **现有局限**：近期研究从平面向量检索转向结构化记忆（如图知识图谱），但多数系统的记忆结构在初始构建后保持静态。少数支持记忆演化的方法（如 HAGE、MemEvolve）仍然使用固定的演化算子或人工设计的适应机制。
- **核心问题**：如果智能体能够对自身记忆进行推理，为什么记忆演化方式要由人类设计者预先指定？本文提出将记忆演化重新定义为**演化策略发现**：智能体需要学习在何时、应用何种、如何实例化记忆变换算子，而非在固定算子调度下重写记忆。
- **整体含义**：EvoDisco 把记忆演化从“固定规则下的记忆重写”提升为“状态条件下的策略选择与实例化”，让智能体自主发现适合当前记忆状态和任务历史的演化策略。

## 2. 方法论

### 2.1 问题建模与记忆表示

- 智能体维护一个有向多关系记忆图 \(G=(V,E)\)。节点存储事实、情节摘要、程序或概念，并包含嵌入、时间戳、置信度、检索计数等属性。边为类型化关系（如 `causes`, `precedes`, `analogous-to`, `is-a`, `generalizes`），带权重和证据新近度。
- 目标函数为 \(F(G)=\mathbb{E}_{t\sim\mathcal{T}}[\text{score}(t;G)]\)，即任务分布上的期望得分。
- 在演化事件 \(i\)，智能体编码当前图状态和近期历史为状态 \(s_i\)，然后选择并执行动作 \(a_i=(o_i,c_i,\theta_i)\)，其中 \(o_i\in\mathcal{O}\) 是算子，\(c_i\) 是候选索引，\(\theta_i\) 是实例化参数。图更新为 \(G_i^+=T_{o_i}(G_i;c_i,\theta_i)\)。
- 状态 \(s_i\) 包含四组特征：图统计量（节点/边数、平均度、模块度、路径长度）、检索统计量（延迟、命中率、检索节点多样性）、近期结果（最近算子选择与效用、最近观测得分 \(y_j\)）、结构缺陷摘要（高度节点、断连分量、长路径）。

### 2.2 认知算子库

设计四个语义级变换算子，策略学习其选择与实例化：

- **抽象（Abstract）**：将相关记忆压缩为高层次概念或可复用程序，并通过 `generalizes` 边连接到支持记忆。
- **精炼（Refine）**：将过载记忆沿时间、因果或类别维度分解为更细粒度单元。
- **桥接（Bridge）**：识别语义相关但连接薄弱的记忆区域，生成类型化关系连接它们。
- **重构（Reframe）**：保持节点文本不变，仅沿某条路径重写 `causes` 和 `precedes` 边，重新组织推理链的逻辑顺序。

执行器为每个算子通过固定规则生成最多 8 个候选，并为空候选集的算子做掩码。策略还抽样五个类别头：邻域半径 \(k\in\{1,2,3\}\)、剪枝水平 \(p\in\{0,0.5\}\)、子节点数 \(m\in\{2,3,4\}\)、分解维度、逻辑框架。冻结 LLM 仅在算子、候选和参数确定后为抽象、精炼、桥接生成新文本；重构调用仅返回重定向。

### 2.3 双层适应度框架

反馈在两个时间尺度上运作：

- **内层即时效用（Immediate Utility）**：对单次图变换 \(G_i\to G_i^+\) 定义
  \[
  U_i = \alpha\, \Delta F_i - \beta\, \big(C(G_i^+)-C(G_i)\big)
  \]
  其中 \(\Delta F_i\) 是检索质量代理变化 \(\Delta Q_i = Q(G_i^+; \mathcal{Q}_i)-Q(G_i;\mathcal{Q}_i)\)，基于此前已观察到的查询缓存计算；\(C(G)\) 是结构复杂度（节点数、边密度、路径长度统计的线性组合）。未提交编辑的尝试记录 \(U_i=-0.05\)。变换后的图无论效用正负都保留，无基于效用的回滚。
- **外层战略效能（Strategic Efficacy）**：每隔 \(N\) 次尝试，基于最近 \(K\) 次尝试窗口计算
  \[
  E_i = -\gamma\,\text{Regret}_i - \delta\,\text{PredErr}_i + \eta\,\text{Div}_i
  \]
  其中 Regret 是算子效用遗憾（与最近 \(h=8\) 次执行平均效用的差距正部），PredErr 是效用预测误差，Div 是算子选择熵（对多样性的软偏好）。
- 效用预测器 \(q_\psi(s_i,a_i)\) 在动作执行前记录预测值，用于计算预测误差；正效用状态-动作对进入回放缓冲，用于辅助监督更新。

### 2.4 策略学习

- 策略 \(\pi_\phi(a|s)=\pi_\phi(o|s)\,\pi_\phi(c|s,o)\,\pi_\phi(\theta|s)\) 由两层 MLP 参数化。
- 每 \(N\) 次尝试，使用得分函数更新（REINFORCE 风格）：
  \[
  \nabla_\phi J_i = \mathrm{sg}(E_i)\sum_{\ell\in B_i}\nabla_\phi \log \pi_\phi^w(a_\ell|s_\ell)
  \]
  其中 \(B_i\) 是自上次策略更新以来的新事件。旧事件只用于计算 \(E_i\)，不作为新样本。
- 加权对数概率中对五个实例化头的对数概率乘以固定因子 \(1/4\)。
- 效用预测器通过监督回归训练，正效用样本进入重放缓冲进行辅助策略更新。

### 2.5 在线学习与评估协议

- 在线阶段：智能体单遍处理训练流，每个回合后写入记忆。演化仅在前 80% 回合内启用；触发机制为每 \(T=10\) 回合或最近 10 回合得分移动平均下降超过 \(\epsilon=0.15\)。
- 冻结迁移阶段：在线阶段结束后冻结所有记忆状态（包括检索），在留出集上评估，不进行写入或演化。
- 跨基准策略迁移：允许将源基准（ALFWorld）学到的策略 MLP 权重固定，用于目标基准从头构建记忆图，但不转移记忆图本身。

## 3. 实验设计

### 3.2 协议与指标

- **在线 SR（Runtime Learning）**：训练流全过程的成功率。

### 3.3 对比方法

- **No Memory**：仅基于当前回合信息，无跨回合记忆。
- **RAG**：基于嵌入检索最近笔记。

## 6. 主要结论与发现

- EvoDisco 在全部四个基准上取得最高在线 SR 和冻结迁移 SR。

- OS 上相较 MemP 在线 +2.3、迁移 +1.3；WebShop 和 DB 增益较小（迁移分别 +1.0 和 +0.8）。
- 记忆并非在所有环境都带来提升：DB 上若干记忆基线低于 No Memory，而 EvoDisco 在线 88.4% vs No Memory 88.1%，迁移 87.1% vs 84.9%，仅略高或小幅提升。
- 消融表明**两个适应度信号和认知算子库均重要**：移除外层适应度使 ALFWorld 迁移 SR 下降 7.9 点，移除内层下降 9.3 点，移除认知算子下降 6.5 点。

- 成本分析显示 EvoDisco 墙钟时间低于或接近 MemRL 和 No Memory，未引入明显额外算力负担。
- 定性编辑展示了抽象生成的元策略在后续任务中被唯一检索并成功执行，精炼生成的子程序在后续任务中帮助快速完成。

- **统计严谨性不足**：无多次运行、方差、置信区间或显著性检验，部分小差距可能不稳健。
- **单骨干与单源迁移**：仅在 GPT-5-mini 上验证；跨基准迁移只用 ALFWorld 作为源，未设置未训练选择器对照，迁移结论有限。
- **算子库固定**：只有四个预定义算子，不能发现新算子类别，限制策略发现空间。
- **触发机制为启发式**：演化触发依赖固定间隔和移动平均下降阈值，不是学习得到的。
- **效用代理的局限**：内层效用使用图局部检索质量代理，不是对 \(F(G)\) 的无偏估计；复杂度权重为人工设定。
- **环境偏差风险**：WebShop 和 DB 上增益很小，且记忆在某些基线（DB）上甚至有害，需要更多环境验证。
- **可扩展性未知**：大规模图、多任务流、更长周期下的表现及策略稳定性未验证。
