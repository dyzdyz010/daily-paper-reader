## 摘要
除了记忆存储与检索之外，长期LLM智能体系统中的一个根本挑战是：当已存储的记忆与不断演变的世界发生冲突时，智能体应如何行动。事实往往在没有显式删除的情况下过时，因此冲突会在存储被刷新之前显现：延迟反馈表明，依据某条过时记录采取行动会带来损失，但并未说明抑制应仅限于该事实（局部策略），还是扩展到其他已存储事实（全局策略）。现有系统在设计时硬编码了其中一种作用范围。我们将这种在隐藏有效性和延迟反馈下的在线选择形式化为记忆冲突治理，并提出 RegimeCouncil——一种轻量级路由器，它保留两种作用范围作为顾问，并在它们之间进行仲裁，而无需重新训练LLM。每个借助记忆的响应都会与一个无记忆锚点进行评分，评分方式为离路径配对比较，或仅根据所执行动作的逆倾向估计。局部顾问仅追踪被查询的事实，全局顾问汇聚存储中近期的结果，而非对称的元治理器默认遵循局部顾问，只有当汇聚产生严格为正的近期效用边际时才切换到全局顾问。我们证明，使用延迟结果可以突破仅提示策略的后悔下界；任一固定作用范围单独使用都不足够；并且该边际门控会在有界时间内切换。在 LongMemEval 数据流、TempLAMA 和 TAQA 的历史漂移、延迟 τ∈[1, 96] 以及稀疏或赌博机反馈条件下，使用 Qwen3-30B-A3B 和 GPT-4o，RegimeCouncil 在所有30个留出设置中均优于较好的固定作用范围：在分歧片段上高出5.2–7.3个百分点，在聚类漂移下比独立的冷启动回退方案高27.9个百分点，同时以微秒级开销减少有害的过时记忆使用。

## Abstract
Alongside memory storage and retrieval, a fundamental challenge in long-term LLM agent systems is how the agent should act when stored memories conflict with an evolving world. Facts often go stale without explicit deletion, so the conflict surfaces before the store is refreshed: delayed feedback shows that acting on one outdated record hurt, but not whether suppression should stay on that fact (a local policy) or extend to other stored facts (a global policy). Existing systems hard-code one of these scopes at design time. We formulate this online choice, under hidden validity and delayed feedback, as memory conflict governance, and propose RegimeCouncil, a lightweight router that keeps both scopes as advisors and arbitrates between them without retraining the LLM. Each memory-assisted response is scored against a no-memory anchor, by off-path paired comparison or by inverse-propensity estimation from the executed action alone. A Local Advisor tracks only the queried fact, a Global Advisor pools recent outcomes across the store, and an asymmetric Meta Governor follows Local by default, switching to Global only when pooling yields a strictly positive recent utility margin. We prove that using delayed outcomes escapes the prompt-only regret floor, that neither fixed scope suffices alone, and that this margin gate switches within bounded time. On LongMemEval streams, historical drift in TempLAMA and TAQA, delays $τ\in [1, 96]$, and sparse or bandit feedback, with Qwen3-30B-A3B and GPT-4o, RegimeCouncil outperforms the better fixed scope in all 30 held-out settings, by 5.2-7.3 points on disagreement episodes and +27.9 points over standalone cold-start fallback under clustered shifts, while cutting harmful stale-memory use at microsecond overhead.

## 1. 论文的核心问题与整体含义

- **核心问题**：长期 LLM 智能体系统中，存储记忆会随着世界变化而“静默过时”（silent staleness）。延迟反馈（如用户抱怨、任务失败）只能说明“使用某条记忆造成了损失”，却无法直接说明：抑制范围应**局限于该条事实**（局部策略）还是**扩展到整个记忆库**（全局策略）。
- **研究动机**：
  - 现有记忆系统在**写入时**更新或覆盖记忆，但实际部署中记忆常在存储刷新之前就已过时，冲突发生在“预整合窗口”（pre-consolidation window）。
  - 现有系统在设计时**硬编码固定作用范围**：局部策略能避免跨事实干扰但无法应对相关漂移和冷启动；全局策略能快速阻止集群性失效但可能因少数易变事实禁用稳定的有效记忆。
  - 因此需要一个**在线、无需重训 LLM** 的仲裁机制，在隐藏有效性状态和延迟反馈下动态决定使用局部还是全局证据。
- **整体含义**：将“记忆冲突治理”形式化为一个序贯决策问题，并提出轻量路由器 RegimeCouncil，在微秒级开销下自适应地在两种作用范围之间切换，提升记忆使用准确率并减少有害过时记忆暴露。

## 2. 论文提出的方法论

RegimeCouncil 是一个**三模块路由器**，核心思想是：保留局部和全局两种顾问，通过**无记忆锚点**评分每个历史事件的记忆贡献，再由非对称元治理器进行在线仲裁。

### 2.1 问题形式化

- 记忆库包含 \(K\) 个键（如 city、commute、allergy）。
- 每一步 \(t\) 收到查询键 \(k_t\)，决策时观测 \(z_t\)（用户提示 + 检索到的记忆记录）。
- 隐藏有效性状态 \(r_t \in \{0,1\}\)：当事实静默变化时不包含在 \(z_t\) 中（碰撞上下文，collision）。
- 动作 \(a_t \in \{0,1\}\)：\(1\) 表示注入记忆，\(0\) 表示只用基础模型（无记忆锚点）。
- 反馈延迟最多 \(\tau\) 步，目标最大化期望累积效用 \(J_T = \mathbb{E}[\sum_{t=1}^T u_t]\)，不重训 LLM。

### 2.2 证据评分：成对锚点与赌博机反馈

- 原始任务奖励 \(u_s \in [0,1]\) 混淆了记忆有效性与查询难度。通过**成对效用差**隔离记忆的因果贡献：
  \[
  d_s = u_{s,\text{mem}} - u_{s,0} \in [-1,1]
  \]
  其中 \(u_{s,\text{mem}}\) 为注入记忆的效用，\(u_{s,0}\) 为无记忆锚点效用。\(d_s>0\) 表示记忆有帮助，\(d_s<0\) 表示过时记忆有害，\(d_s=0\) 为平局。
- 支持两种反馈模式：
  - **异步成对模式**：用户首先收到选中动作的响应；延迟反馈到达后，后台离线评估无记忆响应，得到成对效用，不增加用户可见延迟。
  - **仅执行动作的赌博机模式**：只观测到实际执行动作的标量结果，使用 \(\varepsilon\)-探索（\(\varepsilon=0.05\)）构造逆倾向估计：
    \[
    \hat{d}_s = \frac{\mathbf{1}[a_s=1] u_s}{p_s} - \frac{\mathbf{1}[a_s=0] u_s}{1-p_s}, \quad \mathbb{E}[\hat{d}_s \mid h_s] = d_s
    \]
    其中 \(p_s = \Pr(a_s=1 \mid h_s)\) 被裁剪到 \([\varepsilon, 1-\varepsilon]\)。

### 2.3 RegimeCouncil 架构

- **全局顾问（Global Advisor）**：维护最近 \(W_g\) 个已揭示成对差异的滑动窗口，提议使用记忆当且仅当其和严格为正：
  \[
  g_t = \mathbf{1}\left[\sum_{i \in W_g(t)} d_i > 0\right]
  \]
  用于冷启动和集群漂移场景。

- **本地顾问（Local Advisor）**：仅看当前键 \(k_t\) 的最近 \(W_\ell\) 个结果。设计上取 \(W_\ell=1\)，即只跟踪该键最新已揭示差异 \(d_{\text{last}}(k_t)\)：
  - \(d_{\text{last}}>0\) → \(\ell_t=1\)；
  - \(d_{\text{last}}<0\) → \(\ell_t=0\)；
  - 无决定信号（冷启动或平局）时有两种 tie 处理：
    - **RegimeCouncil（保守弃权）**：\(\ell_t=0\)（除非元治理器覆盖）。
    - **RegimeCouncil-TD（平局委托）**：当本地无信号时委派给 \(g_t\)，否则保持本地隔离。

- **元治理器（Meta Governor）**：当 \(g_t \neq \ell_t\) 时，在最近 \(W_m\) 个已揭示事件上计算两个顾问的反事实效用：
  \[
  v_{j,i} = \begin{cases}
  u_{i,\text{mem}} & \text{若顾问 } j \text{ 在事件 } i \text{ 提议使用记忆}\\
  u_{i,0} & \text{否则}
  \end{cases}
  \]
  \[
  A_t = \sum_{i \in W_m(t)} (v_{g,i} - v_{\ell,i})
  \]
  采用**非对称规则**：默认局部，仅当 \(A_t > 0\) 时切换到全局：
  \[
  a_t = \begin{cases}
  g_t & \text{if } A_t > 0 \quad (\text{Global override})\\
  \ell_t & \text{otherwise} \quad (\text{Local default})
  \end{cases}
  \]
- 超参数：\((W_g, W_m)\)，默认 \(W_g=32, W_m=8\)；\(W_\ell=1\) 和阈值 \(0\) 固定。

### 2.4 理论保证

- **命题 1**：在隐藏有效性下，仅基于当前观测的策略存在常数后悔下界 \(\delta = p q \Delta\)（\(p\) 为碰撞频率，\(q\) 为少数状态份额，\(\Delta\) 为碰撞间隔）；重放最近已揭示结果的本地顾问在有限切换和延迟下有界后悔，严格优于仅提示策略。
- **命题 2**：任一固定作用范围都不足够：全局汇聚在多数键占优时会错误分类少数键（线性损失）；本地隔离在稀疏键上因缺少历史无法转移全局证据（线性损失）。
- **命题 3**：当全局与本地效用在 \(W_m\) 个连续已揭示事件上存在 \(\gamma>0\) 的持续边际时，元治理器会选中相应顾问；在延迟 \(\tau\) 下，切换在 \(W_m + \tau\) 步内有界完成。

## 6. 论文的主要结论与发现

- RegimeCouncil 在**所有 30 个留出设置**中均优于更好的固定作用范围，分歧片段增益中位数 +7.3 分（RC）和 +9.8 分（RC-TD），全流增益 +1.9 到 +2.3 分。
- 在**聚类漂移**（Sync-Multi/Sync-Switch）下，RC 相比无元治理器的冷启动回退分歧准确率提升 **+27.9 分**，有害暴露最高减少 59%。
- **真实历史漂移**：TempLAMA 上 GPT-4o 的固定最优范围仅约 66%，RegimeCouncil 维持 83.6%–84.2%；所有 8 个 95% CI 均严格为正。
- **延迟鲁棒性**：保守 RC 的增益受 \(\tau/K\) 缩放影响，在长延迟下可能变负；RC-TD 通过平局委托使所有 126 个池-延迟设置保持正增益（+5.9 到 +12.3 分）。
- **模块必要性**：移除任一模块均降低准确率 2–7 分；移除元治理器最严重（+6.5–6.8 分全流下降，分歧上 17.2–21.8 分）。
- **反馈质量**：在稀疏、噪声、随机延迟、赌博机反馈下仍优于固定范围和对称追踪基线；赌博机模式达到 68.9% 全流准确率，有害暴露减半。
- **理论结论**：延迟结果可突破仅提示策略的后悔下界；固定作用范围单独不足；边际门控在有限时间内切换。

## 7. 优点

- **问题新颖且实用**：聚焦记忆冲突的“预整合窗口”和延迟反馈下的作用范围仲裁，补齐了现有记忆系统写入时更新的空白。
- **方法轻量、无需重训 LLM**：仅基于已缓存生成和 O(1) 滚动和进行在线路由，微秒级开销、零额外关键路径延迟。
- **理论支撑扎实**：三个命题分别对应证据评分器、双顾问、边际门控的设计动机，给出后悔下界、线性分离和有界切换。
- **实验丰富、公平性强**：多数据集、多模型、多延迟、多反馈质量；缓存生成隔离生成方差；冻结超参数避免调参偏倚；非对称元治理器对比多种追踪基线。
- **两种模式灵活适应部署**：异步成对模式和仅执行动作的赌博机模式，可在不同监控条件下使用。

## 8. 不足与局限

- **算力信息缺失**：论文未报告具体 GPU 型号、数量或推理成本，难以评估资源需求。
- **真实漂移基准规模有限**：TempLAMA 120 键、TAQA 100 键，可能不足以覆盖现实世界的复杂漂移模式。
- **人工构造调度的局限**：虽然包含多种调度，但 Block-Switch、Independent-Switch 等仍为合成流，与真实用户记忆漂移的复杂性有差距。
- **理论假设较强**：Assumption 2 要求已揭示比较携带状态最优动作的符号，实际噪声和部分可观测可能破坏这一假设；Proposition 3 未覆盖窗口内边际符号交替或反倾向估计的单轨迹方差。
- **超参数敏感性**：\(W_g\)、\(W_m\) 在开发集上选择并冻结，但不同规模键池或延迟下可能需要调整；文中主要报告固定窗口，实际部署或需重新调优。
- **仅二值动作和单模型评估**：研究的动作仅为“使用/不使用记忆”，未扩展至更细粒度的记忆选择或集成；两个 LLM 均较强，小模型上的迁移效果未验证。
- **反馈模型简化**：真实用户反馈可能非对称、有偏或缺失严重；文中稀疏/噪声/赌博机设置是简化模拟，未覆盖全部现实复杂性。
