## 摘要
基于LLM的智能体在解决复杂、长周期任务时会积累大量交互历史，这使得高效的记忆管理对其性能和可扩展性至关重要。现有的记忆管理方法主要关注保留或检索什么信息，往往忽略了应为单个历史交互分配多少感知细节。我们认为，有效的智能体记忆不仅取决于所保留的信息，还取决于对每次历史交互进行感知的粒度。受此启发，我们提出了分辨率即注意力（Resolution as Attention, RAA），一种记忆感知机制，将视觉分辨率作为跨交互历史分配注意力的手段。RAA 将历史交互渲染为图像，并根据其与智能体即将做出的决策的相关性，在每一步动态调整其分辨率，从而为关键交互保留细粒度信息，同时减少与不太相关的交互的视觉token消耗。为了自适应地确定每次交互的感知保真度，我们通过教师模型引导训练了一个轻量级相关性估计器，并进一步优化它，以在降低视觉token成本的同时保持智能体的决策一致性。在多个任务和骨干模型上的实验表明，RAA 在不影响任务性能的情况下将token消耗降低了50%以上。此外，RAA 可作为即插即用的感知层与现有记忆管理方法集成，进一步节省token，并揭示自适应感知是智能体记忆的一个补充维度。

## Abstract
LLM-based agents accumulate extensive interaction histories when solving complex, long-horizon tasks, making efficient memory management critical to their performance and scalability. While existing memory management methods primarily focus on what to retain or retrieve, they often overlook how much perceptual detail should be allocated to individual past interactions. We posit that effective agent memory depends not only on the information preserved, but also on the granularity at which each past interaction is perceived. Motivated by this insight, we propose Resolution as Attention (RAA), a memory perception mechanism that uses visual resolution as a means of attention allocation across interaction histories. RAA renders past interactions as images and dynamically adjusts their resolution at every step according to their relevance to the agent's upcoming decision, preserving fine-grained information for critical interactions while reducing visual-token consumption for less relevant ones. To adaptively determine the perceptual fidelity of each interaction, we train a lightweight relevance estimator with teacher-model guidance and further optimize it to preserve the agent's decision consistency at a reduced visual-token cost. Experiments across multiple tasks and backbones show that RAA reduces token consumption by over 50% without compromising task performance. Moreover, RAA can be integrated as a plug-in perception layer with existing memory management methods, yielding further token savings and revealing adaptive perception as a complementary dimension of agent memory.

## 1. 论文的核心问题与整体含义

- **研究背景**：基于 LLM 的智能体在长周期任务中会不断累积“推理—动作—观察”交互历史，导致上下文 token 数量持续膨胀，影响性能与可扩展性。
- **现有方法的局限**：主流记忆管理分为两类：
  - **检索型**：如 MemGPT、A-MEM，仅在被检索到时将相关片段放回上下文，未被召回的信息对智能体完全不可见，性能受检索质量限制。
  - **压缩型**：如摘要、剪枝、光学压缩等，通常以统一压缩率或固定策略处理历史，要么不可逆地丢失细粒度信息，要么对无关交互浪费 token、对关键交互细节不足。
- **核心观点**：有效记忆不仅取决于“保留/检索什么内容”，还取决于“每个历史交互以多大感知粒度被读取”。论文由此提出“记忆感知”作为与检索、压缩正交的第三维度。
- **整体含义**：通过把“分辨率”作为注意力分配手段，让智能体对关键历史看得更清楚、对次要历史看得更粗糙，从而在保持决策性能的同时减少视觉 token 消耗。

## 2. 论文提出的方法论

- **总体框架：Resolution as Attention（RAA）**
  - 将每个历史交互 \(h_i\) 渲染为一张规范图像 \(I_i\)。
  - 每一步根据该交互对下一决策的相关性，动态计算分辨率缩放系数 \(s_i\)，再对图像进行缩放后交给智能体感知。
  - 缩放后的视觉 token 数量近似与 \(s_i^2\) 成正比，因此分辨率越低，token 节省越显著。

- **关键组件**
  - **相关性估计器 \(f_\theta\)**：
    - 基于 Qwen3-Reranker-0.6B 初始化。
    - 查询由任务描述 \(D\) 和最新交互 \(h_{t-1}\) 构成。
    - 对每个历史交互 \(h_i\) 独立打分 \(p_i=f_\theta(D,h_{t-1},h_i)\)，输出“yes/no”logits 经 sigmoid 得到相关性概率。
  - **分辨率映射 \(g_\phi\)**：
    - 采用可学习的归一化 sigmoid 映射，将相关性分数映射到 \((0,1]\) 分辨率尺度。
    - 映射单调，保留相关性排序，并确保 \(g_\phi(0)=0\)、\(g_\phi(1)=1\)。
  - **分辨率控制渲染**：
    - 每一步从原始规范图像出发，按当前尺度缩放，避免累积失真。
    - 保留规范图像，随时可恢复关键交互的精细信息，因此是非破坏性感知。

- **两阶段训练**
  - **阶段一：相关性监督**
    - 教师模型（Qwen-3.8-27B）在高质量轨迹上为每个历史交互标注其对下一动作的依赖程度 \(\hat{p}_i\)。
    - 轻量估计器用密度加权 MSE 回归这些评分，学习“决策相关性”而非简单语义相关性。
  - **阶段二：分辨率强化**
    - 将 \(g_\phi \circ f_\theta\) 视为随机策略，围绕预测尺度采样多个候选尺度。
    - 奖励由两部分组成：决策保真度（保留智能体原始动作的对数似然之差）+ \(\lambda(1-s_i^2)\) token 节省项。
    - 用 group relative policy optimization 在候选间归一化优势，优化估计器和映射参数。
  - 智能体本身始终冻结，RAA 训练一次即可迁移到未见过的视觉语言智能体。

## 6. 主要结论与发现

- **Token 节省显著**：在 ClawGym-Bench 上，RAA 相对于 Vanilla 每任务历史 token 分别减少 **57.5%**（Qwen-3.8-27B）、**51.5%**（Qwen-3.6-27B）、**55.9%**（Kimi-K3）。
- **性能基本保持**：三个骨干上 RAA 平均分与 Vanilla 接近，均优于或与基线相当，且每任务 token 数在所有基线中最低。
- **自适应感知有效**：相比统一分辨率或 top-k 文本保留，RAA 能在 token 节省和决策性能之间取得更好平衡。
- **两阶段训练必要**：阶段一提供决策相关性基础，阶段二校准分辨率映射；缺少任何一阶段都会导致 token 上升或性能下降。
- **即插即用互补**：与 ACON、A-MEM、Observation Masking 结合后，进一步节省 22.5%–54.1% 的 token，且性能不下降。
- **视觉感知优于等预算文本剪枝**：在同一交互级预算下，视觉分辨率控制比 LongLLMLingua 文本剪枝少走 14% 步数、分数高 0.97 点。
- **在 AppWorld 上仍具优势**：RAA 取得最低每任务 token，但 OCR 依赖导致分数相对 Vanilla 有所下降，尤其在 Qwen-3.6-27B 上。

## 7. 优点

- **概念创新**：首次将“感知粒度”作为记忆管理维度，用分辨率类比注意力分配，与检索、压缩互补。
- **非破坏性**：保留每个交互的规范图像，可随时恢复关键细节，避免压缩和剪枝的不可逆信息丢失。
- **交互级、决策感知**：每一步对每个历史交互独立打分和缩放，分辨率随任务进展动态变化。
- **轻量、可迁移、即插即用**：估计器仅 0.6B，智能体全程冻结；训练一次可迁移到不同视觉语言智能体，也能与现有记忆管理方法叠加。
- **实验严谨**：多基准、多骨干、多基线、多维消融，包含跨模型迁移和与现有方法集成的验证。
- **低额外成本**：相关性估计和渲染仅占端到端延迟约 2.51%，历史 KV cache 峰值降低约 47.8%。

## 8. 不足与局限

- **任务分布偏重 ClawGym-Bench**：尽管 AppWorld 作为补充验证存在，但论文的核心结论仍主要建立在 ClawGym-Bench 上；该基准的任务类型、界面风格、交互节奏与真实世界 GUI 智能体或移动端任务仍可能存在差异，跨领域泛化能力需要更广泛的基准和真实环境测试。
- **OCR 质量是潜在瓶颈**：RAA 将历史交互渲染为规范图像，因此感知质量高度依赖上游 OCR 的准确性和稳定性；OCR 错误会被带入相关性估计与视觉感知，尤其在 AppWorld 上部分骨干分数相对 Vanilla 下降，说明当 OCR 不准时，即使分辨率分配合理，也可能损害最终决策。
- **教师标注偏置风险**：阶段一的相关性标签由 Qwen-3.8-27B 教师模型生成，而该教师与训练阶段使用的智能体相同；这可能导致估计器学到该模型自身的决策偏好，而非任务本身的客观重要性排序，换用差异较大的智能体时相关性打分可能需要重新校准。
- **训练数据规模与任务多样性有限**：阶段一约 12,000 条决策历史、阶段二 2,400 条自采轨迹，任务数量与类别仍然有限；对于更长周期、跨应用、多跳推理的真实任务，估计器的排序稳健性和分辨率映射的适应性尚缺乏充分验证。
- **连续分辨率的离散化误差**：实际渲染时需要将连续尺度 \(s_i\) 离散到有限的图像宽度/高度集合，可能引入量化误差；虽然报告端到端延迟占比仅约 2.51%，但在历史交互数量极大或需要高吞吐量部署时，渲染与编码开销仍不可忽略。
- **超参数 \(\lambda\) 需任务级调参**：奖励函数中 token 节省项与决策保真度之间的权重 \(\lambda\) 对性能较敏感，论文通过扫描 \(0.5\times10^{-3}\) 到 \(4\times10^{-3}\) 选择；迁移到新任务或新智能体时，可能需要重新调整，削弱零配置即插即用的便利性。
- **评估指标相对单一**：主要关注每任务历史 token、峰值历史 token 和最终混合分数，缺少对中间决策质量、错误恢复能力、长时运行稳定性、崩溃恢复等更细粒度指标的分析；token 数量减少也不完全等价于真实计算成本或延迟降低，因为不同分辨率图像的编码开销并非严格线性。
- **与文本压缩方法的系统对比不足**：虽然与 LongLLMLingua 做了预算匹配对比，但未在相同延迟或计算预算下系统比较更多文本摘要、剪枝、上下文蒸馏方法；视觉分辨率控制对纯文本历史或非视觉智能体的适用性也未被探讨。
- **基线复现存在不确定性**：OCR-Memory 因官方代码未公开而由作者复现，可能与其原始实现存在差异；AgentOCR 等其他基线的实现细节也可能影响对比结论，导致部分对比结果存在一定不确定性。
- **相关性估计的独立打分局限**：估计器对每个历史交互独立打分，未显式建模交互之间的相互依赖或信息冗余；某些关键信息可能由多个交互共同承载，独立打分可能低估或高估单个交互的重要性，影响分辨率分配的全局最优性。
