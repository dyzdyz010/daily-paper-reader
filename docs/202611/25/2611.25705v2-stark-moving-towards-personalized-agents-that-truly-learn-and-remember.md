## 摘要
长期记忆对于长时间与用户交互的个性化智能体系统至关重要，然而当前架构仅捕获发生了什么，而将为什么发生的推理留给底层大语言模型后续推导。然而，这些事件不仅能传达用户经历了什么，还能传达该经历如何塑造了他们的行为模式。我们提出 STARK，一种双图记忆架构，将这些事件不仅视为节点，还视为行为洞察之间的边。STARK 维护一个情节图，将交互记录为在时间、因果和语义上关联的情节；以及一个洞察图，表示由大语言模型提取的行为信号，并根据支持它们的事件数量评分，由导致这些洞察的事件连接。在推理时，行为知识直接从以事件为边的洞察节点中检索，消除了重复的情节遍历。事件作为边的结构也自然支持将知识图投影到关系嵌入空间中，在共享上下文环境下实现跨用户迁移，使系统能够为冷启动用户推断缺失的洞察。评估表明，STARK 在 LongMemEval 信息抽取上比现有最佳水平提高了 1.48 个评委分数，在 LoCoMo 开放域问题上提高了 0.93 个评委分数。在公开的 LongLaMP 摘要生成基准上，跨用户迁移在 5% 图稀疏度下将开放式评委分数提高了 0.7 分，ROUGE-L 提高了 3。

## Abstract
Long-term memory is essential for personalized agentic systems that interact with users over long time periods, yet current architectures only capture what happened while leaving the reasoning of why it happened to be derived later by underlying LLMs. These events can, however, convey not only what a user experienced but also how that experience shaped their behavioral patterns. We introduce STARK, a dual-graph memory architecture which treats these events not just as nodes but also as edges between behavioral insights. STARK maintains an Episodic Graph which records interactions as temporally, causally, and semantically linked episodes; and an Insight Graph which represents LLM-extracted behavioral signals scored by how many events support them, connected by the very events that led to them. At inference, behavioral knowledge is retrieved directly from insight nodes grounded by event-as-edges, eliminating repeated episodic traversal. The event-as-edge structure also naturally enables projecting the knowledge graph into a relational embedding space where cross-user transfer becomes possible under shared contextual circumstances, allowing the system to infer missing insights for cold-start users. Evaluations show that STARK improves by 1.48 judge score on LongMemEval information extraction and 0.93 on LoCoMo open domain questions over state of the art. On the public LongLaMP abstract-generation benchmark, cross-user transfer improves open-ended judge scores by 0.7 points and ROUGE-L by 3 at 5% graph sparsity.

## 1. 核心问题与整体含义

**研究动机：**
- 长期记忆对个性化智能体系统至关重要，但现有架构存在根本性缺陷：它们只记录“发生了什么”（episodic facts），而将“为什么发生”（行为原因）的推理留给底层大语言模型在查询时重新推导，导致推理冗余且不一致。
- 现有记忆系统（如 Mem0、A-MEM、Zep、MAGMA 等）将事件、偏好、约束等作为**未区分类型的节点**共存于单一扁平图中，行为信号（可复用的用户偏好、目标、价值观）分散在事件节点中，无法被直接检索和复用。
- 这种设计还导致每个用户的图是自洽孤岛，缺乏跨用户知识迁移的通道，冷启动用户（几乎没有交互历史）无法获得有效引导。

**核心含义：**
STARK 提出将“事件”与“行为洞察”在记忆架构层面解耦，使行为知识（为什么）成为显式、可评分、可跨用户共享的一等公民，从而让智能体真正“学习并记住”用户的行为模式。


## 2. 方法论

### 2.1 双图架构

STARK 将用户记忆表示为 **Mi = (G_i^E, G_i^I)**：

- **情节图（Episodic Graph）**：捕获用户交互的事实记录。节点类型包括 User、Event、Milestone、Organization 等，边具有时间（followed_by）、因果（led_to, caused）或动作标签，每条边携带时间戳 t(e)。
- **洞察图（Insight Graph）**：捕获行为信号（偏好、约束、目标、价值观等），只有一个固定锚点节点 User。边分为两类：
  - **结构关系**（闭合集合）：`prefers, wants, values, tried, avoids, learned`
  - **事件链接关系**：直接复用情节图中的事件标识符作为边标签，形成“事件即边”的桥梁。

**事件即边（Event-as-Edge）桥接机制：**
- 一条边 `(va, e_id, vb)` 表示“va 与 vb 之间的关系是在事件 e_id 期间观察到的”。
- 这样每个洞察节点都被其形成过程的事件所锚定，无需合并两张图即可双向导航。
- 检索时直接从洞察节点获取行为知识，而不需反复遍历情节图。

### 2.2 证据向量与信号评分

每个非用户洞察节点携带证据向量：

```
ev(v) = (s(v), n(v), w(v), c(v))
```

其中：
- **n(v)**：支持该信号的不同事件数量；
- **w(v)**：结果权重 = 成功支持事件数 / 已解决支持事件数，范围 [0,1]，未解决事件不参与分母；
- **s(v)**（信号强度）：`s(v) = σ(α_s · log₂(1 + n(v)) + λ_s · 1[w(v) > τ_w])`，对证据量取对数增长以获得递减回报；
- **c(v)**（置信度）：`c(v) = σ(α_c · n(v) − λ_c · w(v)(1 − w(v)))`，奖励证据量、惩罚结果不一致。

**矛盾信号处理：** 冲突信号作为独立节点共存，各自携带证据向量，检索时同时呈现并根据证据、上下文和时近性来解决，而非提前消解；若无法判定则明确向用户展示权衡。

### 2.3 跨用户结构迁移

- **关系嵌入空间**：将所有用户的双图合并为统一三元组集合 (h, r, t)，使用 **TransR** 嵌入（实体嵌入 e ∈ ℝ^d，关系嵌入 r ∈ ℝ^k，每关系投影矩阵 M_r ∈ ℝ^{k×d}），评分函数：
  ```
  f(h, r, t) = ‖M_r · e_h + r − M_r · e_t‖²
  ```

- **选择性前缀化**：用户特定实体加前缀（不共享），行为信号实体不加前缀（跨用户共享），使共享信号节点成为跨用户迁移的“缝合点”。事件链接标签合并为单一 `surfaced` 关系以便训练。

- **偏好指纹（Preference Fingerprint）**：
  ```
  fp(u) = Σ_{(u,r,p)∈T_u} w_r · e_p  /  Σ_{(u,r,p)∈T_u} w_r · e_p
  ```
  其中 w_r 是关系信息量权重（`prefers` 高于 `tried`）。用户相似度 = 指纹的余弦相似度，据此从最相似的 m 个用户继承候选信号。

- **实体级链接预测**：冷启动用户缺乏指纹锚定信号时，直接通过链路预测推断缺失信号：
  ```
  predicted(u) = arg min_{p ∉ P_existing} min_{r ∈ R_p} f(seed, r, p)
  ```
  当用户完全无信号时，User 节点本身作为 `prefers` 和 `wants` 关系的种子。

### 2.4 检索流程（Algorithm 1）

1. 从查询中提取实体提及并识别查询意图 τ（behavioral / episodic / mixed）；
2. 若可用，使用 TransR 链路预测增强洞察图，并通过指纹检索相似用户洞察；
3. **洞察检索**：按照 `rank(v) = s(v) · c(v) · (0.5 + w(v))` 排序返回行为信号；
4. **情节检索**：按时间时近性和因果相关性检索事件节点；
5. **桥接遍历**：从行为信号沿事件边回溯到情节图，获取来源事件；
6. **上下文组装**：根据意图 τ 分配预算 B=4000 词元，截断最低分结果。

## 6. 主要结论与发现

1. **双图分离有效**：情节图服务事实性/时间性查询，洞察图服务偏好/行为查询。移除情节图对事实回忆影响巨大（LongMemEval 4.38→2.60），对偏好影响较小；移除洞察图则相反（RealPref 4.19→2.95）。
2. **证据评分在偏好任务中至关重要**：RealPref 开放式得分从 LLM-only 的 2.15 提升到 4.19（+2.04），MCQ 提升幅度较小，说明增益来源于信号的高效排序而非检索更多内容。
3. **跨用户迁移在极端冷启动下效果显著**：在 5% 图稀疏度下，TransR 组合策略实现 2.0/5 分、ROUGE-L 15，对比纯文本的 1.3/12，质量恢复约为 1.5 倍。实体级链接预测在各稀疏度下均占主导。
4. **洞察图节点随历史增长而饱和**：情节图线性增长，洞察图因信号合并而趋于饱和，使读路径保持平坦。
5. **生产部署验证**：记忆开启减少每笔交易的谈判轮次 18%、周期时间 15%，新员工收益约 2 倍于老员工；约 40% 的总体收益来自跨用户迁移。


## 7. 优点

- **创新的“事件即边”桥接设计**：将事件从节点提升为行为信号之间的关系载体，实现了情节与洞察的解耦与可追踪性，概念简洁且优雅。
- **证据评分机制成熟**：结合早期证据计数、结果权重、置信度与强度四个维度，成功处理部分/未解决/矛盾证据，避免早期未完成的证据减弱有效信号。
- **冷启动处理扎实**：提出偏好指纹 + 实体级链接预测的双层迁移机制；链接预测在零信号场景下仍能运行。
- **隐私保护意识强**：跨用户迁移仅共享行为信号节点与嵌入，不共享原始对话记录；遗忘机制通过 DELETE_NODE 和 UNLINK 操作实现，且在下一个全量重训练时清除用户对共享嵌入的贡献。
- **实验可靠性高**：多个基准、严格的消融、实际的 A/B 部署，远超纯学术论文的验证程度；附录补充了成本、治理、提示词库、管道追踪等工程细节。
- **结论诚实**：明确承认 LongMemEval 弃权指标未超越基线，随机匹配有时优于无匹配等意外发现，并进行讨论。


## 8. 不足与局限

- **隐私保护非形式化**：论文承认聚合指纹在成员推理攻击下可能存在的残余泄漏，没有提供正式的差分隐私或其他形式化隐私保证。
- **TransR 容量限制**：每关系投影矩阵的容量固定，随着图密度增加，嵌入质量可能下降；需要周期性全量重训练来接纳新用户和实体。
- **跨域迁移受限**：迁移仅在同域共享目标分布的用户之间有效，无法跨领域迁移（论文明确声明）。
- **证据评分依赖结果标签**：证据评分在 PAL-Bench 和 LongLaMP 上被禁用（数据无结果信号），其优势无法泛化到所有场景；对无标记结果信号的数据，信号只能平均排序。
- **LLM 提取的非确定性**：LongMemEval 中 S2 节点数因 LLM 提取非确定性而波动，可能影响生成质量的一致性。
- **弃权偏见**：LongMemEval 弃权指标未改善，说明检索到的节点与查询实体相似时仍偏置模型作出回答，可能导致幻觉。
- **生产 A/B 规模有限**：仅 40 名经理、600 笔交易、8 周，样本量较小且所有交易均已成交，可能存在选择偏差。
