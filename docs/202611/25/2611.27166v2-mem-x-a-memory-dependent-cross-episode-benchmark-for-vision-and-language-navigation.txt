Abstract — Long-term memory enables embodied agents to reuse past observations across tasks. However, existing cross-episode vision-and-language navigation (VLN) benchmarks of-ten leave it unclear whether successful navigation relies on historical memory or current exploration. We introduce Mem-X, a benchmark designed to evaluate memory-dependent cross-episode VLN. Mem-X organizes episodes into sessions in which subsequent instructions refer to objects or routes encountered in earlier episodes. Its three levels evaluate historical-object recall, in-memory localization and episodic indexing, and off-memory relocalization and historical-route reproduction. For the latter two levels, agents receive episode-local poses but no transformations between episode frames, requiring them to establish spatial correspondence with historical memory. Mem-X comprises 2,071 episodes across 710 sessions in 34 scenes, including 1,204 memory-dependent episodes. We also provide MemBridge, a modular baseline that combines se-mantic scene memory, cross-episode localization, and coarse-to-fine retrieval to support existing VLN agents. Experiments with state-of-the-art VLN methods demonstrate the bene-fits of MemBridge while revealing substantial room for im-provement on memory-dependent navigation. The benchmark and baseline code are available at https://github.com/ NJU-R-L-Group-Embodied-Lab/Mem-X .

I. I NTRODUCTION 

Embodied agents that operate in real environments over long horizons need to retain and use observations and expe-rience from past tasks [1], [2]. When an agent continuously executes tasks in the same scene, different tasks usually share the same locations, and historical memory from preceding episodes can often assist later tasks [1]. Cross-episode mem-ory is therefore necessary. Traditional VLN benchmarks [3]–[8] usually evaluate each episode independently, and an agent’s historical information is used only within the current task, making it difficult to exploit the associations across tasks. Existing cross-episode VLN benchmarks [1], [9] and life-long navigation benchmarks already allow agents to retain and use historical information. However, these benchmarks usually do not make historical memory necessary for com-pleting later tasks. Relying only on the spatial relations and actions suggested by the current instruction, exploration can achieve the same effect. We therefore consider this task design not tightly coupled with the memory mechanism, and it cannot truly evaluate an algorithm’s cross-episode memory ability.

A. Vision-and-Language Navigation Benchmarks 

VLN benchmarks typically evaluate each episode inde-pendently. R2R [3] established the classic setting on the discrete Matterport3D [10] graph; R4R [5] and RxR [4] extended it to longer and multilingual paths. CVDN [6], REVERIE [7], and SOON [8] study dialog, remote-object, and goal-oriented variants, while R2R-CE [11] and LH-VLN [12] move to continuous and long-horizon settings. In all of these benchmarks, historical information remains limited to a single episode. 

B. Cross-Episode Memory and Lifelong Embodied Naviga-tion 

In addition to independent single-episode settings, existing studies have also begun to explore persistent memory across tasks and lifelong embodied navigation. IVLN [1] organizes independent episodes from existing VLN datasets into tours that are executed continuously in the same scene, and allows agents to retain and use historical memory across episodes. GSA-R2R [9] evaluates agents that execute a large number of instructions in the same building and perform scene adaptation. LENL [13] is a continual-learning benchmark across scenes and instruction types. GOAT-Bench [2] extends lifelong embodied navigation from the perspective of multimodal sequential-goal navigation. These benchmarks usually treat historical memory only as auxiliary information, and the completion of later tasks does not necessarily depend on historical memory. Some recent work tries to emphasize historical memory. LMEE-Bench [14] accumulates episodic memory along a single multi-goal exploration trajectory and then tests recall with question answering; the memory dependency occurs in QA rather than in later navigation, and it does not constitute a cross-episode setting. FindingDory [15] first collects long-horizon interactions, then retrieves a target frame from the historical video and navigates back, which evaluates in-trajectory memory recall quite thoroughly. Its history records include pose, and the agent is also equipped with GPS, so it does not require cross-episode self-localization and memory alignment without a shared global pose. C. Memory-Augmented VLN Agents 

Memory in existing VLN methods is typically implicit temporal memory or explicit spatial memory. Implicit meth-ods encode history inside the model, including recurrent hidden states [11], Transformer-based history encoding and caching [16]–[18], state-space recurrent memory [19], [20], and multi-timescale memory [21]–[23]. Explicit methods store memory in external structures, including topological and scene graphs [24]–[26], metric or semantic maps [27]–[29], and waypoint-indexed episodic memory [30], [31]. These mechanisms are mainly used within a single episode, or accumulate maps with pose, and are not designed for memory-dependent tasks across episodes without a shared global pose. III. B ENCHMARK 

A. Task Design 

Mem-X groups navigation episodes into sessions. Agents accumulate experience during initial tasks and use it in subsequent tasks, whose instructions refer to previously encountered objects or traversed routes. We design three levels that progressively extend historical-object recall to cross-episode localization and historical-route reproduction. All levels provide drift-free poses derived from simulator ground truth. Level 1 uses a shared coordinate frame across episodes to isolate historical-object recall from cross-episode localization. Levels 2 and 3 instead express poses in episode-local frames obtained by resetting the simulator pose. Transformations between episode frames are withheld, requiring agents to establish spatial correspondence with historical observations. 

Level 1: In-Trajectory Memory Recall. Each session consists of a base episode, Episode 0, followed by 1–4 memory-dependent tasks. These tasks start at the endpoint of the trajectory actually executed in Episode 0 or at a point sampled from its 75%–90% interval. The agent must identify and return to an object referenced through the preceding experience. By placing the start on the historical trajectory and providing a shared coordinate frame, this level focuses on memory construction and target recall while reducing the need for unexplored-region navigation. 

Level 2: In-Memory Localization and Episodic Index-ing. Each session contains three episodes with separate local coordinate frames. Episode 0 provides the initial experience. Episode 1 starts 1.0–1.5 m from the start of the Episode 0 reference trajectory and requires the agent to revisit a target from Episode 0 before following a new navigation instruction. Episode 2 starts at the same position as Episode 1 and refers to a target encountered in Episode 1 but not Episode 0. The agent must relate its current observations to the visited region and retrieve the target associated with the relevant episode. 

Level 3: Off-Memory Relocalization and Route Re-entry. Each session contains two base episodes whose ref-erence trajectories share a continuous segment, followed by a memory-dependent episode. All three episodes use separate local coordinate frames. The final episode starts outside historical observation coverage, requiring the agent to explore and establish correspondence with a previously visited region. It must then identify and reproduce a specified sub-path of the shared historical segment before completing the remaining instruction. Specifying a sub-path requires selecting the relevant portion of the historical route, beyond simply returning to a familiar region. This level evaluates off-memory relocalization and ordered historical-route repro-duction. Memory-related instructions refer to past experience with-out directly describing how to reach the target. Agents must visit the specified targets or follow the required historical routes, but may use any memory representation or navigation method. 

B. Manual Trajectory Collection 

We collect reference trajectories and their corresponding navigation instructions in HM3DSem scenes [32] using the Habitat simulator [33]. Collection is organized at the session level so that later tasks can refer to objects and routes encountered in earlier episodes. Collectors first familiarize themselves with the scene, then design the instructions and reference paths according to the level-specific requirements in Section III-A. They manually control the agent to exe-cute each planned route, producing paired instructions and trajectories. The agent’s forward step size is 0.25 m , and each turn is 

15 ◦. The agent and the RGB-D sensor are both 1.2 m high. The image resolution is 960 ×720 , with a 90 ◦ horizontal field of view. During collection, we record the complete action sequence, 3D position, orientation, task start and end points, and the reference path. These recordings are used for data generation and cleaning in Section III-C. 

C. Data Generation and Cleaning 

Level 1: For each collected trajectory, we manually anno-tate visible and distinctive anchor objects along the route and use them as memory recall targets for subsequent episodes. 

Level 2: To prevent the agent from directly discover-ing a target in the initial observation and bypassing self-localization and memory fusion, the respective recall targets of Episode 1 and Episode 2 are not visible at their starting points, and their shortest geodesic distances from the corre-sponding starting point are no less than 3.25 m. 

Level 3: We keep Episode 0–1 pairs whose overlapping sub-paths have bidirectional coverage of at least 95% and bidirectional P95 and ordered discrete Fr´ echet distances of at most 1.2 m ; the 0.6 m neighborhoods of this overlap define the shared route. Episode 2 must follow that route: 95% of its points lie within 0.8 m of either memory trajectory, the P95 distance is at most 0.8 m , and the maximum deviation is at most 1.2 m . It starts at least 1.0 m geodesic from both. RGB-D replay of the first two episodes further removes starts observed in any historical frame. Finally, we manually review all samples and remove those that do not satisfy the task constraints or contain annotation errors to ensure the accuracy and reliability of the dataset.

E. Evaluation Protocol 

We establish an evaluation protocol to systematically as-sess Mem-X. The protocol controls access to cross-episode coordinates (Section III-A): Level 1 shares a global frame, while Levels 2 and 3 provide only episode-local poses and withhold inter-episode transforms, so later tasks cannot be solved from a shared pose. Following common VLN settings [3], [11], we report Success Rate (SR) and Success weighted by Path Length (SPL) to measure task completion. Because these endpoint-based metrics cannot tell whether the agent used historical memory, we further propose metrics for memory-related capabilities, covering target recall, cross-episode localization, constrained completion, and historical-route reproduction. Because we cannot accurately measure whether the agent truly found the target object, we use Memory Recall Rate (MRR) as a coarse measure of memory-target recall accu-racy. A. Episode-Level Memory Construction 

As shown in Figure 2(a), MemBridge incrementally con-structs a semantic scene graph [35]–[38] within a single episode from the current RGB-D observation and the local pose. Keyframes are selected with DINOv3 [39] features when the similarity to the previous keyframe falls below a thresh-old. For each keyframe, SAM3 [40] detects and seg-ments objects, DINOv3 extracts region features, and three-dimensional positions are computed from depth and camera poses. Following INHerit-SG [38], a new observation is associated with existing nodes by visual-feature similarity, semantic consistency, and geometric distance; a matched instance is updated, otherwise a new node is created. Object nodes also store an episode index for later retrieval. 

B. Cross-Episode Memory Localization 

As shown in Figure 2(b), MemBridge first performs self-localization across episodes. The current observation is encoded with a DINOv3 [39] global feature, compared by cosine similarity to historical keyframes, and the top-k

frames are selected. SuperPoint [41] and LightGlue [42] establish correspon-dences between the current RGB image and these k frames. Each match is back-projected from depth and projected onto the ground plane. RANSAC [43] then estimates a planar transform g ∈ SE(2) on each candidate. Because similar appearance at different places can make 

g unreliable, we accept it as the unique valid transform only when the best candidate has at least 80 inliers and, if the second-best has at least 20 inliers, the best is still no less than 1.5× the second-best. A valid g warps the current observations into the historical scene-graph frame and updates the graph. If no unique g is found, a frontier on the agent’s occupancy map whose heading is most similar to a historical frame is selected, and self-localization is repeated every 1 m .

C. Coarse-to-Fine Memory Retrieval 

As shown in Figure 2(c), MemBridge uses coarse-to-fine two-stage retrieval over the scene graph. A VLM parses the instruction into segments and routes each segment to memory retrieval or the base VLN model. For a memory-recall segment, the coarse score of each object node is the maximum of label matching and text similarity to the target category. Nodes are ranked by this score, room consistency, and historical observation quality, and the Top-k candidates are kept. In the fine stage, the original instruction, these k candi-dates, and their historical keyframes are input to the VLM, which selects the target UID from appearance and scene context. If no suitable candidate exists, recall is rejected and the system falls back to the base VLN model. After a target is selected, its stored position is used for planning on the aligned occupancy map. V. E XPERIMENTS 

A. Implementation Details 

We conduct experiments on eight NVIDIA RTX 4090 GPUs. Instruction parsing and Top-k fine retrieval use Qwen-3.5-27B, with VLM fine-retrieval Top-k of 3 and historical-keyframe retrieval Top-k of 5. The keyframe-selection threshold for semantic-graph construction is 0.85, the visual-similarity threshold is 0.80, and the spatial-distance threshold is 1.5 m . The text encoder is all-MiniLM-L6-v2 [44]. All methods at Level 2 and Level 3 use simulator-obtained local poses. We evaluate four agents with different memory mecha-nisms. CMA [11] uses a recurrent GRU, ETPNav [24] uses a topological graph, JanusVLN [18] uses a Transformer history cache, and Uni-LaViRA [30] uses waypoint-indexed episodic memory. CMA’s GRU is cleared each episode, because car-rying the hidden state causes an immediate STOP. JanusVLN does not depend on pose, so its cache is retained at all three levels. ETPNav and Uni-LaViRA use position-dependent inputs: native memory is retained at Level 1, which uses a global frame, and is reset at Levels 2 and 3, which use episode-local frames, to avoid misaligned historical poses.

C. Ablation Study 

We analyze the components of MemBridge to examine how different parts of the reference baseline contribute to performance on Mem-X. Table V reports the effects of re-moving VLM Top-k fine retrieval, cross-episode localization, and frontier exploration. Removing VLM Top-k fine retrieval reduces Level 1 SR from 74 .08% to 63 .40% and MRR from 61 .12% to 52 .71% .Level 2 and Level 3 also decline, but the largest drop is on Level 1, where the shared frame already isolates target recall from localization. Coarse scene-graph ranking is therefore insufficient when several candidates share a category. Removing cross-episode localization yields metrics close to Uni-LaViRA’s native Memory setting, effectively reducing the agent to in-episode memory. Frontier exploration is used only when the first observation does not yield a unique lock. Removing it leaves Level 1 and Level 2 largely unchanged, because Level 1 does not require cross-episode localization and Level 2 starts in a previously observed region. On Level 3, SR falls from 38 .85% to 

28 .66% and C-SR from 26 .75% to 11 .46% , approaching the native Memory row. Off-memory relocalization therefore depends on exploring into historical coverage, not on a start-view match. 

D. Qualitative Analysis 

We select Uni-LaViRA, which has stronger overall perfor-mance, and analyze the four cases shown in Figure 3. The Level 1 case requires returning to a previously seen basket. Uni-LaViRA does not recall this object, and its trajectory misses the basket; after MemBridge is added, the agent stops beside it. The Level 2 case uses local coordinates and requires first returning to a previously seen bench, then stopping beside a blanket. Uni-LaViRA’s trajectory cuts directly toward the goal, with SR = 1 and C-SR = 0: the memory task is reduced to a final ordinary-navigation segment. MemBridge completes self-localization at the start and then visits the two anchors in order. The Level 3 case starts from a region not covered by his-tory. The instruction requires first finding a previously seen fireplace, then following the shared route of two memory segments to a refrigerator. Uni-LaViRA can approach the goal (SR = 1 ) but does not visit the anchors in order; ST-nDTW is near 0, and the shared route is barely reproduced. MemBridge first establishes spatial correspondence with the historical region during exploration, then visits the two anchors in sequence. The failure case requires first revisiting a trash bin, then entering the kitchen and stopping in front of a microwave. MemBridge has already locked the pose, but retrieves the instruction’s bin as a basket in the same scene, yielding C-SR = 0 .VI. C ONCLUSION 

We propose Mem-X, a cross-episode memory-dependent VLN benchmark with explicit dependencies between tasks. We also introduce an evaluation protocol that measures memory-related capabilities beyond endpoint success. Mem-Bridge is a modular baseline that combines semantic scene memory, cross-episode localization, and coarse-to-fine re-trieval and can be integrated with existing VLN agents. Experiments with four VLN agents show that MemBridge improves memory-related metrics, but reaching the goal or aligning poses does not mean the agent used histori-cal memory. Even with MemBridge, Level 3 constrained success remains below 30% , leaving substantial room for improvement. The current dataset covers only single-floor environments, and the odometry is ground-truth from the simulator, which still differs from real settings.
