# MemOnce: A Scalable Memory Architecture for Large Language Models 

Chang Nie 1, Chaoyou Fu 1, Songlin Liu 2, Yiqing Hu 2, Caifeng Shan 11Nanjing University, 2University of Science and Technology of China Deploying large language models (LLMs) in long-horizon and continual interactions requires maintain-ing reusable memory states for future inference, posing challenges for existing architectures. Standard Transformers accumulate layer-wise, token-level KV caches, incurring linear GPU memory growth and quadratic computational complexity as the context expands. In contrast, linear-time architectures com-press history into fixed-size states, but struggle to retain fine-grained details. We introduce MemOnce ,a foundation architecture that learns scalable memory states for language models. MemOnce is based on two core designs: (a) Memory encoder-decoder : it caches only a small subset of final-layer hidden states as compact memory representations and dynamically decodes them back into KV caches for attention layers; (b) Memory sparse attention : for each continual input, MemOnce adaptively retrieves relevant memory representations, with the sparse indices computed only once across layers. Coupling these two designs enables efficient on-the-fly memory loading and KV cache decoding, drastically reducing the GPU memory footprint and achieving linear-time complexity. We conduct extensive experiments to show that MemOnce outperforms Transformers and other architectures across varying model sizes, context lengths, and training paradigms (pretraining and post-training adaptation). In particular, adapting Qwen3.5-4B with MemOnce reduces memory state cache by 1313 × and prefill latency by 6.9 × at 1M context, and improves throughput by 3.5 × and overall memory performance by +5.77% . Finally, MemOnce generalizes zero-shot to downstream representation tasks, achieving competitive results against specialized models.

1arXiv:2611.27973v1 [cs.CL] 20 Nov 2026 1 Introduction 

Memory serves as the foundation for experiential and continual intelligence (Hassabis et al., 2017; Sumers et al., 2023; Hu et al., 2025). As large language models (LLMs) transition from single-turn processing toward continual interactions and long-horizon agent tasks, maintaining reusable memory states is essential to eliminate redundant context recomputation and ensure low-latency response generation (Xi et al., 2025; Chhikara et al., 2025; Zheng et al., 2026). However, existing architectures face a fundamental trade-off between retention fidelity and inference scalability. Transformers (Vaswani et al., 2017) with global attention retain layer-wise, token-level key-value (KV) caches, incurring linear GPU memory growth and quadratic computational complexity as the context expands. In contrast, recurrent and linear models (e.g., Mamba (Gu and Dao, 2023), RWKV (Peng et al., 2023), and GDN (Yang et al., 2025)) compress history into fixed-size states to enable constant-memory, linear-time inference; yet their bounded state capacity can induce information decay, hindering the preservation of fine-grained details over long horizons (Jelassi et al., 2024). Extensive efforts have sought to reconcile this trade-off, broadly falling into three categories: (1) Architectural and attention optimizations : hybrid models (e.g., Kimi K3 (Kimi Team et al., 2026) and MiMo-V2.6 (Qiao et al., 2026)) interleave attention and linear layers, cross-layer sharing approaches (Sun et al., 2024b; Xu et al., 2026a) reuse intermediate KV caches, and sparse attention mechanisms (e.g., DeepSeek-V4.1-Flash (Xu et al., 2026a) and Qwen3.8-Next (Qiu et al., 2026)) restrict attention to top-k relevant tokens. However, during continual inference, they still need to maintain or access global caches that grow linearly with context length. (2) Native memory models : parametric memory designs (e.g., Titans (Behrouz et al., 2025), M+ (Wang et al., 2025a), and Metis (Zhang et al., 2026)) compress historical context into compact memory representations via specialized training or post-training adaptation. Yet, they often suffer from performance degradation, layer-wise retrieval overhead, or catastrophic forgetting. (3) External memory systems : agentic memory frameworks (e.g., Mem0 (Chhikara et al., 2025), A-MEM (Xu et al., 2026b), and PersonaVLM (Nie et al., 2026b)) organize historical context into explicit databases that can be managed, updated, and queried. Nevertheless, constructing and maintaining these discrete stores is costly (Nie et al., 2026c) and difficult to optimize end-to-end (Wang et al., 2025b). Despite these efforts, a central question remains open: How can we build a foundational memory architecture (or adapt an existing one) to simultaneously achieve accurate recall, linear-time inference, and bounded GPU memory cache overhead for continual inference? In this paper, we propose MemOnce , an expressive yet scalable architecture that learns reusable memory states for language models. The core idea of MemOnce is to maintain a single compact global cache and retrieve relevant memory only once during continual inference to decode layer-wise KV caches, thereby enabling memory on-demand loading and decoding. Specifically, we first develop a memory encoder-decoder that caches a small subset (e.g., 1/8) of final-layer hidden states as compact memory representations, dynamically decoding them via lightweight MLPs into KV caches for attention layers. This design achieves cache recurrence and an Lr × compression across both depth and time dimensions. Second, we introduce memory sparse attention , which adaptively selects the top-K task-relevant states for each input and shares the sparse routing indices across all attention layers and decoding steps. By coupling these two designs, MemOnce achieves strong expressiveness, linear-time complexity, and a constant active memory state (see Figure 1). We conduct extensive experiments across diverse tasks, model sizes, and context scales to demonstrate the superiority of MemOnce. Specifically, we highlight three key results: (1) MemOnce as a foundation architecture :We train MemOnce and other foundation architectures from scratch across model sizes ranging from 150M to 1B parameters. MemOnce consistently achieves lower or comparable perplexity on validation data and performs well on downstream benchmarks compared to evaluated baselines (e.g., Transformer, GDN, and YOCO (Vaswani et al., 2017; Yang et al., 2025; Sun et al., 2024b)). (2) MemOnce as a native memory model :We adapt Qwen3.5 via post-training and evaluate it on five memory benchmarks spanning 4K to 1M tokens. As shown in Figure 1, MemOnce is the first native memory model to surpass the full-context baseline (+5.77% at the 4B scale) (Qwen Team, 2026), and outperforms prior memory methods (by +18.68% over M+ (Wang et al., 2025a) and +32.27% over Metis (Zhang et al., 2026)). At 1M context, it reduces memory state cache by 1313 × and prefill latency by 6.9 ×, and improves throughput by 3.5 ×. Moreover, MemOnce avoids catastrophic forgetting on general benchmarks by keeping its parameters frozen during inference and inherently ignoring irrelevant decoded caches. (3) MemOnce as a representation model : We show that 2MemOnce’s learned memory representations transfer naturally to downstream retrieval and reranking tasks, outperforming specialized models without task-specific fine-tuning. These findings underscore the potential of MemOnce as a next-generation general-purpose architecture. In summary, our main contributions are as follows: • We propose MemOnce , a foundation architecture that achieves strong expressiveness, linear-time complexity, and constant active memory for continual inference. • We couple two designs, memory encoder-decoder and memory sparse attention, to cache and retrieve memory representations only once for on-demand memory loading and KV cache decoding. • We establish through comprehensive experiments that MemOnce advances the performance–complexity Pareto frontier, marking the first native memory model to surpass the full-context baseline and generalizing zero-shot to downstream representation tasks.

## 3 MemOnce 

We introduce MemOnce , a foundation architecture that learns scalable memory states Mt in Eq. (1) for efficient continual inference. Formally, MemOnce constructs and utilizes the active memory state Mt through three functions: 

Gt = gθ (x1: t−1), Mt = iθ (xt, G t), Ct = uθ (Mt), (5) where gθ , iθ , and uθ denote the memory writing, indexing, and reading operations, respectively. We instantiate Eq. (5) through two core designs: (1) the memory encoder-decoder (gθ and uθ ), which caches partial final-layer 4states into a persistent memory bank Gt and decodes the active memory state Mt into multi-layer KV caches

In practice, as shown in Figure 2, MemOnce adopts an L-stage hybrid backbone by default, where each stage interleaves three linear blocks (e.g., GDN (Yang et al., 2025)) with one Memory Sparse Attention block.

3.2 Memory Sparse Attention 

While the memory encoder-decoder substantially compresses the global cache by Lr ×, decoding the entire memory bank Gt across ultra-long horizons would still incur linear growth in cache memory and attention compute. We introduce memory sparse attention to break fixed capacity limits while maintaining constant active states and linear-time complexity. Its core idea is to retrieve relevant memory representations only once for each continual input and reuse them across layers with negligible loading overhead.

3.3 Analysis and Optimization 

Advantage Analysis. Compared with existing foundation architectures and native memory models, MemOnce offers three key advantages: (1) Strong Performance: By maintaining an expandable memory bank 

Gt and retrieving final-layer representations back into multi-layer KV caches, MemOnce overcomes fixed-capacity bottlenecks and achieves accurate recall in long-context scenarios. (2) Bounded Active Memory State: 

MemOnce reduces the persistent cache footprint by a factor of Lr and achieves constant active memory state during continual inference. (3) High Inference Efficiency: As illustrated in Figure 1 (right), MemOnce operates with linear-time complexity and achieves superior inference efficiency over existing memory architectures.

Optimization. MemOnce supports end-to-end optimization under the standard next-token prediction paradigm for both pretraining and post-training adaptation. During pretraining, the backbone and memory encoder-decoder are jointly optimized, where historical segments are encoded in parallel into Gt and gradients flow directly through the active memory state Mt and the decoded KV caches. During post-training adaptation, we freeze the backbone and optimize only the lightweight projections in iθ and uθ , alongside low-rank adapters (LoRA) activated exclusively during memory encoding ( gθ). Because historical context is internalized as decoded KV caches and the backbone remains frozen during response generation, MemOnce equips pretrained LLMs with native long-range memory capabilities without compromising their general task performance. ## 4 Experiments 

4.1 Experimental Setup 

Evaluation and Benchmarks. We conduct extensive experiments to evaluate MemOnce across diverse tasks, model scales, and context lengths. Our evaluation is organized into four primary tracks: (1) Foundational Capability: We evaluate language modeling performance using perplexity (PPL) on WikiText (Merity et al., 2017) and LAMBADA (Paperno et al., 2016). We further report zero-shot accuracy across eight downstream tasks using the LM-Evaluation-Harness (Gao et al., 2021) to assess general knowledge and reasoning capabilities.  

> (2) Long-Context Memory Capability:

We evaluate continual and long-horizon memory recall across context lengths spanning 4K to 1M tokens on standard memory benchmarks, including MemBench (Tan et al., 2025), LoCoMo (Maharana et al., 2024), LongMemEval (Wu et al., 2025), and PersonaMem (Jiang et al., 2025).  

> (3) General Capability Retention:

To measure general capability retention under active memory load and verify robustness against catastrophic forgetting, we evaluate models on MMLU (Hendrycks et al., 2021), GSM8K (Cobbe et al., 2021), and GPQA (Rein et al., 2024). (4) Representation Tasks: Finally, we assess the zero-shot generalizability of MemOnce’s learned memory representations on downstream text retrieval and reranking benchmarks (Nie et al., 2026a). 

Baselines. We compare MemOnce against three distinct categories of baselines corresponding to our evaluation tracks: (1) Foundational Architectures: We compare against the standard Transformer (Vaswani et al., 2017), cross-layer KV-sharing variants including YOCO (Sun et al., 2024b) and LastKV (Cai et al., 2026), linear and efficient attention architectures including Sliding Window Attention (SWA) (Beltagy et al., 2020), Gated DeltaNet (GDN) (Yang et al., 2025), and Multi-head Latent Attention (MLA) (Liu et al., 2024), as well as the memory architecture Memory Caching (Behrouz et al., 2026). 2 (2) Native Memory Models: For continual memory evaluation, we compare against advanced native memory methods, including M+ (Wang et al., 2025a), Metis (Zhang et al., 2026), δ-Mem (Lei et al., 2026), and EvoEmbedding (Nie et al., 2026a).

Implementation Details. For foundational capability evaluation, all architectures are trained from scratch on the FineWeb-Edu dataset (Lozhkov et al., 2024) under unified training configurations and token budgets. For long-context memory evaluation, we adopt Qwen3.5 (Qwen Team, 2026) as the base backbone for lightweight LoRA post-training adaptation, and employ DeepSeek-V4.1-Flash (Xu et al., 2026a) as a strict judge to report final response accuracy across all methods. All experiments are conducted on a single server equipped with 8 NVIDIA H100 GPUs. Full details are provided in Appendix D. 

4.2 Main Results 

(1) Foundational Capability. Joint recurrence and compression of context caches across depth and time enable MemOnce to cut the persistent cache footprint by Lr × while delivering strong foundational performance. 

We report the results of pretraining different foundation architectures from scratch on FineWeb-Edu. As shown in Figure 3, MemOnce attains lower final validation perplexity than GDN, SWA, and YOCO, matches or surpasses the Transformer even at r = 8 , and achieves the best scaling performance from 0.15B to 1.0B parameters. In downstream evaluations (Table 2), MemOnce r=1 and MemOnce r=8 attain the highest and second-highest average zero-shot accuracies across all evaluated architectures, while respectively achieving the lowest language modeling perplexities on WikiText-103 and LAMBADA. Notably, compressing the temporal dimension by 8× (MemOnce r=8 vs. MemOnce r=1 ) incurs virtually no performance loss, demonstrating that the model can effectively condense segment-level context into the trailing tokens while preserving essential long-range information. (3) Inference Efficiency and Scalability. MemOnce achieves linear-time prefilling, constant active GPU cache, and steady decoding throughput up to 1M tokens. Figure 4 evaluates prefilling time, GPU cache footprint, and decoding throughput across context lengths from 32K to 1M tokens (detailed in Table 14). Beyond the quadratic prefill cost of standard Transformers, existing memory baselines also suffer from severe execution bottlenecks: δ-Mem still relies on full-context attention computation during state construction in its official implementation, Metis employs coarse sequential blocks that limit GPU parallelism, EvoEmbedding requires two separate forward passes to generate memory states and retrieval keys, and M+ incurs heavy layer-wise retrieval and CPU–GPU communication overhead across all layers. By encoding historical chunks in parallel and retrieving memory only once, MemOnce scales linearly from 1.38s (32K) to 41.36s (1M), achieving a 

6.9× speedup over Hybrid and 35 .8× over M+. Meanwhile, whereas the KV caches of Transformer and Hybrid grow linearly with sequence length and exceed 32 GB at 1M tokens, MemOnce offloads the historical pool and bounds the active GPU cache to a near-constant 25 MB footprint across all scales (Figure 4(b)). Consequently, while surging KV cache traffic severely degrades decoding throughput in Hybrid and Transformer baselines, MemOnce attends only to a constant-sized memory subset, sustaining the highest and near-invariant throughput across all context lengths. 

(4) Representation Capability. The memory representations learned by MemOnce transfer naturally to downstream retrieval and context reranking tasks, outperforming specialized embedding and reranking models. 

We evaluate MemOnce on eight long-context and conversational retrieval benchmarks against dedicated embedding models, BGE-M3 and Qwen3-Embedding-4B (Zhang et al., 2025) (Table 5). Unlike standalone embedding models trained solely on pairwise text similarity, MemOnce jointly optimizes its terminal index representations with end-to-end language modeling and contrastive evidence supervision, enabling the compact 1024-dimensional descriptors to capture multi-hop and temporal dependencies critical for answering downstream queries. Consequently, MemOnce achieves the best overall Recall@10 of 69 .21 and NDCG@10 of 53 .06 , ranking first on long-context benchmarks. Furthermore, when deployed as a plug-and-play reranker on LoCoMo to select the top-20 segments from 256 candidates retrieved by All-MiniLM-L6-v2 (Nie et al., 2026a) (Table 6), MemOnce boosts the overall performance of representative agent memory systems by +17 .2 on A-MEM (60 .78 ) and +13 .3 on LightMem ( 53 .90 ), consistently surpassing both the multi-turn reasoning-based retrieval strategy and the specialized Qwen3-Reranker-4B (Zhang et al., 2025).

## 5 Discussion 

5.1 Why Existing Memory Architectures Fail to Scale 

Existing memory architectures (Wang et al., 2025a; Lei et al., 2026; Zhang et al., 2026) struggle to scale effectively due to three fundamental bottlenecks: performance degradation, system overhead, and limited generalizability. First, from a performance perspective, compressing full-context attention into bounded or fixed-size states inevitably induces information decay and fails to retain fine-grained details over long horizons. Second, from a cost perspective, long-term memory methods such as M+ (Wang et al., 2025a) overlook cache compression, as maintaining multi-layer KV caches and repeatedly fetching states across layers incur heavy storage overhead and communication latency. Third, from a generalizability perspective, prior memory architectures are typically tailored either to pretraining from scratch (Behrouz et al., 2025) or to post-training adaptation, lacking versatility across both paradigms. To tackle these challenges, MemOnce couples compact final-layer memory encoding with efficient memory retrieval and on-demand KV decoding, and is validated across both pretraining and post-training adaptation. Our experimental results demonstrate that learning scalable, reusable memory states provides a viable path toward next-generation foundation architectures. 

5.2 Limitations and Future Work 

Several limitations of MemOnce offer valuable directions for future research. First, constrained by available computing resources, our pre-training from scratch is conducted up to the 1B parameter scale; validating the foundational scaling behavior of MemOnce via full pre-training at larger scales (e.g., 7B or beyond) remains future work. Second, while MemOnce demonstrates strong memory capabilities, its performance in downstream agent tasks remains to be fully validated, particularly in complex scenarios such as long-horizon interactive coding and multi-step tool use. In future work, we plan to pre-train MemOnce at larger parameter scales and explore its potential across broader continual interactive scenarios. 

## 6 Conclusion 

In this paper, we present MemOnce , a foundational memory architecture that achieves accurate long-context recall, linear-time complexity, and constant active memory states for continual language modeling. By coupling the memory encoder-decoder and memory sparse attention designs, MemOnce caches and retrieves memory states only once while dynamically decoding them into multi-layer KV caches on demand. MemOnce seamlessly integrates into pretrained models to accelerate inference while establishing itself as the first native memory model to surpass full-context baselines. ## A Related Work 

A.1 Architectural and Attention Optimizations 

To alleviate the quadratic compute and linear KV cache growth of standard Transformers (Vaswani et al., 2017), architectural reforms have progressed along three lines. First, from linear to hybrid architectures :linear and recurrent models such as Mamba (Gu and Dao, 2023), RWKV (Peng et al., 2023), and Gated DeltaNet (Yang et al., 2025) compress history into fixed-size states for constant-memory, linear-time inference, but struggle with fine-grained in-context recall (Jelassi et al., 2024). To balance computational efficiency with accurate recall of historical information, modern backbones increasingly adopt hybrid designs: Qwen3.5 (Qwen Team, 2026) and Kimi K3 (Kimi Team et al., 2026) interleave linear or gated delta layers with periodic global attention, while MiMo (Xiaomi, 2026) interleaves sliding-window attention with full attention. Second, from global to sparse attention : intra-layer sparse mechanisms, such as Native Sparse Attention (NSA) (Yuan 1et al., 2025; Xu et al., 2026a) and block-sparse routing (Qiu et al., 2026), dynamically prune attention matrices via hardware-aligned compressed, selected, and sliding-window branches. Third, cross-layer KV cache reuse : architectures like YOCO (Sun et al., 2024b) and HySparse (Gao et al., 2026) cache KV states at an intermediate anchor layer and feed them forward to subsequent layers, whereas LastKV (Cai et al., 2026) directly reuses raw final-layer KV states across earlier layers. Despite these gains, hybrid and sparse models still retain multi-layer KV caches, with sparse mechanisms further incurring repeated routing overhead across layers and decoding steps, while cross-layer sharing methods still retain full-length token states without sequence compression. 

A.2 Native Memory Models 

Native memory models internalize historical context into compact parametric or latent states. One category compresses history into fixed-capacity representations: Titans (Behrouz et al., 2025) updates a deep neural memory at test time via surprise-driven gradients with momentum and weight decay; δ-Mem (Lei et al., 2026) updates low-dimensional state matrices online via delta-rule learning; Metis (Zhang et al., 2026) embeds persis-tent, gradient-free memory states directly into the backbone in a single forward pass; and EvoEmbedding (Nie et al., 2026a) maintains a window-based latent memory queue for long-context representation learning. To overcome fixed capacity limits, a second category dynamically expands the state pool: M+ (Wang et al., 2025a) extends MemoryLLM (Wang et al., 2024) with a long-term latent pool and layer-wise co-trained retrievers; and Memory Caching (Behrouz et al., 2026) caches recurrent states at segment boundaries for gated residual aggregation. Nevertheless, these methods either suffer from fixed-capacity bottlenecks or incur retrieval overhead, and their prevalent reliance on post-training adaptation often induces catastrophic forgetting. 

A.3 External Memory Systems 

External memory systems decouple persistent memory storage and management from the model backbone, representing historical experiences in explicit stores and handling memory construction, updating, and retrieval through dedicated pipelines (Hu et al., 2025). Mem0 (Chhikara et al., 2025) dynamically extracts and consolidates salient conversational facts for subsequent retrieval, while A-MEM (Xu et al., 2026b) employs agent-driven note construction and dynamic linking to organize memories into an evolving knowledge network. For multimodal personalization, PersonaVLM (Nie et al., 2026b) integrates proactive multimodal memory accumulation and multi-turn memory-grounded reasoning with dynamic personality profiling for response alignment. To improve memory construction efficiency, LightMem (Fang et al., 2026) introduces lightweight sensory-level compression, topic-aware segmentation and summarization, and offline “sleep-time” consolidation. For streaming video understanding, Light-Omni (Nie et al., 2026c) employs a dual-state architecture, combining a non-parametric global state distilled from episodic memory with a parametric latent state that enables reflexive action control and semantically aligned retrieval without iterative reasoning. Despite these advances, long-term memories are still largely maintained in external stores or auxiliary memory structures, with memory construction, consolidation, and retrieval handled through separate procedures. This separation can introduce additional storage and orchestration overhead while making it less straightforward to jointly optimize memory formation, maintenance, and utilization with the backbone, particularly under end-to-end objectives such as reinforcement learning (Wang et al., 2025b). 

A.4 Comparison with Existing Methods 

MemOnce addresses the limitations across all three paradigms. Compared with architectural and cross-layer KV optimizations, MemOnce caches only a small subset of final-layer hidden states and performs sparse retrieval only once per query, eliminating both layer-wise storage and routing overhead. Compared with native and external memory systems, MemOnce enables efficient end-to-end optimization and long-term memory capabilities for both pretraining and post-training adaptation. Furthermore, decoding compact memory states into KV caches effectively preserves long-range context without catastrophic forgetting. 2B Detailed Analysis and Implementation of MemOnce

## C Training Dataset Construction and Statistics 

C.1 MemOnce-1M 

To jointly optimize MemOnce’s memory encoder-decoder and single-shot sparse retrieval, we construct a large-scale multi-turn training corpus, MemOnce-1M (1M samples). Every training instance is standardized into a multi-turn conversational sequence H = {x1, x 2, . . . , x t−1, x t}, consisting of h = t − 1 historical interaction rounds followed by a target query turn xt. To obtain high-fidelity supervision for both language modeling and memory retrieval without costly manual annotation, we employ Qwen3.5-35B-A3B as a teacher model for the final user query xt. Conditioned on the complete dialogue history, the teacher model simultaneously generates: (i) a grounded reference response yt to supervise the language modeling objective, and (ii) the exact indices of historical evidence turns E+ ⊂ { 1, . . . , h } containing the supporting facts required to answer the query. These distilled evidence annotations directly supervise the contrastive retrieval loss in Eq. (11), aligning the query descriptor ϕ(hLt ) with relevant historical index vectors {ϕ(hLi )}hi=1 .

E.1 Compression Ratio 

We first evaluate the trade-off between the compression ratio r ∈ { 1, 2, 4, 8} and downstream accuracy in Table 8. Increasing r from 1× to 8× compresses the persistent memory bank Gt by 8× along the sequence dimension, while causing only a negligible accuracy drop of 0.0025 (0.5280 → 0.5255 when linear states are persisted) and 0.0028 (0.5263 → 0.5235 when discarded). This confirms that the trailing 1/r final-layer hidden states effectively encapsulate segment-level semantics, allowing r = 8 to serve as our default setting. 

E.2 Linear State Persistence 

Table 8 also examines whether the recurrent states of linear layers need to be maintained across historical segments. The Persisted setting carries linear recurrent states across segments alongside Gt, whereas the 

Discarded setting resets linear states at segment boundaries and relies solely on the decoded KV caches from 

Mt for long-range context. Across all compression ratios, both settings yield nearly identical performance (e.g., 0.5255 vs. 0.5235 at r = 8 ), demonstrating that long-range information is predominantly preserved by our expandable memory bank Gt rather than fixed-capacity linear states. We therefore discard cross-segment linear states by default, which eliminates multi-layer recurrent state storage.
