## 摘要
大语言模型（LLM）智能体如今能够调优神经网络，但若没有跨会话记忆，它们会在昂贵的试验中重复发现已知经验。复用之所以困难，是因为生产模型在架构、训练设置和推理预算上各不相同。我们提出 Engram，一个将过往试验结果与其背后的假设和推理依据关联起来，并评估这些证据是否适用于当前模型的记忆系统。在线智能体在需要证据的决策点整理证据：初始引导（Initial Guidance）在开始时提供经过验证的经验，会话检索（Session Retrieval）在每批假设生成前提供相关的过往会话，试验候选审查（Trial Candidate Review）将每个候选试验与匹配的过往试验进行核对。在会话之间，离线智能体蒸馏经过验证的经验，使记忆不断自我改进。在两个广告模型上，Engram 以少 47% 的试验次数达到了无记忆对照的 32 次试验结果，并且平均最终得到的模型也更好。

## Abstract
Large language model (LLM) agents can now tune neural networks, yet without cross-session memory they spend costly trials rediscovering known lessons. Reuse is difficult because production models differ in architecture, training setup and inference budget. We present Engram, a memory system that links past trial outcomes with the hypotheses and rationale behind them and assesses whether this evidence applies to the current model. An online agent curates evidence at the decision points where it is needed: Initial Guidance supplies validated lessons at the start, Session Retrieval supplies related past sessions before each batch of hypotheses is generated, and Trial Candidate Review checks each trial candidate against matching past trials. Between sessions, an offline agent distills validated lessons, making the memory self-improving. On two ads models, Engram reaches the 32-trial result of a no-memory control with 47% fewer trials and also ends with a better model on average.

## 1. 论文的核心问题与整体含义

- **核心问题**：大语言模型（LLM）智能体已经能够自动调优神经网络，但缺少**跨会话记忆**，导致每次调优都从零开始，重复发现已知经验，浪费昂贵的训练试验。
- **根本困难**：生产环境中的模型高度**异构**，在架构、训练设置（数据、训练时长、优化器调度）、推理预算等方面各不相同。因此，在一个模型上有效的调优经验，不一定能迁移到另一个模型上。
- **论文提出的五个核心挑战**：
  - **C1**：过往收益依赖于具体模型和训练设置，一个模型上的提升可能不会在另一个模型上重现。
  - **C2**：适用的参数变更取决于推理预算，预算充足时的有效改动在预算受限下可能不可行。
  - **C3**：仅有结果记录无法解释原因；缺少假设与依据，就无法判断结果是否可迁移。
  - **C4**：过往会话的相关性在调优过程中会发生变化——当前模型的表现会揭示哪些改动有效，此时最有用的历史会话是那些从相同改动中获益的会话，而非单纯最相似或最新的会话。
  - **C5**：错误应用证据可能误导搜索，来自差异过大的模型的历史结果可能把智能体引向更差的配置。
- **整体含义**：Engram 的目标不是简单提供更多历史数据，而是**评估哪些过往证据适用于当前模型和预算，并在调优智能体最需要的决策点提供这些证据**，从而实现高效、可迁移、自我改进的调优记忆。

## 2. 论文提出的方法论

### 2.1 问题设置

- 一次调优会话从基线配置 \(x_0\) 开始，最多进行 \(K\) 次试验。
- 每次试验评估一个配置 \(x_k\)，测量质量指标 \(q(x)\)（论文中为**归一化熵 NE**，越低越好）和推理成本 \(c(x)\)（推理 FLOPs）。
- 试验可行条件：\(c(x) \le \rho \cdot c(x_0)\)，即推理成本不超过基线的 \(\rho\) 倍。
- 会话返回满足成本约束的最佳配置 \(x^\star\)。
- 调优智能体遵循 **observe–reason–act** 循环，以 LLM 作为优化器；Engram 在此基础上补充来自过往会话的证据。

### 2.2 记忆、知识与固化

- **两个存储层**：
  - **Memory**：保存原始证据。每次试验记录配置变更、NE、FLOPs、状态，以及智能体在试验前写的**假设、理由**和试验后的**分析**。
  - **Knowledge**：保存经过离线固化并验证的**教训（lesson）**。每条教训包含：
    - 参数、起始值范围以及从该范围出发的**变更动作（move）**；
    - 关于该变更对 NE 影响的声明（claim）；
    - **适用范围（scope）**：该声明适用于哪类模型（如特定架构或训练数据规模）。
- **离线固化（offline consolidation）**：
  - 从 Memory 中挖掘候选教训：代码首先从会话内成对试验中挖掘单参数变更和联合变更；联合变更的效果无法归因于单一参数，因此只作为相关性声明。
  - 离线智能体结合支持试验和记录的理由审查每个候选，决定保留、缩小范围或丢弃，并与调优指南中的默认建议关联。
  - 候选教训只有在满足以下条件时才会发布：
    1. 在全历史和时间交叉验证上比默认调优指南更准确地预测结果；
    2. 基于多个不同模型（默认为 5 个）；
    3. 得到多个独立 LLM 评审（默认为 2 个）的认可。
- **效果**：离线智能体将 Memory 转化为 Knowledge，使 Engram 成为**自我改进的记忆**，其指导能力随着调优更多模型而增强。

### 2.3 多阶段检索（Multi-Stage Retrieval）

算法流程：会话开始时执行**初始引导（IG）**；每轮中，先执行**会话检索（SR）**，然后调优智能体提出一批试验，再执行**试验候选审查（TCR）**，最后执行试验。

- **初始引导（Initial Guidance, IG）**：
  - 在会话开始时，告知调优智能体哪些已验证教训适用于当前模型。
  - 教训适用条件：
    1. 其范围覆盖当前模型；
    2. 模型暴露该教训涉及的参数；
    3. 该参数的基线值位于 move 的起始范围内。
  - 在线智能体审查所有适用教训，撰写简报：推荐这些教训支持的 move；联合变更教训仅作为相关性报告，不作推荐。

- **会话检索（Session Retrieval, SR）**：
  - 在每批假设生成前，检索与当前会话相似的过往会话并解释其发现。
  - 排序分数：
    \[
    \text{score}(c) = \sum_i w_i \, \text{Match}_i(c) + \lambda \, \text{Agreement}(c)
    \]
  - 其中 \(\text{Match}_i(c) \in [0,1]\) 比较会话 \(c\) 与当前会话的一个元数据字段（模型架构、规模、探索过的参数等）；\(w_i\) 为字段权重。
  - \(\text{Agreement}(c)\) 衡量当前会话迄今的 NE 增益在多大程度上来自对 \(c\) 也探索并改进过的参数的假设；\(\lambda\) 是其权重。
  - 由于 Agreement 每批后重新计算，排序会随新结果动态演化。
  - 在线智能体检查检索到的会话是否覆盖当前可调参数、符合 FLOPs 预算并保持时效，可排除会话或调整 \(w_i\)、\(\lambda\) 重新检索，然后撰写建议，但下一假设仍由调优智能体选择。

- **试验候选审查（Trial Candidate Review, TCR）**：
  - 调优智能体提出一批试验后，对每个候选与 Memory 中做过相同参数变更的过往试验进行比对。
  - 在线智能体判断候选是否可能改善 NE 且不超过 FLOPs 上限。
  - 对被认为不太可能改善 NE 或超限的候选，调优智能体必须替换或给出合理解释。

## 3. 实验设计

- **模型与数据**：
  - 两个广告模型：**Model 1** 和 **Model 2**。
  - **Model 1**：主研究模型，历史丰富，共 227 个会话，其中 59 个来自相近模型（同生产模型类型但架构/特征/训练设置仍有差异），另有 8 个其他基线。
  - **Model 2**：历史较差，299 个会话全部来自远距离模型（部分共享架构家族）。
  - 两个模型的历史均不包含当前评估基线。
  - 每次试验在约 1.9 亿样本（Model 1）或约 1.44 亿样本（Model 2）上训练一个 epoch。

- **对比方法（8 个臂，Model 1 额外 1 个臂）**：
  1. **Control**：无记忆对照。
  2. **NE-sorted journal**：按性能增益排序的历史日志，作为衡量适用性判断价值的基线。
  3. **IG only**：仅初始引导。
  4. **SR only**：仅会话检索。
  5. **IG + SR**：初始引导 + 会话检索（不含 TCR）。
  6. **Full Engram**：完整 Engram。
  7. **No curation**：完整 Engram 但去除在线整理。
  8. **No agreement**：完整 Engram 但去除反馈一致性（Agreement）项。
  9. **Distant history only**（仅 Model 1）：完整 Engram 但只使用远距离历史。

- **实验设置**：
  - 每个臂包含 5 个会话，每个会话最多 32 次试验，试验以 8 个为一批同步提交。
  - 推理 FLOPs 上限 \(\rho = 1.5\)。
  - 搜索空间除批大小、epoch 数和 FLOPs 上限外不受限；智能体主要调整学习率、warmup 调度、优化器设置、嵌入/层大小和输入特征。
  - 调优智能体及其子智能体使用 **Claude Opus 5.5**；在线智能体使用更小的 **Claude Sonnet 5.5** 以降低成本和延迟。
  - SR 最多检索 50 个会话，每批最多修订 2 次；TCR 每批检查 1 次。

- **指标与统计**：
  - 质量指标为归一化熵（NE），报告相对基线的百分比变化，负值表示改善。
  - 报告第 8、16、24、32 次试验后的平均最佳可行 NE 变化。
  - 两组比较使用双侧精确 Mann-Whitney U 检验（未校正多重比较）。
