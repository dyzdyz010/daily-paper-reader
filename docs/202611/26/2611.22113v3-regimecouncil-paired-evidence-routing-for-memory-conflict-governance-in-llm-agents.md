## 摘要
在长期 LLM 智能体系统中，除了记忆存储与检索之外，一个根本挑战是：当已存储的记忆与不断演化的世界发生冲突时，智能体应如何行动。事实往往在没有显式删除的情况下变得过时，因此在存储被刷新之前冲突就浮现出来：延迟反馈表明按某条过时记录行动会造成损失，但并未说明抑制应仅限于该事实（局部策略），还是扩展到其他已存储事实（全局策略）。现有系统在设计时硬编码了其中一种作用范围。我们将这种在隐藏有效性与延迟反馈下的在线选择形式化为记忆冲突治理，并提出 RegimeCouncil——一种轻量级路由器，它保留两种作用范围作为顾问，并在不重新训练 LLM 的情况下在二者之间进行仲裁。每个有记忆辅助的响应都相对于无记忆锚点进行评分，评分方式为离路径成对比较，或仅基于已执行动作的逆倾向估计。局部顾问仅跟踪被查询的事实，全局顾问汇集存储中近期的结果，而非对称元调控器默认遵循局部顾问，仅在汇集产生严格正的近期效用边际时切换到全局顾问。我们证明：使用延迟结果可摆脱仅提示的遗憾下界，任一固定作用范围单独都不足够，并且该边际门控可在有界时间内完成切换。在 LongMemEval 数据流、TempLAMA 与 TAQA 的历史漂移、延迟 τ∈[1, 96] 以及稀疏或老虎机反馈设置下，使用 Qwen3-30B-A3B 和 GPT-4o，RegimeCouncil 在所有 30 个留出设置中均优于较优的固定作用范围，在分歧情节上提高 5.2–7.3 个百分点，在聚集漂移下相比独立冷启动回退提高 +27.9 个百分点，同时以微秒级开销减少有害的过时记忆使用。

## Abstract
Alongside memory storage and retrieval, a fundamental challenge in long-term LLM agent systems is how the agent should act when stored memories conflict with an evolving world. Facts often go stale without explicit deletion, so the conflict surfaces before the store is refreshed: delayed feedback shows that acting on one outdated record hurt, but not whether suppression should stay on that fact (a local policy) or extend to other stored facts (a global policy). Existing systems hard-code one of these scopes at design time. We formulate this online choice, under hidden validity and delayed feedback, as memory conflict governance, and propose RegimeCouncil, a lightweight router that keeps both scopes as advisors and arbitrates between them without retraining the LLM. Each memory-assisted response is scored against a no-memory anchor, by off-path paired comparison or by inverse-propensity estimation from the executed action alone. A Local Advisor tracks only the queried fact, a Global Advisor pools recent outcomes across the store, and an asymmetric Meta Governor follows Local by default, switching to Global only when pooling yields a strictly positive recent utility margin. We prove that using delayed outcomes escapes the prompt-only regret floor, that neither fixed scope suffices alone, and that this margin gate switches within bounded time. On LongMemEval streams, historical drift in TempLAMA and TAQA, delays $τ\in [1, 96]$, and sparse or bandit feedback, with Qwen3-30B-A3B and GPT-4o, RegimeCouncil outperforms the better fixed scope in all 30 held-out settings, by 5.2-7.3 points on disagreement episodes and +27.9 points over standalone cold-start fallback under clustered shifts, while cutting harmful stale-memory use at microsecond overhead.

## 2. 方法论

### 2.1 问题建模
- 智能体维护包含 K 个事实键的记忆库，每个键 k 对应一个维度（如城市、通勤、过敏原）。
- 在步骤 t，查询键 kt，观测 zt 中不包含隐藏有效性状态 rt；系统选择动作 at∈{0,1}：
  - `at=1`：注入存储记忆；
  - `at=0`：使用无记忆锚点（仅基座模型回答）。
- 效用 ut∈[0,1]，真实反馈最多延迟 τ 步揭示。

### 2.2 证据评分
- **配对效用差**：对每个已揭示回合 s，定义  
  `ds = us,mem − us,0 ∈ [−1,1]`  
  其中 `us,mem` 为注入记忆后的效用，`us,0` 为无记忆锚点效用；`ds>0` 表示记忆有帮助，`ds<0` 表示过时记忆有害。
- 支持两种反馈模式：
  - **异步配对模式**：用户即时收到所选动作的回答，延迟反馈到达后再后台评估无记忆回答，得到 (us,mem, us,0)，不增加关键路径延迟；
  - **仅已执行动作的 bandit 模式**：仅能观察到执行动作的标量效用，混合 ε-探索（ε=0.05），使用逆倾向估计
    `ˆds = 1[as=1] us/ps − 1[as=0] us/(1−ps)`，满足无偏性 E[ˆds|hs]=ds。

### 2.3 RegimeCouncil 架构
三个模块均基于已揭示事件流，使用滑动窗口，O(1) 时间更新：

- **全局顾问（Global Advisor）**：
  - 维护最近 Wg 个跨键配对差窗口；
  - 若窗口内 sum(di) > 0，则提议使用记忆；
  - 能快速响应集群漂移并为未见键提供“暖启动”，但会混合异步漂移的正负信号。

- **局部顾问（Local Advisor）**：
  - 设置为 Wℓ=1，即只读取当前查询键 kt 的最新已揭示结果 dlast(kt)；
  - 若 >0 提议记忆，<0 提议抑制；
  - 当本地无决定性信号（冷启动或 tie）时有两种处理：
    - **RegimeCouncil（保守 tie 弃权）**：本地默认弃权（ℓt=0），减少有害记忆暴露；
    - **RegimeCouncil-TD（冷启动 tie 委托）**：在本地无信号时将决策委托给全局顾问，提升长延迟下的冷启动覆盖。

- **非对称元调控器（Meta Governor）**：
  - 计算最近 Wm 个已揭示回合中全局相对局部的反事实效用边际：
    `At = Σ_{i∈Wm(t)} (vg,i − vℓ,i)`
  - 其中 vg,i/vℓ,i 分别表示对应顾问提出动作在该回合所能获得的效用；
  - **非对称规则**：默认采用局部顾问；仅当 `At > 0` 时才切换为全局顾问；
  - 该设计使局部无偏估计成为默认锚点，全局只在近期表现出严格正向额外收益时接管。

### 2.4 理论保证
- **命题 1**：仅基于当前观测的策略存在常数级遗憾下界 δ=pqΔ；使用延迟历史（如局部顾问）可在 T 足够大时突破该下界。
- **命题 2**：存在全局顾问产生 Ω(T) 遗憾的异步漂移流，也存在局部顾问产生 Ω(T) 遗憾的稀疏键流；因此任一固定作用范围都不足够。
- **命题 3**：若全局对局部的效用边际在连续 Wm 个揭示回合中保持 ≥γ>0，则元调控器会在至多 Wm+τ 步内切换到全局；负向持续边际则切换回局部。

  - 覆盖 16/54-key 合成流、真实历史漂移、多种延迟与噪声；
  - 开发/留出分离、固定冻结窗口、缓存生成保证公平比较；
  - 提供 bootstrap CI、敏感性表格与完整附录。
- **实用开销极低**：每决策 2.29 µs，关键路径零额外调用，适合生产环境。

## 8. 不足与局限

- **算力信息缺失**：未披露 GPU 型号、数量、推理时间/成本，难以评估完整资源需求。
- **部分统计显著性有限**：Schedule B 全流置信区间包含零，说明某些场景下全流收益不够稳健；bandit 结果缺少方差展示。
-

- **bandit 模式结果展示不完整**：虽然报告了平均准确率与有害暴露，但未提供各探索种子下的方差或置信区间，难以判断仅执行动作反馈时方法的稳定性是否会被探索随机性显著影响。
- **真实历史漂移基准规模偏小**：TempLAMA 仅 120 个事实、TAQA 仅 100 个表格问题，且时间变化集中在 2010–2020 或 2000–2023，覆盖领域有限；在开放世界长尾知识中，静默过时可能以更复杂、更稀疏的方式出现，当前实证不足以完全支撑跨领域泛化结论。
- **合成更新流对现实复杂性的抽象较强**：Block-Switch、Independent-Switch、Poisson-Flip 等调度假设键翻转相对规则、可预测；真实环境中过时事实可能具有多步因果依赖、渐变漂移或突发性集体失效，模型未对这些更复杂的失效模式进行系统验证。
- **配对反馈的总体推理成本未被量化**：异步配对模式虽不增加关键路径延迟，但需要后台额外生成无记忆回答来构造配对效用差；论文未给出该模式下相比仅执行动作反馈或固定策略的总体 API/GPU 调用量增幅，因此“零训练算力”之外的推理成本透明度仍不足。
- **模型种族与规模覆盖有限**：主要结论基于 GPT-4o 和 Qwen3-30B-A3B 两个模型，未在更多模型家族（如 Claude、Gemini、Llama 系列）或更小开源模型上验证；不同模型对记忆冲突信号的敏感度和校准差异可能影响 RegimeCouncil 的切换行为。
- **元调控器的超参数需要离线调优**：窗口大小 Wm、切换阈值、全局顾问窗口 Wg 等均通过开发集选择，虽给出敏感性分析，但未提供面向非平稳环境的自适应调参策略；当环境分布随时间变化时，固定超参数可能逐渐失效。
- **方法只治理“是否注入记忆”，不治理记忆内容本身**：论文假设记忆库中存在过时但内容固定的键值对，仅决策是否抑制；未涉及记忆内容的主动更新、合并或删除机制，因此无法处理记忆库中同时存在的冗余、矛盾或错误知识需要被修正的场景。
- **反馈延迟模型假设上界已知**：理论分析和实验设置中延迟 τ 有明确上界（如 τ≤96），但真实用户反馈可能缺失、任意长，或存在选择性报告偏差；该方法在无界延迟或反馈缺失率随时间变化时的鲁棒性尚未被充分检验。
