## 摘要
参数化记忆允许大语言模型将知识直接内化到其权重中，为基于检索的记忆（RAG）提供了一种潜在强大的替代方案。然而，现有的参数化记忆方法难以部署，因为它们大多反映了持续学习（CL）无限期保留信息的目标。这对于记忆系统而言既不具可持续性也不充分；记忆系统必须在其整个生命周期中管理知识：保留稳定事实、强化反复出现的观察、更新已改变的信念，并允许短暂信息淡去。我们提出了一种参数化记忆管理系统，由记忆基底（负责信息存储与遗忘）和习得策略（记住什么、记忆多深以及保留多久）组成。我们的基底是一个固定容量的 LoRA 适配器，由 k-hot 秩组合构成，能够存储事实而无灾难性干扰，并保持独立可控的时间衰减，使过时信息消退而长期事实得以保留。在此基底之上，我们训练一个轻量级控制器来管理每个传入的用户事件，确保记忆系统反映用户真实且更新后的信念状态。为评估记忆系统如何管理用户记忆，我们引入了一个受控数据集，其中包含长时程用户轨迹，事实的持久性随信念状态变化和用户行为转变而不同；并设计了探测查询，在信息有效时测试回忆，在信息过期后测试拒答。我们的策略学会了在整个生命周期内有效管理用户记忆，在回忆与拒答之间取得平衡，达到了 oracle 性能的 86%，这与主要默认其中一种行为的 CL 和 RAG 基线不同。通过提供首个直接在模型权重中管理记忆的系统，这项工作为长时程参数化记忆奠定了基础。

## Abstract
Parametric memory allows Large Language Models to internalize knowledge directly into their weights, offering a potentially powerful alternative to retrieval-based memory (RAG). However, existing approaches to parametric memory are difficult to deploy as they largely mirror the Continual Learning (CL) objective of retaining information indefinitely. This is neither sustainable nor sufficient for a memory system, which must govern knowledge across its lifecycle by retaining stable facts, reinforcing recurring observations, updating changed beliefs, and allowing transient information to fade. We propose a system for parametric memory management consisting of a memory substrate (handling information storage and forgetting) and a learned policy (what to remember, how deeply, and for how long). Our substrate is a fixed-capacity LoRA adapter that consists of k-hot rank combinations which store facts without catastrophic interference and maintain an independently controlled temporal decay, enabling outdated information to fade while long-term facts persist. On this substrate, we train a lightweight controller that governs each incoming user event to ensure the memory system reflects the user's true, updated belief state. To evaluate how memory systems manage user memory, we introduce a controlled dataset of long-horizon user trajectories with varying persistence of facts based on changing belief states and user-behavioral shifts, and probe queries that test recall while information is valid and abstention after it expires. Our policy learns to effectively manage user memory over its entire lifecycle, balancing recall and abstention to achieve 86% of oracle performance, unlike CL and RAG baselines that primarily default to one of the two behaviors. By providing the first system to manage memory directly in model weights, this work establishes a foundation for long-horizon parametric memory.

  - **记忆基底（substrate）**：负责信息的实际存储与自然衰减；

### 2. 论文提出的方法论

#### 2.1 总体架构

系统包含四个核心部分：

- 冻结的 **Qwen3-1.7B 骨干模型**；
- **记忆适配器（Memory LoRA）**：用于实际存储用户事实；
- **检索适配器（Retrieval LoRA）**：训练用于决定输出“正确值”还是“Unknown”；
- **路由器 + 控制器**：决定写入位置与写入强度。

#### 2.2 记忆基底：稀疏 k-hot 秩组合 + 独立时间衰减

- 使用固定容量的 **LoRA 适配器**作为记忆存储。
- 将 LoRA 的 B 矩阵中 \( R \) 个秩列视为可寻址记忆单元。
- 每个事实被路由到一个 **k-hot 秩子集**（主实验 \( R=32, k=2 \)），从而限制不同事实之间的梯度干扰。
- 每个秩列具有**独立的时间衰减常数 \( \tau_i \)**：
  \[
  B[:,i] \leftarrow B[:,i] \cdot \exp(-\Delta t / \tau_i)
  \]
  控制器可为每个写入分配合适的生命周期。
- 通过深度 \( d \)（SGD 步数）控制写入强度，形成**分级记忆而非二元可检索性**。
- 重复写入可累积强化；矛盾写入可覆盖旧值。

#### 2.3 检索适配器与拒答机制

- 训练一个独立的 rank-32 检索适配器，与记忆适配器共同工作。
- 其训练标签是**深度条件化的概率目标**：写入深度较浅时更可能输出“Unknown”，深度较深时更可能输出正确值。
- 这使**弱记忆痕迹能够被校准为拒答**，避免模型幻觉。

#### 2.4 管理控制器

- 控制器规模约 **2M 参数**（不到骨干模型 0.4%）。
- 对每个传入事件输出动作三元组：
  - **Gate \( g \in \{0,1\} \)**：是否写入；
  - **Depth \( d \in \{20,30,40,60,80,110,150\} \)**：写入强度；
  - **Lifespan \( \tau \in \{25,100,400,1600,20000\} \)**：衰减时间尺度（天）。
- 控制器输入包括：
  - 事件的语义嵌入；
  - 用户轨迹历史的 GRU 状态；
  - 记忆基底状态（各秩年龄、范数、前向信号等）。
- 训练方式：
  - 使用**有因果元数据但无未来信息的 oracle 策略**做行为克隆；
  - 使用 **DAgger** 让监督适应学生实际写入后的基底状态；
  - 可选第二阶段 PPO 精调（增益甚微）。

#### 2.5 工作流程

- **离线**：训练检索适配器；
- **写入时**：路由器选择 k-hot 秩；控制器决定 gate、depth、lifespan；执行 SGD 写入；
- **事件间**：各秩按自身 \( \tau \) 指数衰减；
- **查询时**：路由选择秩；检索适配器基于基底状态输出“值”或“Unknown”；控制器不参与。

### 3. 实验设计

#### 3.1 数据集

- 构建了 **909 条受控长时程用户轨迹**，跨越 **700–1500 天**，由 Gemini 3.7 Flash 生成。
- 生成流程包含五个阶段：行为母题采样 → 多年背景故事 → 时间事件流 → 实体掩码与生命周期标注 → 时序一致性验证。
- 共约 **170K 写入**、**144K 查询**。
- 使用**模板化输入**（实体替换为类型占位符，如 `FRUIT_4`），以消除预训练世界知识影响。
- 提供**自然语言版本**数据用于额外验证。

#### 3.2 五类记忆类别

基于真值稳定性分数和有效期等标注，将事实分为五类：

| 类别 | 占比 | 含义 | 挑战 |
|---|---|---|---|
| STABLE | 26% | 长生命周期（90–3650 天），通常只写一次（如职业） | 长时程保留 |
| ROUTINE | 42% | 短期（2–21 天）但反复出现（如晨咖啡） | 累积强化 |
| CONTESTED | 20% | 值随时间被覆盖（如当前项目） | 信念修订 |
| TRANSIENT | 7% | 极短生命周期（1–10 天），不重复（如今日午餐） | 选择性过期 |
| ONESHOT | 4% | 中等期限（15–90 天）、不重复 | 中间时程保留 |

#### 3.3 查询评估

- **VAL 查询**：信息有效期内查询，要求输出当前正确值。
- **ABS 查询**：信息过期后查询，要求输出 “Unknown”。
- 报告**类平衡准确率（CB）**，避免多数类主导。

#### 3.4 对比方法

- **持续学习方法**：Naive LoRA、EWC、PCGrad（均为固定深度写入）；
- **无管理写入基线**：不同固定深度（d=20 至 d=110）；
- **检索基线**：
  - RAG（1.7B）；
  - RAG-MM（带写时管理，1.7B 与 122B）；
  - RAG + oracle 元数据（1.7B 与 122B）；
- **本文方法**：
  - PMM-PR（完美路由）；
  - PMM-LR（习得路由）。

### 6. 论文的主要结论与发现

1. **持续学习不足以解决参数化记忆管理问题**：
   - PCGrad 可达到 0.82 的 VAL 检索准确率，但 ABS 为 0.00；
   - 固定深度写入普遍存在 VAL–ABS 权衡困境：深度越深，检索越好，但无法遗忘。

2. **生命周期管理可从在线观察中习得**：
   - PMM-LR 达到 0.56 CB，相当于 metadata oracle 的 86%；
   - PMM-PR 达到 0.60 CB，oracle 上限为 0.65。

3. **每秩独立 \( \tau \) 是必要机制**：
   - 移除 per-rank \( \tau \) 后，PMM-PR 从 0.60 降至 0.48；
   - 全局 \( \tau \) 导致易变类 ABS 几乎归零。

4. **共享列导致寿命被压缩**：
   - 当长期事实与短期事实共享秩列时，后写的短期 \( \tau \) 会覆盖长期 \( \tau \)；
   - 这是 STABLE VAL 较低的主要原因；
   - 使用专属列可显著提升 STABLE 记忆（0.70–0.82 VAL），但需约两倍存储。

5. **管理信号中语义、历史与基底状态是互补的**：
   - 去掉语义或先验导致整体表现大幅下降；
   - 去掉历史对 ONESHOT VAL 尤其有害（−24 点）；
   - 去掉基底状态对 ROUTINE ABS 尤其有害（−9 点）。

6. **方法在自然语言输入下具有迁移性**：
   - NL 设置下各控制器与模板设置差距在 0.02 CB 以内。

### 7. 优点

- **概念清晰且实用**：将“基底动力学”和“管理策略”分离，是重要且合理的设计抽象。
- **显式建模遗忘**：引入每秩时间衰减，使遗忘成为可控操作而非未建模行为。
- **校准的检索与拒答**：用深度条件化标签训练检索适配器，缓解弱痕迹导致的幻觉。
- **受控基准设计严谨**：提供事件级生命周期真值，具有记忆类别、VAL/ABS 查询、类平衡评估，能针对性验证生命周期假设。
- **消融实验深入**：覆盖路由器、容量、输入特征、独立寿命、共享列干扰等关键因素。
- **与 RAG 做 compute-matched 比较**，避免不公平地使用大量外部计算来打压基线。
