## 摘要
视觉-语言导航（VLN）要求智能体在长导航片段中持续累积并推理流式视觉观察。现有方法受限于Transformer架构有限的上下文容量，难以维持长期历史。为解决该问题，快速权重测试时训练（TTT）提供了一种将流式观察编码为持续演化的参数状态的机制。然而，现有TTT并未区分信息性观察与重复视觉内容，导致冗余token干扰后续决策所需信息的保留。我们提出导航条件化的测试时训练（NavTTT），为视觉-语言导航引入自适应记忆形成与分层记忆整合。NavTTT利用全局导航上下文优先处理信息性视觉证据，并将语言指令与空间信息整合，构建空间锚定的记忆表示。片段局部的非线性快速权重将这些表示存储为自适应参数记忆（APM），在视觉上下文之外保留历史以用于后续决策。为减少记忆形成中的跨层耦合，NavTTT在多个解码器深度上维护独立的快速权重记忆。这种解耦设计防止误差或偏置在不同记忆层级间传播。同时，它使共享历史信息能够在不同抽象层级上被独立表示。实验在VLN-CE基准上展示了强大的导航性能，并在真实机器人上实现了有效的指令跟随。

## Abstract
Vision-and-language navigation (VLN) demands that agents accumulate and reason over streaming visual observations throughout long navigation episodes. Existing approaches struggle to maintain long-term history, constrained by the finite context capacity of transformer architectures. To solve the problem, fast-weight test-time training (TTT) provides a mechanism for encoding streaming observations into an evolving parameter state. However, existing TTT does not distinguish informative observations from repetitive visual content, allowing redundant tokens to interfere with the retention of information needed for subsequent decisions. We propose Navigation-Conditioned Test-Time Training (NavTTT), which introduces adaptive memory formation and hierarchical memory integration for vision-and-language navigation. NavTTT leverages global navigation context to prioritize informative visual evidence and integrates language instructions with spatial information to construct spatially grounded memory representations. Episode-local nonlinear fast weights store these representations as Adaptive Parametric Memory (APM), preserving history beyond the visual context for later decisions. To reduce cross-layer coupling in memory formation, NavTTT maintains independent fast-weight memories across multiple decoder depths. This decoupled design prevents errors or biases from spreading across different memory levels. Meanwhile, it enables shared historical information to be independently represented at various levels of abstraction. Experiments demonstrate strong navigation performance on VLN-CE benchmarks and effective instruction following on a real robot.

- **研究背景**：视觉-语言导航（VLN）要求智能体在长导航片段中持续累积并推理流式视觉观察，而导航决策天然依赖历史信息，例如已访问地点、地标和已完成子目标。
- **现有局限**：
  - 显式记忆（地图、图、轨迹）或隐式记忆（循环特征、持久 token）本质仍是 token-based，受限于 Transformer 有限上下文容量，难以长期保留历史。
  - 长期导航中连续观察高度冗余，只有少量历史信息对后续决策有用，token-based 记忆必须在覆盖范围与计算预算之间不断权衡。
- **核心问题**：如何将过去经历存储到模型参数状态中，而非继续作为持久 token；以及应当**存储什么信息**、**如何在导航中使用这些信息**。
- **整体含义**：NavTTT 提出一种面向 VLN 的**参数化记忆框架**，通过测试时训练将导航经验选择性地内部化到片段级快速权重中，以突破视觉上下文窗口限制，缓解冗余 token 对长期记忆的干扰。

## 2. 论文提出的方法论

- **核心思想**：利用**导航条件化测试时训练（NavTTT）**，在推理阶段通过快速权重更新在线编码历史观察，使过去的视觉证据在离开当前上下文后仍可为后续决策所用。
- **自适应记忆形成（写什么）**：
  - 使用冻结视觉编码器提取视觉 token 特征，并加入傅里叶位置编码。
  - 导航状态编码器（NSE）将指令、位姿、步数编码为全局状态 \(c\)，再与解码器高层决策 token 融合为全局引导上下文 \(z\)。
  - 通过 \(z\) 与每个视觉 token 特征融合，计算任务相关性分数 \(r_i\)。
  - 在相关性评分基础上，引入**增量式多样性选择**：逐个选择 token，对已选 token 相似度过高的候选进行惩罚，抑制同一帧中的视觉冗余。
- **上下文关联编码（如何写）**：
  - 对每个被选中的视觉区域，生成层特定的键 \(k_i\) 和值 \(v_i\)。
  - 键编码视觉-位置线索用于检索；值融合视觉外观 \(a_i\)、空间上下文 \(\xi_i\)（patch 坐标与相对位姿）以及导航状态 \(z\)，形成空间锚定、任务相关的记忆表示。
- **分层记忆整合（如何用）**：
  - 在 36 层解码器的第 \(\{5,11,17,23,29,35\}\) 层（0-based）插入 APM 分支，每层维护**独立的非线性快速权重**。
  - 每个 APM 分支包含 4 个记忆头，查询 \(q\) 通过 SwiGLU 非线性映射 \(f_{W}(q)=W_1(\text{SiLU}(W_0 q)\odot(W_2 q))\) 检索历史。
  - 自注意力通路与记忆通路通过残差结合：\(\tilde h_j = h_j + \text{SelfAttn}(H)_j + \gamma_j \text{APM}(h_j;W_{t-1})\)，其中门控 \(\gamma_j\) 在决策/动作位置固定为 1，部分视觉 token 由学习投影+sigmoid 控制。
- **在线更新流程**：
  - 采用因果“先读后写”顺序：当前步使用上一步记忆状态 \(W_{t-1}\) 进行推理；决策完成后，用当前观察的键值对计算记忆损失 \(L_{\text{mem}} = -\sum_i m_i \langle f_W(k_i), v_i\rangle\)，做一步梯度下降更新 \(W_t\)，供下一步使用。
  - 训练时联合优化导航自回归交叉熵损失与 APM 模块；推理时骨干网络冻结，仅更新片段级快速权重。

## 6. 论文的主要结论与发现

- NavTTT 在 **R2R-CE Val-Unseen** 上达到 **66.7% SR / 59.4% SPL**，在 **RxR-CE Val-Unseen** 上达到 **63.6% SR / 52.7% SPL / 71.0% nDTW**，均优于代表性基线（如 JanusVLN、StreamVLN、NaVILA、Uni-NaVid）。
- **快速权重记忆**带来持续提升：在 Qwen3-VL-8B 上，相比无记忆控制，R2R-CE SR 提升 4.3 个点，RxR-CE SR 提升 3.4 个点；在 Qwen2.5-VL-7B-Instruct 上也有类似增益。
- **在线适应** 比静态记忆进一步提升：以 Qwen3-VL-8B 为例，开启在线写入在 R2R-CE 上额外增加 3.32 个点 SR、2.6 个点 SPL；在 RxR-CE 上 nDTW 提升 4.1 个点。
- **导航特定设计**（选择性写入 + 空间/导航上下文编码 + 多深度检索）优于直接 LaCT 适应，尤其在 SPL 和 nDTW 上。
- **组合式 token 选择**（相关性 + 多样性）优于单独使用任一标准，说明任务相关性和视觉去冗互补。
- **分层独立记忆**在相同存储条件下优于单层访问；六层独立比六层共享 SR 更高，但共享配置在 SPL 和存储上具有优势。
- **长路径收益更大**：完整模型相对无 APM 基线在长路径组 SR 优势最明显；在线更新在 R2R-CE 长路径组带来 +9.97 个点 SR。
- 真实机器人成功率 27.5%，说明该方法具备一定的 sim-to-real 迁移能力，但仍有很大提升空间。

## 7. 优点

- **方法创新性**：首次将非线性快速权重测试时训练系统性地引入 VLN，提出参数化隐式记忆，超越 token-based 记忆范式。
- **问题针对性**：明确解决 TTT 直接应用时“写什么”和“如何用”的问题，通过导航条件化选择缓解视觉冗余。
- **设计合理性**：
  - 上下文关联编码将视觉、空间和导航状态融合，形成空间锚定的记忆。
  - 多解码器深度独立记忆减少跨层误差传播，并提供多抽象层级的历史表示。
  - 因果“先读后写”保证在线推理与训练一致，避免信息泄漏。
- **实验扎实**：
  - 在两个主流 VLN-CE 基准上对比大量代表性方法。
  - 使用两个不同 VLM 骨干进行消融，增强结论可信度。
  - 提供真实机器人定性/定量评估，体现实际部署潜力。
  - 补充了推理延迟、显存和记忆读写诊断，工程分析较完整。
- **性能优势**：在任务完成率与路径效率上均取得领先，尤其在长路径上展现了记忆的必要性。

## 8. 不足与局限

- **真实世界成功率低**：40 次试验仅 27.5% 成功，表明 sim-to-real 差距仍大；论文也将其主要用于定性验证，尚未达到实用水平。
- **数据需求较大**：使用了约 297 万额外的图像-动作对，虽然论文声称相对某些方法较少，但对资源有限的团队仍是不小负担。
- **对比公平性有限**：主表中不同方法在观察模态（全景 vs 单 RGB）、位姿/深度信息、训练数据规模和基础模型上不一致，横向对比需谨慎。
- **消融中的非单调现象**：例如在某些设置中完整 NavTTT 的 SPL 略低于静态记忆或直接 LaCT，说明指标提升不完全一致，路径效率收益可能依赖训练/评估条件。
- **记忆检索诊断的绝对命中率低**：历史读出行在 32 次更新后 first-rank hit 率仅为约 5.23%，说明快速权重对同批写入的值区分能力有限，记忆的精确可解释性不足。
- **应用限制**：
  - 当前设计依赖单目 RGB 观察和离散动作空间，对其他传感器（如深度、激光）和连续动作策略的扩展尚不明确。
  - 快速权重只保持在一个 episode 内，未探讨跨片段长期经验保留。
- **未来挑战**：作者也提到需进一步研究更长轨迹下的记忆保留，以及具有重复地标或更强视觉歧义环境中的性能。
