1. Introduction
Vision-and-language navigation (VLN) [2, 16] requires an
embodied agent to interpret natural-language instructions
and sequentially interact with complex visual environments
to reach a target destination. Unlike static vision-language
understanding, navigation decisions are inherently history-
dependent [12]: the agent must continuously relate its cur-
rent observation to previously visited locations, encoun-
tered landmarks, and completed sub-goals in order to infer
its progress and determine the next action [8]. This makes
memory a fundamental component of VLN systems. An
effective navigation memory should not only preserve use-
ful historical information over long trajectories, but also se-
lectively retain observations that remain relevant to future
decisions [32], while avoiding excessive accumulation of
repetitive visual content [34].
Existing VLN methods maintain navigation history
through either explicit [1, 8, 9] or implicit memory [12,
18, 34]. Explicit memory organizes past experience into
structured representations, such as maps, graphs, or tra-
jectories, making historical state directly accessible to the
agent. Implicit memory instead compresses history into la-
tent representations, typically as recurrent features or per-
sistent tokens propagated across time.
While less struc-
tured, these implicit memories remain fundamentally token-
based: retaining more history still requires preserving, up-
dating, or repeatedly attending to an expanding set of latent
states. This dependence becomes increasingly problematic
in long-horizon navigation, where successive observations
are highly redundant and only a small fraction of past infor-

This limitation motivates a different form of implicit

Test-time training (TTT) [25, 26] provides a
mechanism for doing so by updating fast weights with in-
coming observations, allowing past information to persist
in the model parameters [5]. However, applying TTT di-
rectly to VLN is not straightforward.
Navigation obser-
vations are highly redundant: nearby steps often produce
similar visual inputs, while only a few observations remain
useful for later decisions. Which observations matter also
depends on the instruction, the agent’s current location, and
its progress along the route. Simply writing every obser-
vation into fast weights can therefore fill the memory with
repeated or short-lived visual information and make impor-
tant landmarks harder to preserve. In addition, navigation
history needs to support different stages of decision mak-
ing, while a generic fast-weight memory does not specify
how historical information should be used across the navi-
gation model. TTT-based memory for VLN therefore needs
to address two key questions: what information should be
stored, and how should that information be used during nav-
igation.
To address these challenges, we introduce Navigation-
Conditioned Test-Time Training (NavTTT), a parametric
memory framework that selectively internalizes navigation
experience into episode-specific fast weights. NavTTT con-
ditions memory formation on global navigation context, pri-
oritizing visual evidence relevant to the instruction and nav-
igation state while suppressing redundant content. It further
integrates linguistic and spatial cues into the selected evi-
dence, grounding memory in visual appearance and naviga-
tion context. To make accumulated experience accessible at
multiple stages of navigation reasoning, NavTTT maintains
independent fast-weight memories across decoder depths.
Each memory transforms the selected evidence through its
own association encoders and accumulates it via separate
online updates. During subsequent decisions, hidden repre-
sentations at each depth query the associated memory, inte-
grating historical information with ongoing decoder compu-
tation. Together, adaptive memory formation and hierarchi-
cal memory integration allow navigation history to persist
beyond limited visual context and inform subsequent deci-
sions through layer-specific encoding and retrieval.
We evaluate NavTTT on the R2R-CE [2] and RxR-
CE [19] benchmarks to examine the effectiveness of adap-
tive parametric memory for vision-and-language naviga-
tion. NavTTT achieves 66.7% SR and 59.4% SPL on R2R-
CE, and 63.6% SR and 52.7% SPL on RxR-CE, consistently
outperforming representative VLN baselines.
Controlled
ablations demonstrate that persistent fast-weight memory,
online episode-level adaptation, and adaptive evidence se-
lection each contribute substantially to navigation perfor-
mance. Together, these results show that selectively inter-
nalizing navigation history through fast-weight updates pro-
vides an effective mechanism for preserving and exploiting
long-horizon experience beyond the active visual context.
• We introduce NavTTT, a parametric memory framework
for vision-and-language navigation that internalizes ob-
servations into episode-specific fast weights through test-
time training, making accumulated experience accessible
beyond the explicit visual context.
• We propose navigation-conditioned memory formation
that jointly considers task relevance and visual redun-
dancy when selecting evidence, and incorporates linguis-
tic and spatial cues to construct grounded representations
for memory updates.
• We develop a hierarchical memory architecture that in-
dependently encodes and accumulates shared historical
evidence across decoder depths. Layer-specific queries
retrieve this information during subsequent decisions, in-
tegrating persistent memory into multiple stages of navi-
gation reasoning.
2. Related Work
2.1. Vision-Language Navigation and Memory
Vision-language navigation (VLN) has evolved from
vision-language pre-training and sequential history model-
ing toward foundation-model-based navigation. Early ap-
proaches leverage large-scale pre-training [11] or explic-
itly model navigation history, such as recurrent state prop-
agation in VLN-BERT [12] and long-horizon trajectory en-


coding in HAMT [8]. DUET [9] further constructs an on-
line topological map to couple global planning with local
grounding.
More recently, NavGPT [41] and NaviLLM
[40] explore LLM-based navigation reasoning, while NaVid
[35], Uni-NaVid [36], and NaVILA [10] extend VLMs to-
ward end-to-end, unified, and real-world navigation. Our
work complements this line by focusing specifically on how
historical observations are retained and exploited during
navigation.
Recent VLN systems have consequently developed in-
creasingly sophisticated memory mechanisms. StreamVLN
[31] maintains a slow-updating compressed visual con-
text alongside a fast streaming context, while NavMorph
[33] introduces contextual evolution memory within a self-
evolving world model.
JanusVLN [34] maintains sepa-
rate spatial-geometric and visual-semantic histories as com-
pact implicit memories, whereas HiMemVLN [22] orga-
nizes navigation history through a hierarchical memory sys-
tem. Memoir [32] further studies retrieval of accumulated
environmental and behavioral experience across navigation
episodes.
Unlike these approaches, NavTTT selectively
writes navigation-relevant observations into online-adapted
fast weights, treating the model parameters themselves as
persistent memory during an episode.
2.2. Parametric Memory and Test-Time Training
Test-time training (TTT) was originally introduced for
self-supervised adaptation on unlabeled test samples [25],
but has recently been repurposed as a sequence-modeling
mechanism in which fast weights serve as recurrent state
[26]. This view is closely related to earlier fast-weight for-
mulations of linear attention: Schlag et al. [24] interpret
linear Transformers as fast-weight programmers that store
key–value associations in rapidly changing weights. Mod-
ern TTT generalizes this perspective by allowing a learn-
able, potentially nonlinear model to serve as the evolv-
ing parameter state. Titans [5] develops such online neu-
ral memory for long-context modeling, while LaCT [39]
enables large nonlinear fast-weight states through efficient
large-chunk updates.
Recent work further explores fast weights as explicit
parametric memory for adaptive inference and agents.
TMEM [23], for example, consolidates interaction experi-
ence into lightweight online-updated parameters rather than
relying solely on prompt-space memory. NavTTT adopts
LaCT’s nonlinear fast-weight formulation as its underlying
memory operator, but focuses on a different question: how
TTT-based memory should be organized for embodied navi-
gation. Specifically, we study what to write into fast weights
from redundant visual streams and where to write this infor-
mation across the navigation model.
3. Methodology
3.1. Preliminary
Navigation task. Vision-and-language navigation in con-
tinuous environments (VLN-CE) tasks an embodied agent
with navigating to a target destination by following a
natural-language instruction x via sequential interactions
with the environment. At each decision step t, the agent
observes an egocentric RGB image It, maintains a visual
history Ht of up to 7 sampled frames, and receives an
episode-relative pose st = (pt, sin ψt, cos ψt), where pt
denotes its 2D position and ψt its heading. These inputs
are denoted by Xt = (x, Ht, It, st, t).
Conditioned on
the instruction and all available observations, the naviga-
tion policy predicts an action sequence At of up to 4 prim-
itive actions drawn from the discrete action space A =
{FORWARD, LEFT, RIGHT, STOP}, where t indexes deci-
sion cycles rather than individual actions. An episode termi-
nates upon the STOP action or exhaustion of the predefined
interaction budget. The core objective is to reach the target
location efficiently while faithfully adhering to the given in-
struction.
Test-Time Training. In the fast-weight formulation, test-
time training (TTT) enables online adaptation through a
neural memory fW , whose parameters are updated as new
observations arrive, while the pretrained backbone remains
fixed during inference. Given a query qt and selected key–
value pairs (ki, vi), NavTTT adopts a causal read-before-
write order. In the basic gradient-descent form:

3.3. Fast-Weight Memory for Navigation
NavTTT extends the limited visual context capacity by
persisting selected task-relevant visual evidence via Adap-
tive Parametric Memory (APM). Following the LaCT [39]
framework, each memory-augmented decoder layer main-
tains an independent nonlinear fast-weight mapping to en-
code accumulated key-value associations. During naviga-
tion, this persistent memory complements the self-attention
pathway over instructions and current observations, con-
necting current perception with historical experience from
earlier decisions.

3.3.2. Hierarchical Retrieval and Memory Fusion

through a hierarchical dual-path decoder. Self-attention is
retained throughout the 36-layer backbone, while parallel

using zero-based indices. These branches provide memory
access at different decoder depths. Each augmented layer
maintains independent fast weights, allowing historical ev-
idence to be encoded and retrieved through layer-specific
representations.

4. Experiments
4.1. Experimental Setup
Simulation environments and metrics.
Following
standard evaluation protocols for continuous vision-and-
language navigation [31, 34], we evaluate NavTTT on the
R2R-CE and RxR-CE benchmarks [2, 16, 19]. Both bench-
marks require agents to follow natural-language instruc-
tions and navigate continuous Matterport3D [6] environ-
ments via low-level actions. Experiments are evaluated on
the R2R-CE Val-Unseen split and the RxR-CE Val-Unseen
split. R2R-CE performance is reported using NE, OS, SR,
and SPL, while RxR-CE performance is reported using NE,
SR, SPL, and nDTW. SR and SPL serve as primary metrics
for task completion and navigation efficiency.
Real-world evaluation setup. We deploy NavTTT on a
humanoid robot (shown in Figure 3) to assess the real-
world deployment capability and Sim-to-Real generaliza-
tion of its learned memory mechanism in continuous navi-
gation tasks. The robot perceives the environment through
a forward-facing RGB camera, receiving natural-language
instructions alongside streaming egocentric visual obser-
vations.
NavTTT runs on an off-board inference server
equipped with an NVIDIA RTX 4090 GPU, transmitting
predicted low-level navigation actions to the robot for exe-
cution. No real-world trajectories are used for fine-tuning,
enabling a direct assessment of sim-to-real generalization.
Implementation details.
NavTTT is initialized from
Qwen3-VL-8B [3], with APM integrated from the begin-
ning of joint training. The language backbone, multimodal
projector, and APM modules, including the learned fast-
weight initialization, are jointly fine-tuned, while the vision
encoder remains frozen. Joint training runs for one epoch
using AdamW with a weight decay of 10−2 and a cosine
learning-rate schedule with a warmup ratio of 0.03, con-
suming approximately 1,910 GPU hours on NVIDIA H20
GPUs. The peak learning rates are 1 × 10−5 for the lan-
guage backbone and 5×10−6 for the multimodal projector.
The architectural ablations in Section 4.3 follow the same
joint-training protocol as the main model. We detail the


training objective and inference-time fast-weight updates in
the supplementary material.
4.2. Main Results
Results on VLN-CE benchmarks.
Table 1 compares
NavTTT with representative VLN-CE methods across ob-
servation modalities and training setups. On R2R-CE Val-
Unseen, NavTTT achieves a leading 66.7% SR and 59.4%
SPL, outperforming JanusVLN by 6.2 SR / 2.6 SPL and
StreamVLN by 9.8 SR / 7.5 SPL. These improvements
demonstrate how our selective memory pipeline resolves
perceptual ambiguities. Context-guided selection isolates
task-relevant visual regions, whereas intra-frame redun-
dancy suppression ensures maximal feature diversity within
each fast-weight update.
NavTTT parametrically regis-
ters these distilled historical anchors into fast weights and
queries them alongside streaming observations, enabling
robust long-horizon contextual reasoning.
On RxR-CE
Val-Unseen, which presents long-horizon trajectories and
detailed instructions, NavTTT reaches 63.6% SR, 52.7%
SPL, and 71.0% nDTW. Here, APM retrieves long-range
evidence that has exited the active visual window, while the
self-attention pathway preserves local grounding, ensuring
smooth continuity across extended navigation steps.
Figure 3 presents representative instruction-following
episodes on the real robot. Across 40 real-world naviga-
tion trials, NavTTT successfully completes 11, achieving
a success rate of 27.5%. During execution, the agent pro-
cesses successive egocentric observations and predicts short
action chunks for the robot to execute. Its fast-weight mem-
ory is updated online with newly observed evidence, mak-
ing accumulated context available to subsequent decisions.
This evaluation complements the simulation benchmarks
and provides a quantitative assessment of NavTTT on a
physical platform, while highlighting substantial room for
improving real-world navigation reliability.
The larger SPL gain over JanusVLN on RxR-CE (5.2
percentage points) than on R2R-CE (2.6 percentage points)
is consistent with the motivation to retain historical evi-
dence over longer trajectories. The accompanying improve-
ment in nDTW indicates better alignment with reference
routes, complementing the gains in task completion.
A
possible explanation is that persistent memory makes pre-
viously observed landmarks and their navigation context
available when recent frames alone provide insufficient in-
formation. Context-guided selection and redundancy sup-
pression determine which evidence enters this memory,
while hierarchical retrieval allows the retained information
to support subsequent decisions. NavTTT obtains these re-
sults using approximately 2.97 million additional image–
action training pairs. This reported data requirement should
be interpreted alongside differences in observation modali-
ties and training settings across methods. We provide addi-
tional qualitative results and failure cases in the supplemen-
tary material.

tial and navigation context encoding, and multi-depth re-
trieval as a combined design. At the same write budget,
combining relevance and within-frame diversity improves
SR and SPL over either criterion alone. At the same fast-
state storage, the six-layer shared configuration improves
SR and SPL over last-layer access. The supplementary ma-
terial provides details of both ablations, additional memory
analyses, and inference latency measurements.
5. Conclusion
This paper presented NavTTT, a framework that uses
fast-weight memory to retain historical information for
vision-and-language navigation.
The method combines
navigation-conditioned token selection, contextual associ-
ation encoding, and memory retrieval at multiple decoder
layers. Token selection balances task relevance and visual
diversity under a fixed write budget, while contextual en-
coding associates the selected visual features with spatial
information and navigation state. The decoder combines
self-attention over the available context with retrieval from
episode-local memory, allowing earlier observations to in-
form subsequent decisions after their source frames leave
the active visual window. During inference, the fast weights
are updated through a self-supervised objective, while the
backbone and other slow-weight parameters remain fixed.
Experiments on R2R-CE and RxR-CE show improvements
in navigation success and efficiency. We also evaluated the
method on a real robot to examine its behavior outside simu-
lation. These results suggest that selectively storing and re-
trieving historical evidence can complement the limited vi-
sual context available to the navigation model. Future work
will investigate memory retention over longer trajectories
and performance in environments with repeated landmarks
or greater visual ambiguity.

C. Visual Token Selection Analysis
We compare random, relevance-only, diversity-only, and

D. Memory Configuration Analysis
We examine memory depth and state sharing on R2R-CE
Val-Unseen using Qwen3-VL-8B. All variants follow the
main joint-training protocol with matched inputs, training
data, and optimization budget. The token selector, writing
feature source, number of memory heads, and per-head state
dimensions are fixed. Online updates are enabled for every
configuration.
Layer placement.
We divide the 36-layer decoder into
equally sized segments and attach a memory branch to the
final layer of each segment. Using zero-based indices, the
single-layer configuration uses layer 35, the three-layer con-
figuration uses layers {11, 23, 35}, and the six-layer config-
uration uses layers {5, 11, 17, 23, 29, 35}. These nested lay-
outs retain the deepest access point while extending mem-
ory access to earlier decoder stages.
State sharing.
Independent configurations maintain a
separate fast-weight state at each augmented layer.
The
shared configuration uses the same six access locations,
with corresponding memory heads sharing their states
across layers. With per-head dimensions fixed, indepen-
dent configurations allocate more total state as the number
of augmented layers increases.
Among independent configurations, increasing the num-
ber of memory depths improves both SR and SPL, accom-
panied by higher state storage and latency (Table S2). The
six-layer shared configuration uses the same state storage as
the last-layer configuration and improves both SR and SPL
by 0.6 percentage points. This storage-matched compar-
ison supports accessing historical information at multiple
decoder depths.
At the same six access locations, independent states im-
prove SR over shared memory by 1.4 points. Shared mem-
ory achieves 0.1 point higher SPL and reduces state stor-
age to the single-layer footprint. Its mean latency remains
close to that of the full model. Thus, the storage saving is
accompanied by a small latency reduction. The full config-
uration achieves the highest SR, and the shared configura-
tion achieves the highest reported SPL with lower persistent
storage.
E. Navigation Performance by Route Length
We partition Val-Unseen episodes into short, medium, and
long groups using tertiles of reference trajectory length. The
cutoffs are approximately 7.8 and 10.0 m on R2R-CE and
9.5 and 17.7 m on RxR-CE. The groups contain 1,839 R2R-
CE episodes and 3,669 RxR-CE episodes. All variants use
the same episode groups within each benchmark. The base-
line omits APM. Static APM uses the full-model checkpoint
with online fast-weight updates disabled.
Full NavTTT has its largest SR advantage over the base-
line without APM in the long-route group on both bench-
marks (Table S3). The static control further distinguishes
the effects of memory initialization and online updates. On
R2R-CE, static APM improves SR over the baseline on
short and medium routes and scores lower on long routes.
Enabling updates increases long-route SR by 9.97 percent-
age points and SPL by 4.95 points. The short- and medium-
group changes in success count cancel, so the long group
accounts for the net gain of 61 successes over static APM.
The SPL gain is driven by more successful episodes, with
lower mean normalized path efficiency among successful
full-model episodes.
On long RxR-CE routes, static APM improves SR over
the baseline by 5.16 points, and full NavTTT adds 2.46
points.
The SR gain over static APM is larger in the
medium group.
The comparison with direct LaCT also
varies by benchmark. Full NavTTT improves long-route
SR by 6.37 points on R2R-CE and 0.41 points on RxR-CE.
Direct LaCT achieves higher SPL on long RxR-CE routes.
The results show that the gains in task completion vary
with route length and are accompanied by different path-
efficiency tradeoffs.

G. More Qualitative Results
We present Habitat navigation trajectories to illustrate in-
struction following and representative failure modes.
Successful navigation.
Figures S2 and S3 present suc-
cessful episodes involving multi-step instructions, extended
traversal, and target landmarks.
During these episodes,
NavTTT updates its fast state with selected observations
and makes the accumulated history available to later de-
cisions. The examples provide qualitative illustrations of
instruction following across successive observations.
Failure cases.
Figure S4 presents three failure modes. Di-
rectional drift or reversal leads the agent away from the in-
structed route. Repetitive action loops yield little progress
toward the goal. Missed turn-offs occur when the agent
passes a required branching point without executing the in-
structed turn. These cases reveal challenges in translating
perceptual and historical context into reliable local deci-
sions. Directional grounding, progress-aware recovery, and
timely landmark-conditioned turning are directions for fur-
ther investigation.
