## 摘要
长视频问答需要从跨越数小时甚至数天的视频中检索并整合相关证据。近期的智能体方法将视频信息组织到外部记忆中，并迭代检索证据以回答问题。然而，有效的检索和推理仍然具有挑战性，因为智能体必须确定要搜索哪些信息、访问哪些记忆源，以及如何连接远距离时间间隔之间的证据。为了解决这些挑战，我们提出了视频记忆技能智能体（VMSA），这是一个联合设计结构化视频记忆和记忆技能以用于长视频理解的框架。VMSA 构建了三个互补的记忆组件。片段字幕记忆和实体事件记忆充当可搜索的证据来源，而实体感知的情节记忆提供广泛而详细的视频上下文，以指导证据检索和推理。为了进一步支持有效的记忆利用，VMSA 从成功的智能体轨迹中归纳记忆技能，逐步细化或扩展一个紧凑的技能库，以指导迭代的证据检索、推理和验证。在七个长视频问答基准上，VMSA 在全部三个长达一周的自我中心基准上取得了最高准确率，在 Ego-R1 Bench 上比最强基线高出多达 9.4%，并在另外四个基准上取得了最佳或具有竞争力的性能。消融研究进一步证明了三个记忆组件和记忆技能的贡献，其中记忆技能还改善了时间证据定位。

## Abstract
Long-video question answering requires retrieving and integrating relevant evidence from videos spanning hours or even days. Recent agentic approaches organize video information into external memories and iteratively retrieve evidence to answer questions. However, effective retrieval and reasoning remain challenging, as agents must determine what information to search for, which memory sources to access, and how to connect evidence across distant temporal intervals. To address these challenges, we propose Video Memory Skill Agent (VMSA), a framework that jointly designs structured video memories and memory skills for long-video understanding. VMSA constructs three complementary memory components. Segment Caption Memory and Entity Event Memory serve as searchable evidence sources, while Entity-Aware Episode Memory provides broad yet detailed video context to guide evidence retrieval and reasoning. To further support effective memory utilization, VMSA induces memory skills from successful agent trajectories, incrementally refining or extending a compact skill library to guide iterative evidence retrieval, reasoning, and verification. Across seven long-video question-answering benchmarks, VMSA achieves the highest accuracy on all three week-long egocentric benchmarks, outperforming the strongest baseline by up to 9.4% on Ego-R1 Bench, and the best or competitive performance on four additional benchmarks. Ablation studies further demonstrate the contributions of all three memory components and memory skills, with memory skills also improving temporal evidence localization.

## 2. 论文提出的方法论

VMSA（Video Memory Skill Agent）包含三大组成部分：

### 2.1 结构化视频记忆

VMSA 构建三个互补的记忆层级：

1. **Segment Caption Memory（片段字幕记忆）**
   - 将长视频切分为短片段，对每个片段采样帧并生成详细字幕。
   - 定义为：  
     \(M_{cap} = \{(C_i, \tau_i)\}_{i=1}^{N_s}\)
   - 保留局部视觉细节和对应时间范围。

2. **Entity Event Memory（实体事件记忆）**
   - 从每个片段中提取局部实体画像（属性、动作、关系、状态变化）。
   - 在滑动时间窗口内使用 mutual-kNN 图和 VLM 验证，逐步合并指向同一实体的画像。
   - 对每个实体 \(E_k\)，整合重复事件并扩展时间范围，生成实体事件集合：
     \[
     M_{evt} = \bigcup_{k=1}^{N_e} \{(E_k, e_{k,1}, e_{k,2}, \dots, e_{k,J_k})\}
     \]
   - 支持跨远距离时间区间检索同一实体的信息。

3. **Entity-Aware Episode Memory（实体感知情节记忆）**
   - 首先将时间相邻、描述同一活动的片段字幕合并为局部情节。
   - 再利用实体事件识别涉及同一实体的局部情节，并将语义相关的情节合并为实体感知情节。
   - 最终生成全局视频摘要 \(G\) 和实体感知情节集合：
     \[
     M_{epi} = \{G\} \cup \bigcup_{k=1}^{N_e} \{u_{k,j}\}_{j=1}^{L_k}
     \]
   - 该记忆直接放入智能体初始上下文，提供广泛且详细的视频级背景。

### 2.2 搜索与验证工具

智能体通过以下三个工具访问记忆和原始视频：

- **Caption Search**：基于嵌入检索与查询相关的片段字幕及其时间范围。
- **Entity Event Search**：根据目标实体和事件查询，返回相关实体事件、时间范围及实体画像。
- **Segment Inspection**：当结构化记忆证据不足时，直接检查原始视频帧，验证视觉细节。

### 2.3 记忆技能诱导

- 从成功的智能体轨迹中归纳可转移的程序性知识，形成紧凑的技能库。
- 每个技能包含：触发条件、检索与验证步骤、需要保留的证据清单、推理模板、停止规则、常见错误避免。
- 生成过程：
  1. 在源基准上运行智能体，保留预测正确的轨迹；
  2. 依次处理轨迹，判断现有技能是否覆盖该轨迹的程序性知识；
  3. 若未覆盖，则细化已有技能或新增技能；
  4. 每处理 100 条轨迹后进行一次技能库整合，合并冗余技能。
- 推理时，根据查询嵌入检索 top-\(K_s=3\) 个相关技能，并与问题和实体感知情节记忆一起放入智能体上下文。

### 2.4 技能引导的智能体搜索

智能体在每轮迭代中：
- 推理当前证据状态；
- 调用 Caption Search、Entity Event Search 或 Segment Inspection；
- 将工具观察结果纳入上下文；
- 判断是否已收集足够证据，若是则生成最终答案，否则继续搜索，直至达到最大轮数。

## 3. 实验设计

### 3.1 数据集与场景

共评估 **7 个长视频多选问答基准**：

- **三个周长度自我中心基准**：
  - EgoLifeQA（1 名参与者，500 题，平均 44.3 小时/人）
  - Ego-R1 Bench（6 名参与者，300 题，平均 44.3 小时/人）
  - EgoMemReason（6 名参与者，500 题，平均 44.3 小时/人，每题平均需要 5.1 个证据片段）

  - Video-MME long split（300 视频，900 题，平均 41.1 分钟）

- 记忆构建 VLM：Qwen3.5-9B。

- 推理智能体模型：默认 Qwen3.6-27B。
- 片段时长：自我中心基准 60 秒；其他基准 16 秒。
- 最大搜索轮数：10。
- 技能检索数量：top-3。
- 自我中心基准复用 WorldMM 发布的片段字幕。

## 6. 论文的主要结论与发现

- **整体性能**：
  - 在三个周长度自我中心基准（EgoLifeQA、Ego-R1 Bench、EgoMemReason）上均取得最高准确率；
  - 在 Ego-R1 Bench 上比最强基线 WorldMM 高出 9.4%；
  - 在 LongVideoBench 和 HippoVlog 上取得最高准确率；
  - 在 Video-MME 和 LVBench 上取得最佳或具有竞争力的结果。
- **记忆组件的作用**：
  - 三种记忆组件均对性能有贡献；
  - 移除 Segment Caption Memory 导致最严重的性能下降（5.5%–9.2%）；
  - Entity Event Memory 和 Entity-Aware Episode Memory 也分别提供显著收益。
- **记忆技能的作用**：
  - 记忆技能一致提升时间证据定位（tIoG）和答案准确率；
  - 相较于其他技能归纳方法，VMSA 用更紧凑的技能库（15 个技能）取得了更好的性能。
- **技能库紧凑性**：
  - VMSA 的技能库大小远小于 AWM、MemP、ReasoningBank（数百至数千条），但性能更好，表明增量归纳和定期整合能有效去除冗余、保留程序性知识。
- **智能体模型可扩展性**：
  - 替换为更强的 GPT-5 后性能进一步提升，说明 VMSA 框架能够受益于更强的推理模型。
- **搜索预算**：
  - 增加搜索轮次普遍提升准确率，但 LongVideoBench 对轮次最敏感。

---

## 7. 优点

- **新颖的联合设计**：将结构化记忆与可复用记忆技能结合，从“被动存储”提升为“主动指导检索与推理”。
- **三层次互补记忆**：片段字幕保留局部细节、实体事件整合跨时间实体信息、实体感知情节提供全局背景，三者分工明确。
- **技能归纳机制合理**：通过增量覆盖评估和定期整合，得到紧凑、可迁移的技能库，避免冗余。
- **实验广泛且深入**：覆盖 7 个主要基准 + 2 个补充基准，消融和分析维度丰富。
- **模型高效性**：默认使用 27B 开源模型即可超越部分使用 GPT-5 的强基线，具有实用价值。
- **时间定位评估**：引入 tIoG/tIoU 评估证据定位质量，而不仅是最终答案准确率，提供了更细致的诊断。
- **可扩展性验证**：证明更换更强智能体模型后性能继续提升，框架具有通用性。

---

## 8. 不足与局限

- **任务类型单一**：所有主实验结果均为多选问答（MCQ），未评估开放式生成、视频摘要、对话式问答等任务。
- **部分基线结果复用**：一些基线结果来自原始论文而非统一重新实现，可能因数据拆分、字幕使用等条件不同而影响公平性。
- **依赖外部字幕**：周长度自我中心基准复用了 WorldMM 的片段字幕，可能引入外部优势或限制记忆构建的独立性。
- **技能库迁移范围有限**：技能库从固定的一组源基准归纳，未系统分析源基准数量或领域差异对迁移效果的影响。
- **计算成本较高**：离线记忆构建需要较大量 VLM 调用；在线推理虽然可控，但长视频场景下记忆 tokens 较多。
- **自我中心数据规模有限**：三个周长度自我中心基准仅涉及 6 名参与者，可能限制对人群多样性的泛化。
- **未充分报告技能归纳成本**：技能归纳过程使用 GPT-5.6 等大模型，其算力和 token 消耗未量化。
- **实体合并审计基于模型判断**：实体合并错误率使用 Claude Sonnet 5 评估，可能存在模型自身偏差，缺乏人工标注验证。
