INTERNALIZED EXPERIENCE: HOW TRAINING DATA
SHAPES MEMORY FORMATION IN LLMS
Xianxuan Long, Xinnan Dai, Kai Guo, and Jiliang Tang
Michigan State University
ABSTRACT
Parametric memory enables large language models (LLMs) to retain information
from past experience and reuse it in subsequent tasks. Yet how training data sup-
ports the internalization of reusable task rules remains unclear. We introduce FS-
Mem (Finite-State Machine Memory), a state-transition framework for construct-
ing training data and studying how data content and organization shape memory
formation. We evaluate rule reuse across synthetic worlds, classical planning, and
code execution through valid-action identification and execution-outcome predic-
tion, complemented by next-operation prediction in code. Our experiments reveal
several systematic learning patterns. Under matched training conditions, even un-
changed task rules become harder to internalize when learned alongside a larger
variety of action types; by contrast, scaling the training data to provide broader
state–action coverage generally improves rule learning. We further find that train-
ing at a single execution depth produces depth-specialized behavior, with models
performing best when training and test executions have similar lengths. Motivated
by this finding, we construct cumulative corpora that combine short and long tra-
jectories, which can outperform long-trajectory-only training while using fewer
training tokens. Together, these results demonstrate that the same task rules can
be internalized differently depending on how execution experience is constructed,
and that understanding these learning patterns can guide the design of more effec-
tive training data for parametric memory.

INTRODUCTION
Large language models (LLMs) are expected to build on past experience when facing new tasks
and contexts. Memory supports this reuse by preserving information beyond the context in which
it was acquired (Wang et al., 2023). Existing approaches realize this capacity mainly through text-
based memory, which stores information externally for later retrieval (Lewis et al., 2020; Zhong
et al., 2024; Lu et al., 2023), or parametric memory, which incorporates information into model
parameters through updates (Roberts et al., 2020; Meng et al., 2022a;b; Back et al., 2026). In
this work, we focus on parametric memory given its potential to turn past experience into lasting
improvements in model capabilities.
Existing research on LLMs’ parametric memory focuses on mechanisms for encoding useful infor-
mation into model parameters (De Cao et al., 2021; Mitchell et al., 2021; Charakorn et al., 2026)
or dedicated parametric modules for later use (Lample et al., 2019; Wang et al., 2024b; Behrouz
et al., 2026b; Wei et al., 2026). These studies have advanced our understanding of memory capac-
ity (Allen-Zhu & Li, 2024; Xu et al., 2026), the internalization of factual information (Petroni et al.,
2019; Allen-Zhu & Li, 2023; Chang et al., 2024), and reasoning over learned information (Allen-
Zhu & Li, 2025; Wang et al., 2024a; Back et al., 2026). What models internalize also depends on the
training data itself (Tirumala et al., 2022; Ye et al., 2026). For example, planning trajectories (Kokel
et al., 2025) and program execution traces (Nye et al., 2021) have been used to study how LLMs
reason about task execution. These records contain information about particular entities and their
states, as illustrated in Figure 1(a). However, existing work has overlooked the fact that execution
trajectories involving different entities could follow the same task rules: when an action is valid and
how it changes the state, and apply across different entities and states. They are reusable across
instances of a given task (Fikes & Nilsson, 1971; Ghallab et al., 1998; Yang et al., 2007). How the

Studying the internalization of task rules requires distinguishing which rules training data contains
from how their executions are recorded. In this work, we introduce FSMem (Finite-State Machine
Memory), a framework that makes this distinction explicitly by representing task execution as a
finite-state machine (Section 2). For the Blocksworld example in Figure 1(b), states describe the
configuration of blocks and the gripper’s status, while concrete actions manipulate particular blocks.
The transition function specifies whether an action is valid and, if so, the resulting state; trajectories
record sequences of concrete actions and states. This representation allows us to vary the action
types selected for supervision and, with the rules fixed, the state–action coverage and depth of exe-
cution records.
Consistent with our understanding of parametric memory, past experience should induce lasting
changes in model parameters that influence subsequent behavior (De Cao et al., 2021; Charakorn
et al., 2026). Compared with existing work centered on task-level results (Charakorn et al., 2026;
Back et al., 2026), FSMem characterizes this influence through two complementary behaviors: iden-
tifying valid actions and predicting execution outcomes, as illustrated in Figure 1(c). These be-
haviors reflect the two aspects of task rules encoded by the transition function: when an action can
be executed and how execution changes the state. They therefore connect the experience represented
in training data to the subsequent behavior that rule internalization should support.
We instantiate FSMem in synthetic worlds, classical planning, and code execution (Section 3), and
study how training-data content and organization shape parametric memory. Our study of action
complexity shows that, under matched training conditions, task rules can become harder to internal-
ize when learned alongside more action types (Section 4). Expanding trajectory breadth generally
supports more effective rule reuse without increasing the number of training steps (Section 5). Our
study of depth reveals depth-specialized behavior under single-depth training: models tend to per-
form better at execution depths represented in training. Based on this observation, training on a
cumulative corpus of short and long trajectories can outperform long-only one with fewer tokens
(Section 6).

METHOD
Our goal is to understand how training-data content and organization affect memory formation in
LLMs. To this end, we introduce FSMem, a state-transition framework for constructing training
data. We first formalize task rules and execution trajectories and define action complexity, trajec-
tory breadth, and depth (Section 2.1). Building on this formulation, we describe how to construct
supervised training examples from execution records (Section 2.2).

2.1
A FINITE-STATE MACHINE FRAMEWORK
To study how training data supports the learning of reusable execution rules, we need to specify
both the rules underlying the data and the particular executions recorded. We use a finite-state
machine to make this execution process explicit: its transition function specifies action validity
and state changes, while its trajectories provide records for constructing training examples. This
representation allows us to vary the action types selected for supervision or, with the rules fixed,
change the state–action coverage and depth of execution records.

Actions and Transitions
The action set A specifies which operation types are represented in the
training data. Instantiating these types with entity arguments yields concrete actions, whose validity
and execution outcomes are determined by F. This separation of action validity and state changes
follows classical planning representations (Fikes & Nilsson, 1971; Ghallab et al., 1998).
Definition 1 (Action Complexity). Let A = {a1, a2, . . . , aA} be the set of distinct action identifiers
represented in the corpus. The action complexity is A = |A|.
In our framework, each action type provides a template for concrete actions that serve as inputs to the
finite-state machine. Instantiating the same type with different entity arguments does not increase
action complexity.

EXPERIMENTAL SETUP
This section describes the task instantiations, training and evaluation procedures, and experimental
design used to study memory formation with FSMem.
Task instantiations.
We instantiate Algorithm 1 in three task families, constructing execution
records and deriving training targets from their task rules. (1) Synthetic worlds. We execute valid
actions from sampled entity configurations; execution conditions and resulting states provide targets
for valid-action identification and state prediction. (2) Classical planning. We construct records
4


from problem instances in 13 ACPBench domains (Kokel et al., 2025). Domain rules determine
valid-action targets for query states, specified directly or through an initial state and an action se-
quence. (3) Code execution. Running CodeI/O programs (Li et al., 2025) on concrete inputs yields
operation sequences and outputs. Recorded operations supervise next-operation prediction; outputs
supervise output prediction from the program and input (Native), optionally augmented with execu-
tion order without intermediate values (Explicit trace). Further details are provided in Appendix B.
Training and evaluation.
We fine-tune Qwen2.5-0.5B-Instruct (Qwen et al., 2025) with
LoRA (Hu et al., 2021), keeping the procedure fixed within each comparison. We assess memory
formation through two complementary behaviors: identifying valid actions and predicting execution
outcomes on held-out sources without access to training records. In synthetic worlds, we evaluate
valid-action selection by order-robust accuracy and state prediction by exact match. In classical
planning, we use candidate selection (order-robust accuracy) or complete valid-action-set predic-
tion (exact-set accuracy and action-set F1). In code execution, we evaluate program-output pre-
diction by numeric-equivalence accuracy and, as a complementary test of rule reuse, next-operation
selection by order-robust accuracy, using repository-disjoint training and test splits. Order-robust
accuracy requires correct answers under every tested candidate ordering. Appendix C reports addi-
tional valid-action identification experiments with Qwen2.5-3B-Instruct, Qwen2.5-7B-Instruct, and
Qwen3-8B (Yang et al., 2025) in synthetic worlds and classical planning.
Experimental Design
Our experiments aim to investigate three research questions about how
training-data content and organization shape memory formation. First, how does action complexity
affect the effectiveness of task-rule internalization? Controlled comparisons introduce additional
action types while keeping existing actions’ execution conditions and effects unchanged (Section 4).
With these rules fixed, the remaining studies focus on trajectory organization. Second, does broader
state–action coverage support memory formation more effectively than repeatedly learning
from fewer sources? Breadth experiments vary the number of distinct source examples while hold-
ing trajectory depth and the number of training steps fixed (Section 5). Third, how does training
trajectory depth affect generalization across execution depths, and can short and long tra-
jectories complement each other? Depth experiments compare training at individual depths with
training on cumulative corpora containing both shorter and longer trajectories (Section 6).
4
ACTION COMPLEXITY AFFECTS MEMORY FORMATION EFFECTIVENESS
We examine how action complexity affects the effectiveness of memory formation. Increasing the
number of action types represented in training data expands the range of task rules the model must
learn. We assess how effectively models internalize and reuse these rules through two complemen-
tary behaviors: identifying valid actions in synthetic worlds and classical planning (Section 4.1),
and predicting execution outcomes in synthetic worlds, with an additional test of next-operation
prediction in code (Section 4.2).
4.1
IDENTIFYING VALID ACTIONS
We begin with synthetic worlds instantiated from our state-transition formulation, which allows us to
vary action complexity in a controlled setting. In synthetic worlds, we expand nested sets of action
types from A=5 to A=20, holding the other world properties fixed within each comparison. Mean
order-robust accuracy decreases from 88.1% to 65.1% (Figure 2 a) with the same number of training
steps and examples processed. These results indicate that increasing action complexity reduces the
effectiveness of rule internalization under the same training conditions. We next examine whether
this finding could be extended to classical planning tasks.
In 13 planning domains, exact-set accuracy is negatively associated with the number of action types
appearing in the ground-truth valid-action sets of the training data (Spearman ρ = −0.819; Figure 2
b). We then progressively expand the set of action types within seven planning domains to examine
whether the same decline appears (Figure 2 c). Including more action types generally makes valid-
action identification harder to learn within each domain.

5.3
BREADTH SCALING ENHANCES EXECUTION-OUTCOME PREDICTION
For execution-outcome prediction, synthetic models predict complete next states under the same
A=20 rule set, and code models predict outputs on the same 500 repository-disjoint test programs,
trained on nested program sets with a fixed mixture of short, medium, and long trajectories (S+M+L;
depth ranges defined in Section 6.3). Synthetic training uses 667,200 prompt tokens and 48,000
supervised tokens per condition; code token counts are not exactly matched. Synthetic next-state
exact-match accuracy rises from 20.83 ± 1.89% at N=50 to 46.33 ± 3.55% at N=1,600 (+25.5
points), and program-output accuracy rises from 19.2% to 28.6% in the Native view (+9.4 points)
and from 18.0% to 37.0% in the Explicit-trace view (+19.0 points) (Figure 5).
Takeaway 5.1 Expanding trajectory breadth generally improves memory formation, providing a
way to mitigate the difficulty of rule internalization under higher action complexity.

BENEFITS OF ACCUMULATING TRAJECTORIES ACROSS DEPTHS
Entity attributes and relations change along a trajectory, but the transition function governing an
action does not change with depth, so a model that has learned the rules should reuse them at
different trajectory depths. We first test this expectation and find that single-depth training produces
depth-specialized behavior (Section 6.1). This motivates accumulating trajectories across depths
while retaining shorter ones; we compare the resulting cumulative corpora with long-only training
on valid-action identification (Section 6.2) and execution-outcome prediction (Section 6.3).
7


6.1
SINGLE-DEPTH TRAINING PRODUCES SPECIALIZED BEHAVIOR
Motivated by known limits of length generalization (Anil et al., 2022), we train separate models at
individual depths and evaluate each across depths in the synthetic, planning, and code task families.
Table 1 reports, for selected settings, the matching gain (the difference in mean accuracy between
matched and mismatched training–test depths) and ρ (Spearman’s correlation between the binary
depth-matching indicator and accuracy); matched-depth training achieves higher accuracy on aver-
age in each. Figure 6 shows the synthetic A=5 setting, where the matching gain is 12.2 percentage
points and is most pronounced at shallow evaluation depths. Longer training executions thus do not
automatically support stronger performance at shorter depths.
6.2
VALID-ACTION IDENTIFICATION ACROSS DEPTHS
We test whether retaining shorter trajectories improves valid-action identification as longer trajec-
tories are added. The synthetic corpora cover depths 1, 1+4, 1+4+8, or 1+4+8+16, where “+”
denotes depths included together in one corpus, and 16-only training uses the same maximum depth
without shorter trajectories. The synthetic and code conditions in Sections 6.2 and 6.3 each use
600 optimizer updates and 9,600 training examples. Order-robust accuracy averaged over evalu-
ation depths rises from 62.1% to 85.7% as depths are added, against 71.2% for 16-only training
(Figure 7): a 14.5-point advantage with 29.1% fewer non-padding tokens.

6.3
EXECUTION-OUTCOME PREDICTION ACROSS DEPTHS
In synthetic worlds with varying action complexity A, models receive a held-out initial state and an
executed action prefix and predict the complete terminal state. As the corpus expands from depth
1 to 1+4+8+16, terminal-state exact-match accuracy averaged over evaluation depths rises from
32.3% to 99.0%, with corresponding non-padding training tokens reported in Table 3.
To determine whether this gain comes only from the depth-16 trajectories, we compare the full
cumulative corpus with 16-only training at each evaluation depth (Figure 8). The cumulative corpus

RELATED WORK
Parametric memory in LLMs.
Analyses of pretrained Transformers characterize feed-forward
layers as key-value memories (Geva et al., 2021) and identify neurons associated with particular
facts (Dai et al., 2022). Existing approaches update stored information through targeted parame-
ter changes (Meng et al., 2022a; Fang et al., 2025; Wang et al., 2024b), additional trainable pa-
rameters (Dong et al., 2022; Huang et al., 2023), or dedicated memory modules (Lample et al.,
2019; Behrouz et al., 2026b; Wei et al., 2026). Engram adds conditional memory through sparse
lookup (Cheng et al., 2026), while consolidation methods transfer short-term memories into long-
term parameters through distillation and replay (Behrouz et al., 2026a). Recent LoRA-based studies
examine capacity, retention, and reasoning over internalized information (Back et al., 2026; Xu
et al., 2026).
Training data and memory formation.
Varied presentations of facts (Allen-Zhu & Li, 2023),
supervision formats (Back et al., 2026), and the number and frequency of facts (Ye et al., 2026) in-
fluence acquisition and memorization. For document-specific LoRA memory, training on question-
answer pairs outperforms next-token prediction on raw documents when answering questions about
the encoded content (Liu et al., 2026). Data repetition also affects verbatim memorization (Carlini
et al., 2022; Lee et al., 2022). However, recalling stored information does not ensure its flexible
use in downstream reasoning (Allen-Zhu & Li, 2025). Our study concerns execution records of
rules shared across entities and states. With fine-tuning fixed, we vary action complexity, trajec-
tory breadth, and depth to study how data construction supports rule internalization, as reflected in
identifying valid actions and predicting execution outcomes.
Generalization and transfer.
Compositional generalization tests whether models can recombine
familiar components in new ways (Lake & Baroni, 2018; Keysers et al., 2019). Length generaliza-
tion asks whether learned behavior extends to inputs longer than those seen during training (Anil
et al., 2022; Zhou et al., 2024). Transfer learning studies how knowledge acquired in a source task
or domain helps in a target setting (Pan & Yang, 2009; Raffel et al., 2020). FSMem studies how the
content and organization of execution records shape within-task generalization. We evaluate valid-
action identification and execution-outcome prediction on held-out instances governed by the same
task rules, with training records absent from the evaluation context. Performance on these instances
provides behavioral evidence of rule reuse.
8
CONCLUSION
We introduced FSMem, a state-transition framework for studying how training-data content and or-
ganization shape parametric memory in LLMs. Our findings show that increasing action complexity
9


can make even shared task rules harder to internalize, while broader state–action coverage supports
more effective rule reuse. Single-depth training produces depth-specialized behavior, motivating
cumulative corpora of short and long trajectories that can outperform long-only training with fewer
tokens. Together, these findings show how training-data construction shapes the internalization of
experience into reusable task rules, providing guidance for more effective memory formation under
a fixed fine-tuning procedure.

DATA CONSTRUCTION DETAILS
Synthetic worlds. Valid-action queries provide an initial state, an execution record, and candidate
actions; labels are obtained by checking execution conditions in the resulting state. The action-
complexity study of next-state prediction instead supplies a complete current state and one valid
concrete action. Actions use fixed identifiers without descriptions of their effects, and the target
contains the resulting state of every entity, including entities unchanged by the action. The depth
study supplies an initial state and a valid action sequence and uses the complete terminal state as the
target.
Classical planning. Problem instances specify objects and initial states. Domain rules gener-
ate valid execution records and determine which concrete actions are valid at each reached state.
Current-state queries render the queried state directly; trajectory queries provide the initial state
and executed actions. Targets either select a valid candidate or list the complete valid-action set.
Records derived from the same source problem remain in the same data split. In the breadth experi-
ments, Logistics and FloorTile use regenerated controlled instances; the other planning domains use
native-domain instance construction.
Code execution. Training and test programs are separated by repository. Next-operation queries
include the program description, input/output requirements, program, concrete input, and an execu-
tion prefix with intermediate values removed. The target operation is obtained from the recorded
execution, and each query is presented under both candidate orders. Program-output queries use
the same task information and concrete input; Explicit-trace inputs also include executed line and
statement order, without intermediate values or the terminal output. Both Native and Explicit-trace
inputs share the output produced by execution as their target.
Distinct sources are sampled trajectories, planning problems, and programs for synthetic worlds,
classical planning, and code execution, respectively. Breadth comparisons collect records from
nested source pools with the action types and trajectory depths fixed. Cumulative depth comparisons
retain records at shorter depths when records at longer depths are included.
Result aggregation. Synthetic and planning breadth results average three training seeds; code
breadth results use seed 13. Synthetic cumulative-depth outcome results also use seed 13, while
14


the cumulative-depth code results average seeds 13, 37, and 73. Error bars report sample standard
deviations where shown.
