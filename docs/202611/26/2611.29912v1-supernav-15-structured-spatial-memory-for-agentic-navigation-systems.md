## 摘要
本文针对跨会话与连续物体目标高效导航中的场景级记忆设计挑战。近期方法通常使用场景图或图像-文本记录来表示场景。然而，密集的场景图表示给多模态大语言模型带来显著的推理和上下文开销，而图像-文本记录无法直接转换为可执行的几何路径。为解决这些局限，我们提出 SuperNav-1.5，一个配备由智能体构建的结构化空间记忆的智能体导航系统。该记忆由一个区域分割的占据地图组成，地图上标注有智能体维护、锚定于地图的记忆节点。该地图引导智能体前往未访问区域，并提供到达已知位置的可执行路径。对于多会话导航，我们引入智能体引导的重定位，智能体从当前观测和存储的记忆记录中推断区域先验，以约束几何匹配并在已存储地图中定位机器人。这些设计共同实现了跨会话和连续物体目标的高效导航。实验表明，我们的方法在单物体、多物体和需求驱动导航基准上优于基线方法，尤其在路径效率上提升显著。多会话评估表明所构建的记忆可以复用，而在真实四足机器人上的部署进一步展示了系统的实用性。

## Abstract
This paper addresses the challenge of scene-level memory design for efficient navigation across sessions and successive object goals. Recent methods commonly represent a scene using scene graphs or image--text records. However, dense scene-graph representations impose substantial reasoning and context overhead on multimodal large language models, while image--text records cannot be directly converted into executable geometric routes. To address these limitations, we propose SuperNav-1.5, an agentic navigation system equipped with a structured spatial memory constructed by the agent. The memory consists of an area-segmented occupancy map annotated with agent-maintained, map-grounded memory nodes. This map guides the agent toward unvisited areas and provides executable routes to known locations. For multi-session navigation, we introduce agent-guided relocalization, whereby the agent infers an area prior from current observations and stored memory records to constrain geometric matching and localize the robot within the stored map. Together, these designs enable efficient navigation across session and successive object goals. Experiments show that our method outperforms baselines on single-object, multi-object, and demand-driven navigation benchmarks, with particularly strong gains in path efficiency. Multi-session evaluation demonstrates that the constructed memory can be reused, while deployment on a real quadruped robot further shows the system's applicability.

## 1. 核心问题与研究动机

本文解决的核心问题是：**在跨会话、连续多物体目标的导航任务中，如何设计高效且可复用的场景级空间记忆**。

现有方法主要存在两类局限：

- **场景图（Scene Graph）表示**：虽然提供了显式的物体/房间关系结构，但随着探索推进，节点和边不断增加，导致多模态大语言模型（MLLM）的上下文和推理开销大幅上升。
- **图像–文本记录（Image–Text Records）**：能够保留视觉证据和文本摘要，但检索到的图像或文本本身**不能直接转化为可执行的几何路径**，缺乏与导航动作之间的桥梁。

核心矛盾在于：**语义记忆的可检索性与几何导航的可执行性之间缺乏有效耦合**。本文的深层动机是构建一种既能被智能体方便查询、又锚定于可导航几何坐标的空间记忆，从而同时支持单次长程导航、连续多目标导航以及跨会话记忆重用。


## 2. 方法论

### 2.1 总体框架

SuperNav-1.5 在 SuperNav 的智能体导航框架基础上，引入了**持久化结构化空间记忆**，由三个相互配合的部分构成：**记忆表示**（Sec 3.1）、**记忆构建**（Sec 3.2）和**导航使用**（Sec 3.3）。

### 2.2 结构化空间记忆表示

记忆的核心形式为：

- **区域分割的二维占据地图（Area-segmented Occupancy Map）**：作为空间主干（spatial backbone），由 Cartographer 实时 SLAM 构建，并通过分水岭分割（Watershed Segmentation）划分为带颜色编码的区域。
- **智能体维护的记忆节点（Memory Nodes）**：由智能体通过工具调用**自主决定**在哪些地图位置保留语义信息。每个节点包含：
  - `name`：节点名称，支持直接查找；
  - `description`：场景描述；
  - `records`：事实记录列表；
  - `slam_position`：锚定到 SLAM 坐标系的位姿 `(x, y, θ)`。
- **未访问区域描述（Unvisited Area Descriptions）**：自动生成的区域级文本描述，捕捉运动过程中被路过但未深入探索的区域信息。

这一设计的关键思想是：**几何关系由地图显式编码，智能体无需自行维护拓扑关系；语义决策则由智能体负责，只保留重要信息**，从而实现"地图管几何，智能体管语义"的分工。

### 2.3 记忆构建

#### 异步几何建图
- Cartographer 异步整合深度/LiDAR 观测与里程计，构建占据地图。
- 分水岭分割算法将地图划分为可解释的区域，并为智能体可视化界面分配不同颜色。

#### 智能体维护记忆节点
- 智能体通过 `create` / `update` 工具调用决定何时创建或修改节点。
- 节点自动绑定到机器人当前 SLAM 位姿，**无需智能体显式计算几何坐标**。

#### 未访问区域描述
- 运动过程中每两步保存关键帧（前、右、后、左四视图）。
- 使用 Qwen3.5-2B VLM 异步生成简短描述，**禁止猜测房间类别或不可见物体**。
- 对于每个未访问区域，通过**几何可见性选择**最佳代表关键帧：
  \[
  k^\star(a) = \arg\max_{k \in K(a)} v(k, a)
  \]
  其中 \(v(k, a)\) 统计从关键帧 \(k\) 射出并进入区域 \(a\) 的射线数量。

### 2.4 导航与记忆使用

#### 智能体引导的重定位（Agent-guided Relocalization）
跨会话重用时，机器人需要先确定自己在已存储地图中的位置。流程为：
1. 智能体将当前观测与存储的记忆描述/记录进行语义比对，**推断所处的区域先验**；
2. 将该区域从先验占据地图中裁剪出来，作为局部匹配的约束范围；
3. 在当前局部地图与裁剪地图之间进行几何匹配，估计平面刚体变换 \(^bT_{prior \leftarrow new}\)；
4. 通过多重接受门控（占用/空闲一致性、轨迹覆盖、ICP 细化质量、先验一致性、歧义边际等）确保匹配可靠性。

相比纯几何匹配，语义先验有效降低了相似布局区域之间的匹配歧义。

#### 记忆查找（Memory Lookup）
- **按名称查找**：直接返回节点内容；
- **关键词搜索（grep）**：对节点名称、描述和事实记录进行大小写不敏感的文本匹配。
- 查找结果仅返回匹配项，**避免将所有记忆加载到上下文中**。

#### 几何导航（Geometric Navigation）
- 智能体选定目标节点/区域标记后，几何导航工具负责：
  1. 解析标记到地图平面坐标；
  2. 使用 A* 在占据地图上规划路径；
  3. 路径简化（视线简化）；
  4. 量化动作编译（10° 转向 + 0.25 m 前进），并执行**执行前模拟验证**（simulate-before-commit），确保动作安全；
  5. 碰撞或位姿不一致时进行全局重规划（最多两次尝试）。

这一接口分离了**语义决策（智能体负责）**与**路线执行（几何工具负责）**，免除了智能体逐步骤生成语义指令的负担。

## 6. 主要结论与发现

1. **结构化空间记忆显著提升路径效率**：在多物体导航（Habitat-GS）中，SR 从 SuperNav 的 34.00% 提升至 52.00%，SPL 从 0.1388 提升至 0.2494（提升 80%）。路径效率提升在第三到第五个目标上更为显著（第五目标 SR：60.53% vs. 39.47%）。

2. **单物体导航也有提升但在 SPL 上尤为明显**：HM3D-OVON 上 SR 从 73.33% 升至 80.00%，SPL 从 0.4105 升至 0.4317。Habitat-GS 单物体 SPL 从 0.4127 升至 0.4246（SR 从 78.00% 升至 79.33%）。

3. **需求驱动导航的效率收益远大于成功率收益**：SR 仅从 59.50% 升至 61.00%，但 SPL 从 0.1801 大幅提升至 0.3867（提升 115%），说明记忆主要帮助智能体省去了重复搜索。

4. **跨会话记忆可复用且提高效率**：改变出生点后，Session 2 使用记忆的 SPL 从 0.4364 升至 0.5022，SR 从 78.00% 升至 82.00%。不变出生点条件下同样有提升。

5. **几何与语义记忆缺一不可**：消融实验显示，移除占据地图导致 SPL 骤降（0.5329 → 0.3563），移除记忆节点导致 SR 和 SPL 显著下降，证明两者互补而非替代。

6. **智能体引导重定位降低匹配歧义**：纯几何匹配在相似墙体结构或几何信息不足时容易选择错误对齐，智能体区域先验有效解决了这一问题。

7. **系统不依赖特定推理模型**：KIMI-k3-256k 和 GLM-5.3-flash 均可取得与 GPT-5.6-terra 相近或更高的 SR（KIMI 达到 85.00% SR）。

8. **真实世界可行性**：在 Unitree Go2 四足机器人上完成了多目标、记忆返回和需求驱动导航的演示。


## 7. 优点

- **架构清晰地解耦了语义与几何**：智能体处理语义决策，地图编码空间结构，避免了场景图维护关系边的复杂性和图像文本记录的可执行性问题。这一分工在概念上简单而有效。
- **记忆是"选择性"的**：智能体自主决定何时创建/更新节点，而非被动记录所有观测，符合智能体系统中"主动记忆管理"的趋势。
- **未访问区域描述机制是一种巧妙的"意外观测"保留方案**：利用几何可见性选择最佳视角描述避免了智能体因只接收最终观测而遗漏途中重要信息的问题。
- **重定位的多重接受门控设计严谨**：占用/空闲一致性、轨迹覆盖、歧义边际等门控条件能够有效防止几何匹配的误接受，体现出工程实现上的精细程度。
- **对比公平性控制良好**：模型兼容性消融、记忆设计移植对比、执行器匹配均体现了对公平性较强的关注。
- **跨会话验证设计了改变出生点的场景**，这是对记忆泛化能力一个真实且具挑战性的测试，避免"回放记忆"式的简单成功。


## 8. 不足与局限

- **缺少算力与推理成本分析**：论文未报告 GPU 资源、推理耗时、API 调用次数或每 episode 的总成本。对于与多个大模型 API 深度耦合的系统，这是重要的成本信息。
- **实验主要为模拟器评估**：虽然提供了真实机器人演示，但仅包含 3 个定性场景，缺少定量统计和与对比方法在真实环境中的对比。
- **消融实验样本偏小**（40 个任务）且每 episode 仅运行一次，缺少重复实验的统计方差；单次运行带来的随机性可能影响可复现性。
- **对 VLM 描述生成的能力依赖性未充分探讨**：Qwen3.5-2B 的关键帧描述和区域描述质量直接影响后续信息的可靠性，但论文未讨论错误描述或幻觉描述对导航决策的影响。
- **地图构建依赖于准确的深度/LiDAR 和里程计**：论文承认传感器误差或里程计漂移可能破坏几何重建。在长时跨会话场景中，累计漂移可能成为比论文所讨论的更严重的问题。
- **未系统讨论安全与伦理考虑**：鉴于系统可在真实室内环境中自主导航，缺少关于隐私保护（如摄像头记录个人空间）和故障安全机制的讨论。
- **依赖多个闭源模型 API**：GPT-5.6-terra、GPT-6.1-sol、KIMI-k3-256k、GLM-5.3-flash 均为外部服务，其长期可用性和可复现性存在风险。
- **未与最新的端到端学习方法进行充分对比**：尽管与多类基线进行了对比，但缺少与近期的学习型交互式方法（如更大规模视觉-语言-动作模型）的直接对比。
