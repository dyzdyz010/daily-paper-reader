## Abstract
This paper addresses the challenge of scene-level memory design for efficient navigation across sessions and successive object goals. Recent methods commonly represent a scene using scene graphs or image--text records. However, dense scene-graph representations impose substantial reasoning and context overhead on multimodal large language models, while image--text records cannot be directly converted into executable geometric routes. To address these limitations, we propose SuperNav-1.5, an agentic navigation system equipped with a structured spatial memory constructed by the agent. The memory consists of an area-segmented occupancy map annotated with agent-maintained, map-grounded memory nodes. This map guides the agent toward unvisited areas and provides executable routes to known locations. For multi-session navigation, we introduce agent-guided relocalization, whereby the agent infers an area prior from current observations and stored memory records to constrain geometric matching and localize the robot within the stored map. Together, these designs enable efficient navigation across session and successive object goals. Experiments show that our method outperforms baselines on single-object, multi-object, and demand-driven navigation benchmarks, with particularly strong gains in path efficiency. Multi-session evaluation demonstrates that the constructed memory can be reused, while deployment on a real quadruped robot further shows the system's applicability. ## 2. 论文提出的方法论

### 2.1 结构化空间记忆

- 记忆由两部分组成：
  - **区域分割的二维占据地图**：由 `Cartographer` 异步构建，并通过分水岭分割成不同颜色区域，机器人位姿、已访问区域、未访问区域均显示在地图上。
  - **智能体维护的记忆节点**：每个节点包含名称、场景描述、事实记录和 `SLAM` 位姿（x, y, yaw）。节点通过同名字典与地图标记关联。
- 地图作为统一接口，使智能体能够：
  - 区分“已记忆位置”与“待探索区域”；
  - 在共享空间参考下选择目的地；
  - 避免在上下文中维护大量关系边，降低推理负担。

### 2.2 记忆构建

- **异步几何建图**：
  - 采用 `Cartographer` 深度/激光雷达 + 里程计实时构建占据地图；
  - 使用分水岭分割将地图划分为区域，赋予不同颜色；
  - 两套地图：结构地图（用于区域分割、重定位）和规划地图（用于路径规划与障碍物覆盖）。
- **智能体维护记忆节点**：
  - 智能体通过工具调用自主决定何时创建或更新节点；
  - 创建/更新后，节点自动绑定到当前 `SLAM` 位姿；
  - 支持批量原子变更，节省智能体操作步数。
- **未访问区域描述**：
  - 移动过程中保存关键帧图像及其位姿；
  - 异步使用 `Qwen3.5-2B` 对关键帧进行文字 caption；
  - 对每个未访问区域，根据几何可见性选择代表性 caption：
    - 设 `K(a)` 为附近关键帧集合，`v(k,a)` 为从关键帧 k 进入区域 a 的射线数；
    - 选择 \( k^\star(a) = \arg\max_{k \in K(a)} v(k,a) \)，将其 caption 关联到区域的地图标记。

### 2.3 使用记忆进行导航

- **智能体引导重定位**：
  - 跨会话复用时，新会话几何观测有限，全局匹配可能因相似布局而模糊；
  - 智能体根据当前观测与记忆描述/记录推断可能所在区域，形成语义先验；
  - 将先验地图裁剪至该区域，当前局部地图与裁剪地图匹配，估计平面刚体变换 \( {}^{b}T_{\text{prior}\leftarrow\text{new}} \)；
  - 通过多个验证门控（最小证据、占据/自由一致性、轨迹覆盖、细化质量、先验一致性、歧义裕度）接受或拒绝变换；
  - 接受后执行 `Cartographer` 轨迹交接，将当前帧映射到存储地图坐标系。
- **记忆查找**：
  - 支持按节点名称直接查找；
  - 支持关键词 `grep` 式文本检索（如对 `stool`、`office` 进行匹配），返回相关节点描述与事实记录；
  - 避免将完整记忆加载进上下文，只返回相关摘要。
- **几何导航**：
  - 智能体选择记忆节点或未访问区域标记；
  - 工具解析标记到平面地图位置，用 `A*` 在占据地图上规划路径；
  - 路径经过直线简化、离散动作编译、碰撞校验后转换为底层导航动作执行；
  - 执行过程中若出现碰撞、阻塞或位姿不一致，可触发重规划。

## 6. 论文的主要结论与发现

- **面向连续目标与跨会话导航，几何接地、智能体选择性维护的空间记忆优于纯场景图或图像文本记录**。
- 在 HM3D-OVON 上，`SuperNav-1.5` 在 1 m 阈值下达到 80.00% SR，优于同类方法。
- 在 Habitat-GS 多目标任务上，SR 由 `SuperNav` 的 34.00% 提升到 52.00%，SPL 由 0.1388 提升到 0.2494；逐目标分析显示优势在长目标序列上积累更明显。
- 在多会话设置中，改变出生位置时，带记忆会话 2 的 SPL 从无记忆的 0.4364 提高到 0.5022；不变出生位置时也从 0.4246 提高到 0.5195，证明先前场景知识被有效复用。
- 消融显示：
  - 移除记忆节点导致 SR/SPL 下降；
  - 移除占据地图与几何导航导致性能大幅下降，说明几何骨干不可或缺；
  - 移除重定位或智能体引导均降低多会话性能，说明语义先验约束几何匹配有效；
  - 方法对不同推理模型（GPT、KIMI、GLM）均表现稳定。
- 在 EQA 上达到 87.33% 准确率，进一步验证记忆有助于收集和保留任务相关的视觉证据。

## 7. 优点

- **设计新颖**：将占据地图作为空间骨干，智能体决定保留哪些语义记忆节点，天然分离“几何结构”与“语义内容”，避免过重场景图，同时提供可执行路径。
- **接口统一**：地图上同时显示已访问/未访问区域、记忆节点与机器人位姿，智能体只需选择标记即可发起几何导航，降低了推理负担。
- **未访问区域描述机制**：利用异步 caption 和射线可见性选择代表描述，将运动过程中的偶然观测保留下来，作为后续探索线索。
- **智能体引导重定位**：结合语义先验与几何匹配，有效缓解相似结构场景下的全局匹配歧义，支持跨会话复用。
- **实验全面**：覆盖多个基准、消融、模型兼容性、与现有记忆设计对比以及真实机器人部署；对路径效率的定量分析（SPL）具有说服力。
- **可扩展性**：系统模块化，可替换不同推理模型，与 `SuperNav` 框架兼容。

## 8. 不足与局限

- **依赖几何感知与里程计**：占据地图和几何导航依赖精准的 LiDAR/深度观测与里程计；传感器噪声或漂移会扭曲重建几何，长时稳定性仍待提升。
- **真实世界验证有限**：仅提供定性演示，缺少定量指标（如真实环境 SR/SPL）；真实场景的多样性与动态性未充分评估。
- **算力与成本信息缺失**：未披露具体 GPU/硬件配置，且主要依赖闭源大模型 API，复现成本、延迟与可访问性可能成为实际部署障碍。
- **测试环境偏向室内**：实验基于 Habitat 模拟器与有限室内场景，其他环境（室外、多层建筑、动态障碍）的泛化能力未知。
- **消融样本量较小**：组件消融仅用 40 个随机任务，部分结论可能在更大规模上存在波动。
- **智能体模型依赖**：虽然更换模型仍表现稳定，但整体性能仍受底层推理模型能力影响；极端复杂或需要细粒度语义推理的任务可能受限。
- **未处理动态场景与长期更新**：记忆节点与地图的长期维护、冲突消解、环境变化检测等未涉及。
