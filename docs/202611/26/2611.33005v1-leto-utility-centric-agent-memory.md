## 摘要
大语言模型（LLM）智能体依赖外部记忆在交互过程中保留和重用信息。现有记忆系统将记忆视为过去的记录，并根据对话的忠实度来评估它。然而，记忆的价值在于它是否改善了智能体的响应。记忆系统在响应生成之前决定记什么和提供什么，而忠实度检查并不依据响应来检验这两个决策。因此，忠实的记忆可能无法改善响应。我们转而将记忆视为预测问题，并提出 Leto，一个面向 LLM 智能体的记忆系统，关注记忆对未来效用的贡献，而非对过去的忠实度。由于未来的请求是未知的，Leto 通过记忆索引保持对对话细节的访问，使信息可以通过其来源保持可用。当请求到达时，记忆重放利用该索引来预测并提供智能体所需的上下文，超出请求明确表述的内容。所提供的上下文的效用在响应生成之前仍然不确定，这促使了一个效用循环，利用响应结果来优化未来的记忆选择。我们在三个场景的五个基准上，将我们的系统与六个记忆系统进行了评估。在个性化方面，它在 PrefEval 上的准确率比最强对比记忆系统高出 16.3 个百分点，在 PERMA 上的任务完成率高出 3.1 个百分点。对于长期任务，它在 MemoryArena 五个环境中平均取得最佳整体性能，且增益随链深度增加而增大。在长上下文理解中，它与对原始历史进行检索的表现相当，同时提供的上下文 token 更少。

## Abstract
Large language model (LLM) agents rely on external memory to retain and reuse information across interactions. Existing memory systems treat memory as a record of the past and evaluate it by fidelity to the conversation. However, the value of memory lies in whether it improves the agent's response. A memory system decides what to memorize and what to serve before that response exists, and fidelity checks neither decision against it. Faithful memory can therefore fail to improve the response. We instead view memory as a prediction problem and present \textbf{\emph{\leto{}}}, a memory system for LLM agents that focuses on the utility of memory to the future rather than on its fidelity to the past. Because future requests are unknown, \emph{\leto{}} preserves access to conversation details through memory indexing, allowing information to remain available through its sources. When a request arrives, memory replay draws on this index to anticipate and supply the context the agent needs beyond what the request explicitly states. The utility of the served context remains uncertain until the response is generated, motivating a utility loop that uses response outcomes to refine future memory selection. We evaluate our system against six memory systems on five benchmarks across three scenarios. In personalization, it outperforms the strongest compared memory system by 16.3 percentage points in accuracy on PrefEval and by 3.1 points in task completion on PERMA. For long-horizon tasks, it achieves the best overall performance on MemoryArena averaged over five environments with a gain that increases with the chain depth. In long-context understanding, it is on par with retrieval over the raw history while serving fewer context tokens.

## 1. 论文的核心问题与整体含义

- **研究背景**：LLM 智能体依赖外部记忆跨会话保留和重用信息。现有记忆系统在写时提取事实、生成摘要，在服务时按与请求的相似度检索记忆，并以“对过去对话的保真度”作为主要评估标准。
- **核心问题**：保真度高并不等于响应质量高。记忆系统在响应生成之前就要决定“记什么”和“提供什么”，但保真度检查无法确认这两个决定是否真正改善了智能体的后续响应。
- **两个关键缺口**：
  - **记忆化缺口**：忠实记忆不一定保留未来请求所需的信息；摘要或按覆盖度提取的事实可能遗漏后来才显重要的细节。
  - **服务缺口**：按请求相似度选择的记忆，未必是生成正确响应所真正需要的上下文；用户通常不会在请求中重复既有偏好或约束。
- **整体含义**：论文将记忆视为**预测问题**。记忆的价值在于它能否提升未来任务的响应结果，即**效用**，而非对过去的忠实记录。Leto 以效用为中心组织记忆，并用响应结果反馈优化未来的记忆选择。

## 2. 论文提出的方法论

Leto 通过三个机制管理记忆：**记忆索引**、**记忆重放**、**效用循环**。

- **效用定义**  
  对请求 \(x\) 和提供的记忆 \(M\)，定义效用为：
  \[
  U(x,M) = y(x,M) - y(x,\varnothing)
  \]
  其中 \(y(x,M)\in\{0,1\}\) 是任务结果，\(y(x,\varnothing)\) 是无记忆时的结果。效用刻画像记忆是否改善、损害或不影响任务表现。

- **记忆索引**  
  - 写时：将对话拆分为**原子事实**，每个事实作为键，其值为该事实的来源 span（相邻消息片段）。这样既保留原始措辞和限定信息，又使检索更精确、噪声更少。
  - 事实合并：新事实与旧事实整合，修订性事实取代旧事实但不删除旧事实，以区分“当前有效”和“曾经有效”。
  - 每个会话还生成简短摘要。
  - 服务时：检索相关事实及其来源，再交由效用循环决定在 token 预算内提供哪些内容。

- **记忆重放**  
  在请求到达之前，Leto 主动重读存储并组合**常驻上下文**：
  - **用户画像重写**：从当前关于用户的事实和会话摘要中，重写并维护简洁的用户画像，包含跨请求有效的偏好、约束和行为指令。
  - **任务状态渲染**：对长期任务，渲染任务状态，包括按实体分组的当前事实值，以及按时间顺序排列的先前会话摘要。  
  这样，未在请求中明说的偏好和任务进展也能被提前提供。

- **效用循环**  
  - 每个记忆有**效用指数** \(u(m)\in[0,1]\)。新记忆获得初始预测 \(u_0(m)\)；保留与提供是分离的，低预测不会删除记忆。
  - **结果观察**：从交互信号中检测正向结果（如确认、使用该记忆）或负向结果（如纠正），分别编码为 1 和 0；如有任务评分，也可记录。
  - **效用更新公式**：
    \[
    u(m)=\frac{k\,u_0(m)+\sum_{i=1}^{n} o_i}{k+n}
    \]
    其中 \(k>0\) 控制初始预测相对反馈的权重。
  - 检索到的记忆只有效用指数超过阈值 \(\tau\) 才通过效用门；超出上下文预算时，优先提供效用指数更高的记忆。效用指数是启发式服务优先级，而非对公式（1）的直接估计。

## 7. 优点

- **重新定义记忆目标**：从“忠实记录过去”转向“提升未来响应效用”，直接对准记忆系统的核心价值。
- **保留细节同时降低噪声**：原子事实作为键、来源消息作为值的索引设计，既保持信息可追溯，又减轻检索噪声。
- **主动填补服务缺口**：记忆重放在请求前生成用户画像和任务状态，能提供请求中未明说的偏好和进展。
- **闭环优化**：效用循环利用实际交互信号更新记忆优先级，使服务决策随反馈改善。
- **实验广泛**：覆盖个性化、长期任务、长上下文理解三类不同需求，对比多种系统并分析效用/有害率，证据较丰富。
- **对长期任务增益明显**：随着链深度增加，Leto 的增益扩大，验证了任务状态渲染对多步依赖任务的价值。

- **未解决记忆使用问题**：Leto 只负责提供记忆，不确保智能体实际使用；智能体仍可能忽略提供的有效记忆。
- **对比公平性局限**：不同系统的配置和实现有所差异，可能影响结果比较的完全公平性。
