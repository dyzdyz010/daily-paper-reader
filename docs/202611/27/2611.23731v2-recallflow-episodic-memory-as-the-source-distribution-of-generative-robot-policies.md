## 摘要
扩散和流匹配策略已成为视觉运动模仿学习的标准选择，因为它们能够建模多模态动作分布。在依赖记忆的操作中，机器人必须依据不再可见的信息采取行动。现有方法将观察历史作为额外条件输入策略，而动作生成仍从高斯噪声开始。然而，策略随后必须从冗长且冗余的历史中挑选相关目标，随着记忆负荷增加，这会导致虚假相关和不可靠的决策。此外，初始噪声不携带机器人所见内容的任何信息，使得生成过程缺乏朝向记忆目标的引导。为了解决这些问题，我们提出 RecallFlow，一个从情景记忆构建源分布的流策略框架。回忆重定位通过若干个回忆槽将记忆与当前视图关联起来，使源分布反映记忆目标当前所在的位置。回忆锚点随后将每个槽转化为源的高斯分量，使生成能够从接近预期动作的位置开始，而不是从噪声开始。传输网络随后仅根据当前观测完成动作，使推理成本几乎与无记忆策略一样低。我们进一步构建了一套按记忆负荷分组的依赖记忆的任务，并在匹配协议下比较所有策略。大量实验表明，RecallFlow 在公开的 MIKASA-Robo 记忆基准上取得了 80.4% 的最先进平均成功率，并在我们的任务组上比最强基线高出 20.3 个百分点，在四个真实机器人任务上高出 18.8 个百分点。

## Abstract
Diffusion and flow-matching policies have become a standard choice for visuomotor imitation learning, owing to their ability to model multimodal action distributions. In memory-dependent manipulation, the robot must act on information that is no longer visible. Existing methods feed the observation history to the policy as an additional condition, while action generation still starts from Gaussian noise. However, the policy must then pick out the relevant target from a long and redundant history, leading to spurious correlations and unreliable decisions as the memory load grows. Additionally, the initial noise carries no information about what the robot has seen, leaving generation without guidance toward the remembered target. To address these issues, we propose RecallFlow, a flow-policy framework that builds the source distribution from episodic memory. Recall-Relocalization relates the memory to the current view through a few recall slots, so that the source reflects where the remembered targets are now. Recall Anchors then turns each slot into a Gaussian component of the source, enabling generation to start close to the intended action instead of from noise. The transport network then completes the action from the current observation alone, keeping inference nearly as cheap as a memoryless policy. We further build a suite of memory-dependent tasks grouped by memory load and compare all policies under a matched protocol. Extensive experiments show that RecallFlow achieves a state-of-the-art average success rate of 80.4% on the public MIKASA-Robo memory benchmark, and outperforms the strongest baseline by 20.3 points on our suite and by 18.8 points on four real-robot tasks.

## 1. 论文的核心问题与整体含义

- **研究背景**：扩散与流匹配策略已成为视觉运动模仿学习的标准方法，能够建模多模态动作分布；但许多操作任务依赖记忆，机器人必须依据不再可见的信息做决策。
- **核心问题**：现有方法将观察历史作为额外条件输入策略，但动作生成仍从无信息的高斯噪声开始，导致：
  - 策略需要从长而冗余的历史中自行挑选相关目标，容易产生虚假相关，记忆负荷增大时决策不可靠。

- **整体含义**：论文提出一种新视角——**记忆不应只作为条件，而应进入生成式策略的源分布**。生成从“记住的内容”开始，而不是从噪声开始，从而把“决定去哪”与“如何到达”解耦。

## 2. 方法论

### 2.1 核心思想

- 利用**流匹配**可以传输任意源分布到动作分布的特性，将**情景记忆**构造成源分布。
- 分工明确：**记忆决定生成从哪里开始**，**当前观测决定如何到达目标**。

### 2.2 关键组件与流程

1. **编码与记忆写入**
   - 当前与上一帧的双目图像（第三人称 + 腕部相机）经 SigLIP 2 编码为 8×8 patch tokens，得到当前令牌 \(Z_t\)。
   - 每个执行 chunk 开始时，将该帧 patch tokens 写入情景记忆库 \(M_t\)；每项带相机、位置、年龄嵌入；容量满时合并相似相邻项。

2. **Recall–Relocalization（回忆重定位）**
   - **记忆注意力**：当前令牌 \(Z_t\) 先读取记忆库 \(M\)，得到记忆条件化的当前令牌 \(\hat{Z}_t\)。
   - **回忆槽**：\(K\) 个可学习查询槽依次读记忆 \(M\) 与当前令牌 \(\hat{Z}_t\)，输出每个槽的嵌入 \(e_k\)。
   - **回忆热图**：每个槽对当前帧 patch 计算注意力热图 \(H_k(p)\)，并池化当前视图特征得到 \(g_k\)。输出 \((e_k, g_k)\) 只送入 Recall Anchors，**不进入传输网络**。

3. **Recall Anchors（回忆锚点，构建源分布）**
   - 每个槽映射为一个对角高斯锚点：
     \[
     (\mu_k,\log\sigma_k)=\mathrm{MLP}_a([e_k;g_k])
     \]
   - 另有基于当前观测的 no-recall 对数概率，计算权重 \(w=\mathrm{softmax}([\ell_\varnothing,\ell_1,\ldots,\ell_K])\)。
   - 源分布为：
     \[
     p_0=w_\varnothing \mathcal{N}(0,I)+\sum_{k=1}^{K}w_k\mathcal{N}(\mu_k,\sigma_k^2)
     \]
   - 记忆为空时，所有槽被掩蔽，源分布退化为标准高斯，方法退化为无记忆流策略 FM。

4. **训练与推理**
   - 训练锚点用**负对数似然损失** \(L_{\text{NLL}}\) 拟合演示动作；另加 KL 正则与松弛 winner-takes-all 损失。
   - 传输网络用流损失训练，源样本从解释演示的后验分量采样，并使用 stop-gradient 避免流损失影响锚点。
   - 推理时确定性模式：若回忆权重总和超过 no-recall 权重，则从最高权重锚点均值出发；否则从 0 出发，再经 \(S\) 步欧拉积分生成动作 chunk。

## 7. 优点

- **新颖的“记忆即源”范式**：将情景记忆直接构造成生成式策略的源分布，是理论上自然且有效的新视角。
- **高效解耦**：记忆负责起点，当前观测负责路径，缓解历史条件策略中的虚假相关与耦合问题。
- **推理成本低**：传输网络只接收当前观测，额外延迟仅约 1.1 ms，接近无记忆策略。
- **可退化设计**：记忆为空时自动退化为标准高斯源，方法等价于无记忆流策略。
- **实验扎实**：自建任务套件 + 公开基准 + 真实机器人，多组消融和生成过程分析，证据充分。
- **评估公平性较好**：匹配协议、多种子、真实机器人盲评、拉丁方轮换等控制偏差。

## 8. 不足与局限
