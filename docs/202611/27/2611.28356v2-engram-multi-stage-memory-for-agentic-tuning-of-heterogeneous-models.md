## 摘要
大型语言模型（LLM）智能体现在能够调优神经网络，但若没有跨会话记忆，它们会在代价高昂的试验中重新发现已知经验。复用之所以困难，是因为生产模型在架构、训练设置和推理预算上各不相同。我们提出 Engram，一种记忆系统，它将过去的试验结果与其背后的假设和推理依据联系起来，并评估这些证据是否适用于当前模型。在线智能体在需要证据的决策点整理证据：初始引导在开始时提供经过验证的经验，会话检索在每批假设生成之前提供相关的过往会话，试验候选审查将每个试验候选与匹配的过往试验进行核对。在会话之间，离线智能体提炼经过验证的经验，使记忆能够自我改进。在两个广告模型上，Engram 以少 47% 的试验次数达到无记忆对照的 32 次试验结果，并且最终平均得到更好的模型。

## Abstract
Large language model (LLM) agents can now tune neural networks, yet without cross-session memory they spend costly trials rediscovering known lessons. Reuse is difficult because production models differ in architecture, training setup and inference budget. We present Engram, a memory system that links past trial outcomes with the hypotheses and rationale behind them and assesses whether this evidence applies to the current model. An online agent curates evidence at the decision points where it is needed: Initial Guidance supplies validated lessons at the start, Session Retrieval supplies related past sessions before each batch of hypotheses is generated, and Trial Candidate Review checks each trial candidate against matching past trials. Between sessions, an offline agent distills validated lessons, making the memory self-improving. On two ads models, Engram reaches the 32-trial result of a no-memory control with 47% fewer trials and also ends with a better model on average.

- **研究背景**：LLM 智能体已经能够自动调优神经网络，通过“观察–推理–行动”循环提出假设、运行试验并根据结果选择下一组超参数，显著减少人工调参工作量。
- **核心问题**：现有 LLM 调优智能体通常缺乏跨会话记忆，导致在不同模型或不同时间重复尝试已知经验，浪费昂贵的训练试验；同时，生产环境中的模型在架构、训练设置、推理预算等方面差异很大，过去成功的经验不一定适用于当前模型。
- **整体含义**：论文提出 Engram，一个多阶段记忆系统，将过去试验的结果与其背后的假设和推理依据关联起来，评估这些证据是否适用于当前模型，并在调优决策的关键节点提供经筛选的证据，从而加速搜索并提高最终模型质量。

## 2. 论文提出的方法论

### 2.1 核心思想
- 将“原始证据”（Memory）与“经过验证的经验”（Knowledge）分离存储。
- 在线智能体在三个决策阶段（初始引导、会话检索、试验候选审查）根据当前模型和预算对历史证据进行适用性评估、修订和整理。
- 离线智能体在会话之间从 Memory 中提炼并验证经验，更新 Knowledge，实现记忆自我改进。

### 2.2 关键结构与流程
- **Memory 存储**：记录每个试验的配置变更、归一化熵（NE）、推理 FLOPs、状态，以及调优智能体在试验前写下的**假设与理由**和试验后的**结果分析**。
- **Knowledge 存储**：存放经过离线验证的“经验”，每条经验包含参数、起始值范围、变更操作（move）、效果声明（claim）和适用范围（scope）。
- **离线巩固（Offline Consolidation）**：
  - 从同一会话内的试验对中挖掘候选经验（单参数变化和联合变化分开处理，联合变化只作为相关性声明）。
  - 由 LLM 审查候选经验，结合支持试验和理由，决定保留、缩小适用范围或丢弃。
  - 候选经验仅当满足三个条件才发布：① 预测精度优于默认调优指南（在全历史和时序交叉验证上）；② 基于至少 5 个不同模型；③ 通过至少 2 次独立 LLM 评审。

### 2.3 多阶段检索
- **Initial Guidance (IG)**：会话开始时，从 Knowledge 中筛选适用范围覆盖当前模型、参数存在且基线值在起始范围内的经验，生成初始建议；联合变化只作为相关性提示。
- **Session Retrieval (SR)**：在每批假设生成前，检索相似历史会话并排序，排序分数为：
  \[
  \text{score}(c) = \sum_i w_i \cdot \text{Match}_i(c) + \lambda \cdot \text{Agreement}(c)
  \]
  其中 \(\text{Match}_i(c)\) 比较会话元数据（架构、规模、探索参数等）的匹配度，\(\text{Agreement}(c)\) 衡量当前会话已获得的 NE 增益中有多少来自与历史会话 \(c\) 探索并改进过的相同参数。在线智能体可调整权重 \(w_i\) 和 \(\lambda\) 进行二次检索。
- **Trial Candidate Review (TCR)**：在试验提交前，检查每个候选试验与 Memory 中做过相同参数变更的历史试验，判断其是否可能改善 NE 且不超过 FLOPs 上限；被判定为不太可能改善或超预算的候选必须被替换或给出理由。

### 2.4 在线智能体行为
- 每个阶段在线智能体接收检索证据，结合当前基线和已观察结果，执行“评估适用性 → 必要时修订检索 → 撰写给调优智能体的文本”的循环。

## 3. 实验设计

### 3.1 实验场景与数据集
- **两个广告模型**：
  - **Model 1**：历史丰富，包含 227 个会话，其中 59 个来自相近模型（同一生产模型类型，但架构、特征、训练设置不同）。
  - **Model 2**：历史较差，299 个会话全部来自较远模型，但部分共享架构家族。
- 每个会话从基线配置开始，最多提交 32 次试验，每次试验训练一个 epoch（Model 1 约 1.9 亿样本，Model 2 约 1.44 亿样本），推理 FLOPs 上限为基线的 1.5 倍（ρ=1.5）。
- 优化目标：最小化归一化熵（NE），即 log loss 除以平均标签率的熵；搜索空间包含学习率、warmup 调度、优化器设置、嵌入维度、层大小、输入特征等。

### 3.2 对比方法（实验臂）
- **Baselines**：无记忆对照（Control）、基于 NE 增益排序的日志（NE-sorted journal）。
- **Engram 阶段组合**：仅 IG、仅 SR、IG+SR、完整 Engram。
- **消融**：无在线策展（No curation）、无一致性反馈（No agreement）。
- **额外臂**：Model 1 额外运行“仅远历史”版本（Full Engram with distant history only）。

### 3.3 评估指标
- 报告各臂在 8、16、24、32 次试验后的平均最佳可行 NE 变化百分比（负值表示改善）。
- 两组间差异使用双侧精确 Mann-Whitney U 检验（每个臂 5 次会话）。
- 每个臂包含 5 次独立会话，试验以同步批次（每批 8 个）提交。

## 5. 实验数量与充分性

- **实验规模**：
  - Model 1 共 9 个臂（含 distant history only），Model 2 共 8 个臂（distant history only 与 Full Engram 重合），每个臂 5 次会话，合计约 85 次会话。
  - 每次会话最多 32 次试验，但实际生产中位数仅 9–10 次试验，90% 在 25 次内结束，因此 32 次试验的分析已覆盖绝大多数情况。
- **充分性评价**：
  - 消融实验覆盖了主要阶段（IG、SR、TCR 通过 Full Engram 隐含体现，但没有单独的 TCR-only 臂），以及在线策展和一致性反馈的作用。
  - 通过 Model 1 和 Model 2 的不同历史条件（相近 vs. 全部远历史）检验了适用性判断的重要性。
  - 但每个臂仅 5 次会话，统计效力有限，结果被作者定位为“初步证据”；且仅针对两个广告模型，领域和模型数量均较少，泛化性待验证。
- **公平性**：所有臂使用相同的 LLM、同步批次大小、FLOPs 上限和评估协议，无记忆对照作为严格基线，比较公平。

## 6. 论文的主要结论与发现

- **总体效果**：在两个广告模型上，完整 Engram 以少 47% 的试验次数（17 次 vs. 32 次）达到无记忆对照的 32 次试验结果；在 Model 2 上最终模型平均显著更好（-1.46% vs. -1.11%，p=0.032）。
- **多阶段贡献**：
  - Model 1 上，IG 提供的“提高 dense LR 至 0.12+”和 SR 提供的“嵌入维度 4→8”是决定性证据；但仅有 IG 时优势不显著，需要 SR 配合。
  - Model 2 上，决定性变化是缩短 dense 和 sparse LR warmup，该证据来自远历史会话，由 SR 提供；IG 仅将首次 LR 增加提前到第 1 次试验，单独作用有限。
- **适用性判断的价值**：NE 排序日志在 Model 1（有相近历史）上与完整 Engram 相当，但在 Model 2（全是远历史）上从未显著领先对照，且显著落后于完整 Engram，表明对证据适用性的判断（而不仅是按性能排序历史）在历史较差时至关重要。
- **在线策展与一致性反馈**：消融显示去除在线策展或去除一致性反馈均导致性能下降（尤其在 Model 2 上），证明这两个组件的必要性。

## 7. 优点

- **方法设计**：
  - 将试验结果与假设、理由关联存储，超越单纯配置-结果记录，使记忆具备可解释性和可迁移判断基础。
  - 三阶段检索在调优过程的不同时间点提供定制化证据，SR 通过一致性反馈动态调整排序，适应会话进展。
  - 离线巩固采用多标准验证（预测精度、多模型支持、多 LLM 评审），降低误导性经验的风险。
- **实验设计**：
  - 包含严格的无记忆对照和多种消融，能分解各阶段的贡献。
  - 通过两个历史条件不同的模型验证了适用性判断在远历史场景下的关键作用。
  - 使用真实生产广告模型和训练数据，具有实际应用参考价值。
- **可扩展性**：记忆系统分离 Memory 和 Knowledge，离线巩固使记忆随调优会话增多而自我改进，理论上可持续提升。

## 8. 不足与局限

- **实验规模有限**：仅两个模型、每个臂 5 次会话，统计效力不足；作者自己也指出“broader transfer and the benefit of the self-improving memory across repeated consolidation remain to be evaluated”。
- **算力信息缺失**：未提供 GPU 型号、数量、总计算量等细节，难以评估实际资源开销和成本效益。
- **领域偏差**：仅针对广告点击预测模型，任务类型单一；在其他领域（如计算机视觉、NLP 基础模型）的适用性未知。
- **冷启动问题**：离线巩固要求至少 5 个不同模型支持才能发布经验，对于历史很少或全新的模型类型可能无法提供初始指导。
- **阶段贡献分解不完整**：没有单独的 TCR-only 臂，无法完全隔离 TCR 的净贡献；IG 和 SR 之间存在交互，但未设计交叉消融（如 IG+TCR 或 SR+TCR）。
- **潜在偏差风险**：
  - 历史数据来自同一平台的生产调优过程，可能包含平台特定的默认配置或偏好，迁移到其他环境时可能失效。
  - 在线智能体使用较弱的 LLM（Claude Sonnet 5.5），其适用性判断质量可能影响结果，未与更强 LLM 对比。
  - 试验采用同步批次，可能无法完全反映在线调优的异步特性。
- **自我改进效应未验证**：论文没有展示多次离线巩固后 Knowledge 是否随会话数增加而改善，也未评估长期记忆积累的边际收益。
