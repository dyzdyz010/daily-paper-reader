## 摘要
大型语言模型智能体可通过利用从先前任务轨迹中提取的程序性记忆随时间自我改进，然而来自局部成功与失败的记忆所具有的不同效用仍未得到充分探索。本文在一个现实环境中研究该问题，其中包含多领域工具使用任务的异构流以及现实场景中常见的各种环境约束。我们开发了 \emph{双极性记忆与周期性维护}（DualPM），这是一种简单、无检索的记忆工作流，其特点在于：(1) 从每个轨迹内的局部成功和失败中可定制地生成反思和程序性记忆；(2) 在给定记忆容量下对长任务流进行周期性记忆整合，以防止记忆爆炸。在线前序评估与细粒度指标表明，失败记忆更有力地扩展覆盖范围，成功记忆更好地简化执行，而结合两种极性则有效地整合了两方面的优势。进一步研究表明，DualPM 能够实现跨领域记忆泛化与持续记忆适应，而在 EvoMemBench 上的外部评估则揭示了 DualPM 作为通用长期程序性记忆方法的可移植性和有效性。

## Abstract
Large language model agents can self-improve over time by utilizing procedural memory derived from prior task trajectories, yet the distinct utilities of memories derived from local successes and failures remain underexplored. This work studies this question in a realistic setting with heterogeneous streams of multi-domain tool-use tasks and various environment constraints common in real-world scenarios. We develop \emph{Dual-Polarity Memory with Periodic Maintenance} (DualPM), a simple, retrieval-free memory workflow characterized by (1) customizable reflection and procedural memory generation from both local successes and failures within each trajectory, and (2) periodic memory consolidation over long task streams under a given memory capacity, preventing memory explosion. Online prequential evaluation with fine-grained metrics reveals that failure memory more strongly broadens coverage, success memory better streamlines execution, while combining both polarities effectively integrates both benefits. Further studies demonstrate that DualPM enables cross-domain memory generalization and continual memory adaptation, while external evaluation on EvoMemBench reveals the portability and effectiveness of DualPM as a general long-term procedural memory method.

## 1. 核心问题与整体含义

- **研究背景**：大型语言模型（LLM）智能体可通过程序性记忆从历史任务轨迹中持续自我改进。现有方法多从成功轨迹中提炼可复用的工作流或技能（如 Agent Workflow Memory、SkillWeaver），或从失败轨迹中通过反思生成纠正性指导（如 Reflexion）。
- **核心问题**：局部成功与局部失败所产生的记忆，其效用是否存在本质差异？在真实环境（多域、异构、工具不可见、无显式反馈）中，如何有效生成并长期维护来自两种极性的程序性记忆？
- **研究动机**：此前研究主要基于最终任务成功/失败信号，无法揭示局部成功与失败在轨迹内部的不同作用；真实场景缺乏显式 ground truth；长期任务流中记忆会爆炸；成功轨迹可能包含局部失败，失败轨迹也可能包含有效行为。
- **整体含义**：本研究旨在区分并量化“成功记忆”与“失败记忆”对智能体工具使用行为的差异化影响，并提出一种简单、可移植的长期双极性记忆方法。

## 2. 方法论

- **方法名称**：Dual-Polarity Memory with Periodic Maintenance（DualPM），双极性记忆与周期性维护。
- **总体流程**：将任务序列划分为大小为 \(b\) 的块。每个块依次执行三个阶段：
  1. **任务阶段**：使用上一块维护后的冻结记忆上下文 \(M_{k-1}\) 执行块内所有任务，收集轨迹。
  2. **反思阶段**：对每条轨迹进行两次顺序 LLM 调用：
     - 第一次调用反思整条轨迹，不暴露 ground truth；反思提示中包含可定制的“反馈信号”部分，用于定义局部成功/失败标准。
     - 第二次调用基于反思生成成功记忆草稿 \(D^+\) 与失败记忆草稿 \(D^-\)，每极性最多 \(d\) 条。
  3. **维护阶段**：对每个极性独立调用 LLM，将上一块记忆 \(M^{p}_{k-1}\) 与新草稿 \(D^{p}_k\) 整合，在容量约束 \(|M^{p}_k| \le m\) 下保留、修订、合并、拆分、创建或移除记忆，每条记忆最多保留 \(e\) 条证据。
- **记忆结构**：每条记忆含 `memory_type`、`title`、`content`、`evidence`、`applicability`、`confidence` 等字段；记忆草稿附有来源索引。
- **记忆使用**：DualPM 不进行任务级检索，而是将完整记忆池注入系统提示，作为下一块的固定上下文。
- **实验环境改造**：在 TRAJECT-Bench 基础上构建更现实的智能体运行时：隐藏工具池，通过 `tool_search` 函数（BM25 匹配）动态发现工具；ReAct 风格交互；正确工具调用回放 gold 响应，错误调用返回失败消息；使用 hard 版本（用户请求隐式、口语化）。

## 3. 实验设计

- **主要数据集**：TRAJECT-Bench 的 parallel-hard 子集。构建四个用户画像，每个用户序列含 200 个多域工具使用任务，域分布为 70% 主域、30% 次域。
  - U1 信息工作者：Email、News/Media 为主，Finance、Education、Weather 为辅。
  - U2 学生：Education、Email 为主，Gaming、E-commerce、Music 为辅。
  - U3 预算敏感购物者：E-commerce、Finance 为主，Travel、Weather、Education 为辅。
  - U4 娱乐爱好者：Gaming、Music 为主，E-commerce、Travel、Finance 为辅。
- **主要实验设计**：2 × 2 因子设计，四种条件：无记忆、仅失败记忆、仅成功记忆、双极性记忆同时启用。在线前序（prequential）评估，块大小 \(b=20\)，10 个块中 9 个块用于评估，每条件 720 个任务样本。
- **评价指标**：基于三阶段漏斗（工具发现、工具选择、工具使用）的细粒度指标：
  - 发现召回率（Discovery recall）
  - 选择召回率（Selection recall）
  - 使用召回率（Usage recall）
  - 使用精度（Usage precision）
  - 总轮数（Total turns）
  - 最终答案准确率（Final answer accuracy）
- **对比方法（外部基准 EvoMemBench）**：无记忆、Mem0、A-MEM、MemOS、MemoryOS、AWM、SkillWeaver、AgentKB、ACE、ReasoningBank，以及本文的 DualPM。
- **外部评估**：EvoMemBench 的 CrossEp-Tool 子集，四个域（文件系统操作、车辆控制、交易机器人、旅行预订），每域 50 个任务，块大小 \(b=5\)，运行 3 次取平均。
- **模型使用**：TRAJECT-Bench 实验用 GPT-5.5 作为任务智能体与记忆工作流模型，DeepSeek-V3.2 作为最终答案评判；EvoMemBench 实验用 DeepSeek-V3.2 作为任务与记忆模型。

## 6. 主要结论与发现

- **失败记忆主要拓宽覆盖**：失败记忆在发现召回率、选择召回率上显著高于成功记忆，表现为更主动地分解请求、执行更多子任务导向搜索，从而扩展了被考虑和执行的工具集合。
- **成功记忆主要锐化执行**：成功记忆显著提升使用精度并减少总轮数，表现为更有序的并行执行和更少的无效调用。
- **双极性结合整合优势**：同时启用两种记忆可获得最佳综合性能，覆盖提升且效率不降；最终答案准确率最高，但与其他记忆条件统计上无显著差异。
- **记忆改变智能体行为**：记忆使智能体从单一宽泛搜索转向子任务导向的多重搜索，降低 gold 工具在搜索结果中的平均排名。
- **跨域迁移与持续适应**：冻结的不同域记忆能带来中等收益；自适应更新迁移记忆的性能与自建记忆相当，且迁移记忆需要更长时间修订才能稳定。
- **外部基准表现**：DualPM 在 EvoMemBench-CrossEp-Tool 上总体成功率 69.8%，超过所有对比方法；在四个域中的三个域优于 ReasoningBank（最佳基线）。
