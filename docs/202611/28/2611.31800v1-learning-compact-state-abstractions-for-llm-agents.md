## 摘要
LLM智能体通常将完整交互历史作为状态的代理，保留所有过去的观察和动作，而不论它们是否仍然相关。我们转而探究智能体实际需要向前传递哪些信息。我们将智能体状态定义为交互历史的紧凑抽象，该抽象能够保持固定参考智能体的能力，并将最小的此类抽象视为理想状态。由于匹配参考智能体的行为对于黑盒策略而言既不必要地受限又难以实现，我们通过任务表现而非行为匹配来定义充分性。我们将状态抽象表示为确定性递归程序，并使用LLM引导的遗传算法对其进行搜索。在ALFWorld和ScienceWorld上，学习到的抽象保持了接近参考水平的任务成功率，同时将平均策略输入分别减少了最多71%和57%。所得程序可直接检查，明确说明了交互过程中哪些信息被保留、更新和丢弃。

## Abstract
LLM agents commonly use the full interaction history as a proxy for state, retaining all past observations and actions regardless of whether they remain relevant. We instead ask what information an agent actually needs to carry forward. We define agent state as a compact abstraction of interaction history that preserves the competence of a fixed reference agent, with the minimal such abstraction as the ideal. Because matching the reference agent's behavior is unnecessarily restrictive and difficult for black-box policies, we define sufficiency through task performance rather than behavior matching. We represent state abstractions as deterministic recursive programs and search over them using an LLM-guided genetic algorithm. Across ALFWorld and ScienceWorld, the learned abstractions preserve near-reference task success while reducing mean policy input by up to 71% and 57%, respectively. The resulting programs are directly inspectable, providing an explicit account of what information is retained, updated, and discarded during interaction.

## 6. 论文的主要结论与发现

- **紧凑状态可以保留任务能力**：在 ALFWorld 上，学习到的抽象在 6 个任务族中平均策略输入降低最多 71%，在 ScienceWorld 上降低最多 57%，同时保持接近完整历史的成功率。
- **无系统性成功率差异**：汇集 3 次评估，学习抽象 \(\phi\) 相比完整历史 +1.7 pp（95% CI [−1.8, +5.3]），统计上不显著。
- **\(\phi\) 具有最低运行间方差**：学习抽象的智能体运行间标准差为 0.7 pp，低于完整历史的 1.0 pp 和 token 匹配窗口的 1.8 pp，说明确定性状态更新带来了额外稳定性。
- **任务间差异大**：ALFWorld 的 Two Objects 和 ScienceWorld 的 Forces 学习到的抽象几乎退化为“近历史窗口”，token 减少很少；表明所需状态的大小和形式高度任务依赖。
- **学习到的抽象是可解释的**：程序显式保留了任务相关字段，例如目标身份/位置、已搜索容器、物体属性（清洁、冷热）、设备状态、完成标志等，揭示了智能体所需的真正信息。
- **字段重要性的量化证据**：隐藏八个字段组中的七个会显著降低成功率，最大降幅达 36.1 pp（进度与控制），甚至未被策略显式命名的字段（如清洁标记）也可能至关重要。
- **长时域优势放大**：在 BabyAI-GoTo 上，\(\phi\) 将策略输入从完整历史的 27.5k token/调用压缩到约 250 token/调用，减少 95%，且成功率差异不显著。
- **首次 LLM 生成的程序通常不够好**：10 个任务族中只有 2 个首次满足约束；后续改进全部来自突变或交叉，其中 16 次改进依赖反射修复。

## 7. 优点：方法或实验设计上有哪些亮点

- **概念创新**：将 LLM 智能体状态问题从“上下文压缩”提升为“状态识别”，并与经典状态抽象理论建立形式化联系。明确了三者层次（行为、表现、有符号充分性）并提出可行域嵌套的形式证明。

- **实用且推理高效**：学习到的状态更新是确定性程序，部署时**不需要额外 LLM 推理**，比 ACON、LLM Summarizer 更具成本优势。
- **严格的遗传搜索框架**：结合 Proposer 与 Reflector、带缓存评估、反射修复机制，充分利用 LLM 的代码生成与诊断能力。
- **多维度实证评估**：不仅报告成功率和 token 减少，还通过字段遮蔽、交叉模型、tokens 匹配窗口、长时域任务、稳定性方差分析等方式主动检验因果性和鲁棒性。
- **对“成功与 token 应分开解释”有自觉**：作者明确提醒失败轨迹可能更短、token 更少，体现了对指标偏差的意识。

## 8. 不足与局限：包括实验覆盖、偏差风险、应用限制等

- **并非所有任务都能学到紧凑抽象**：Two Objects 和 Forces 表明部分任务的状态几乎等于近历史窗口，说明方法收益高度依赖任务结构。
- **搜索成本高**：总元 LLM 调用 860 次、5,948 次 rollout，虽然启动后抽象可在部署时零推理成本运行，但一次性学习阶段的搜索开销较大，可能限制其在大规模应用中的可行性。
- **策略相关性限制**：状态是为固定策略优化的，换用其他策略模型时可能缺失关键信息。跨模型迁移实验显示用 Qwen 时与完整历史的性能差距为 −1.5 pp，说明跨策略迁移不可靠。**更换策略时需重新搜索**。
- **训练/评估数据规模和任务限制**：ScienceWorld 的部分任务训练实例较少（如 Genetics 仅 6 个），候选抽象可能对训练轨迹过拟合。
- **未明确报告计算基础设施**：论文只报告了元 LLM 调用和 rollout 数量，未给出 GPU/TPU 规格和总训练时间，难以评估计算成本的实际财务/能耗。
- **成功率与 token 减少不可分**：token 使用可能被成功轨迹长度影响，虽然作者做了 tokens 匹配对照，但该混杂因素在任务族之间仍难以完全剔除。
- **二进制成功奖励限制**：充分性只用任务成功定义，无法区分“部分成功”或“不同质量的轨迹”，限制了状态抽象在连续奖励任务中的适用性。
- **语言模型性能依赖**：结果依赖于 GPT-5.6 Luna 这一单一强模型，不同模型对状态信息的敏感

度不同，可能在不同模型上需要重新搜索或调整。

- **状态 schema 依赖人工设计**：程序化状态表示依赖预先给定的字段 schema \(S\)，需要领域知识来定义哪些信息类别可能重要。对于新任务或环境，若 schema 设计不合理，搜索空间会被限制，难以自动发现未预见的必要状态字段。
- **环境范围较窄**：主评估仅覆盖 ALFWorld 和 ScienceWorld 两个文本环境，且均为离散动作、回合制任务；对多模态、连续控制或开放世界任务的适用性尚未验证。
- **搜索过程对生成模型质量敏感**：Proposer 与 Reflector 本身依赖 GPT-5.6 Luna 的代码生成和诊断能力，搜索效果可能随底层模型变化；若生成程序质量下降，遗传搜索可能无法收敛到有效抽象。
- **超参数未充分调优**：种群大小、迭代次数、变异概率、锦标赛规模等搜索超参数主要基于两个环境设定，未报告大规模超参数敏感性分析；不同任务可能需要不同搜索预算。
- **成功信号稀疏且二元**：仅在任务完成时给予成功信号，无法区分部分进展或轨迹质量，可能使学习到的状态只保留“完成所需”的最小信息，而在需要细粒度决策或连续奖励的任务中不够用。
- **长期部署中的分布漂移未考虑**：学习到的状态更新程序在固定任务分布上优化，若环境动态或任务目标在部署后发生变化，该抽象可能不再充分，需要重新学习。
